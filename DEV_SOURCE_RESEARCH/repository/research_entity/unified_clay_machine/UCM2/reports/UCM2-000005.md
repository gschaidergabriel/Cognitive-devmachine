## Question

After UCM2 can replay a hash-chained event stream, what additional mechanism is minimally required to reject a coherent rollback to an older valid prefix?

## Competing realities

### H1 — internal hash-chain verification is enough

If every retained event validates and the chain is contiguous, replay may appear safe to admit.

### C1 — a valid-prefix rollback remains internally self-consistent

An attacker, stale restore, filesystem rollback or old snapshot can remove only the newest tail and leave a perfectly valid earlier chain. Internal verification therefore cannot know that a later admitted head previously existed.

### H2 — an externally admitted event-head receipt discriminates the rollback

If `(root, schema, seq, epoch, terminal event hash, provenance)` is admitted outside the mutable event database, recovery can require an exact match to that receipt before accepting state.

### C2 — a receipt stored under the same mutable authority is only another self-consistent object

The receipt format itself is not trust authority. Its benefit exists only when a separate trusted store/signer/admission boundary preserves the receipt independently of the rolled-back UCM2 database.

## Primary external evidence

RFC 9162 Certificate Transparency v2 was used only as a mechanism analogy: append-only Merkle logs use externally exchanged/signed tree heads and consistency proofs so a later known head can constrain what histories are acceptable. The UCM2 candidate does not implement Certificate Transparency or claim equivalent security; the transferable mechanism is the separation between internal log integrity and an independently retained admitted head.

Primary source: `https://www.rfc-editor.org/rfc/rfc9162`

## Reusable bounded finding for the main instance

Do not treat a valid replay log as sufficient lineage identity. Recovery authority needs two distinct proofs: `(1)` the event history is internally valid/reconstructable and `(2)` the recovered terminal head is admitted by an independently preserved lineage witness. The second proof must not silently collapse into another mutable row in the same state authority.
