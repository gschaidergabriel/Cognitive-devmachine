# Target re-entry plan

PSW itself is refuted as a distinct architecture. Re-entry therefore carries only obligations that survive the refutation.

## Hyperposition / F-V01-05

- preserve existing unresolved-alternative semantics;
- do not introduce a second PSW semantic organ;
- make physical representation replaceable/observable;
- branch identity must preserve exact self/entity/version/epoch/revision/hypothesis/provenance independently of storage deduplication.

## ACEF concurrent candidate

If ACEF later survives its own ATOMIC tests and becomes the branch/transaction substrate, apply the representation measurements below to ACEF `SemanticDelta`/`HypothesisBranch` storage and PURE processing. Do not duplicate ACEF transactions or commit certificates inside PSW.

## ClayCode / F-V01-02

The safety-critical new test obligation is an exact/conservative material-read contract for any cross-alternative pure computation reuse. An incomplete read-set produced an executable false-share counterexample.

No new syntax is requested now. First determine whether current TypedIR/type-effect/lowering can expose a sound read-set/effect summary. Unknown/dynamic cases fall back to separate execution.

## UnifiedDB / F-V01-04

Persist branch identity, sparse deltas, representation conversion receipts and enough resource telemetry to reconstruct exact branches. Physical cache/representation must not become a second source of semantic truth.

## Loop core / F-V01-03

Only PURE internal transitions are candidates for read-signature reuse. GWT broadcast/reconstruction/salience is not evidence that two branches are semantically identical.

## Effects / F-V01-09

No unresolved multi-branch external execution. Branches can produce proposals; only the normal current admitted effect path executes.

## Real falsifier

On real Frank target-VPS traces, compare:

1. materialized independent branch states/execution;
2. conventional sparse delta/overlay state;
3. sparse delta/overlay + exact read-signature memoization;
4. any actual ACEF/Hyperposition representation that exists by then.

Measure CPU/RAM/wire/latency/signature overhead/reconstruction integrity and representation-switch cost. Calibrate a policy from held-out traces. A fixed synthetic threshold must not be copied into production.
