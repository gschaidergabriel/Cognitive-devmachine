# HCU receipts

HCU-specific bounded receipts belong here and are part of the Mini Entity package snapshot.

A runtime-capable receipt should bind, at the scope actually observed:

- exact repository/source identity;
- exact model/tokenizer/runtime identity;
- host/executor class;
- tile count and role/topology;
- measured peak RSS and context settings;
- measured throughput/latency where relevant;
- generation/episode/causal identity;
- feeder/provider classification and FREE_ONLY status;
- command/test identity and exit/result state;
- explicit non-claims.

Source-only work must not mint runtime credit. VPS deployment observations must not be represented as acceptance-test evidence while current execution controls forbid VPS testing.
