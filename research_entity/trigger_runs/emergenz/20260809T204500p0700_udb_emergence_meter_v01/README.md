# UnifiedDB Emergence Lab v0.1

This is a measurement and mutation laboratory, not a consciousness detector.

It preserves a typed evidence vector across factorial interaction, discrete
synergy proxy, common-driver conditioning, lesion, rescue and truthful-vs-
shuffled re-entry. A candidate cannot pass on correlation, non-additivity,
recurrence or one scalar alone.

The SQLite schema separates immutable source snapshots, derived episodes,
interventions, channel samples, metric receipts and candidate assessments.
Every future mutation must point to a parent episode and record the held-fixed
variables, seed, preregistered prediction and hashes.

Run:

```bash
python emergence_meter.py --out emergence_lab.db --json calibration.json
python -m unittest -v test_emergence_meter.py
```

Current evidence boundary: synthetic mechanism calibration over a copied real
FRANK database layout. Live-FRANK causal validation remains blocked until the
runtime emits episode IDs and per-receiver delivery/reconstruction/uptake/use/
outcome/re-entry receipts.
