## 2. Historical mechanism synthesis

The strongest reconstruction from frozen Original-FRANK code/history is not a single consciousness module but a nested multi-timescale recurrent control system:

`world/user/system`
`-> perception + appraisal + body/system state`
`-> thalamic novelty/habituation/prediction-error/gain control`
`-> attention/competition`
`-> workspace global availability/broadcast`
`-> model cognition / response / action proposal`
`-> response analysis + verified action/effect outcome`
`-> reward/RPE + E-PQ/affect + ego/self + memory + prediction + goals + experience-state updates`
`-> persistent state`
`-> top-down gating/context reconstruction`
`-> next workspace/model cycle`
`-> changed internal/external world`
`-> perception ...`

Key historical fact: thalamic gating was itself recurrent. Output use could modify subsequent channel biases, while habituation, novelty, vigilance and prediction error also changed gain. Output feedback changed E-PQ/Ego/consciousness state. NAcc-like reward prediction error and tonic/phasic state changed future motivational context. The resulting loop was distributed across organs rather than implemented by one module.

## 6. Stability distinction

Do not equate low state change with convergence.

- `CONVERGING_FIXED_POINT`: low state delta + low residual pressure/error.
- `STALLED`: low state delta + high unresolved pressure/error.
- `PRODUCTIVE_LIMIT_CYCLE`: bounded recurrent trajectory with useful non-zero periodic/metastable structure.
- `DIVERGING_OR_OVERTHINKING`: rising state/error/cost or negative marginal value under continued recurrence.
- `CHAOTIC_OR_UNCLASSIFIED`: insufficient evidence.

For fixed points use a local Jacobian/spectral stability proxy. For recurrent cycles use perturbation recovery/transverse stability rather than demanding `Delta x -> 0`.
