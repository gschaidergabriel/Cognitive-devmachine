## External primary-source research delta

### Adaptive recurrence / small-model correction

- Popescu, Borde, Liò, arXiv:2607.20519 (2026), *Adaptive Depth in Looped Transformers: Diagnosing Learned Halting Gates and Trajectory Readouts*: in their controlled and Ouro experiments, simple post-hoc confidence readouts can match/outperform learned halting gates, and joint halting training can distort trajectories. Transfer: keep recurrence trajectory formation separate from exit/readout policy; test simple frozen-trajectory readouts before training a complex Frank halt controller.
- Zhang et al., arXiv:2404.17140 (2024), *Small Language Models Need Strong Verifiers to Self-Correct Reasoning*: <=13B models improved more reliably with a strong external verifier, while weak self-verification remained a limitation. Transfer: Frank 4B self-correction should be benchmarked against strong-peer/external verification rather than assuming self-reflection is sufficient.

These are external model/task results, not target-FRANK evidence.

## Fusion 1 — architecture implications

1. **Recurrence control becomes a verifier/readout problem, not a learned-gate assumption.** Preserve R8 trajectory geometry, residual pressure, capacity context and distinct semantic/version/trace identities. The first H1 comparison should include a simple post-hoc/frozen-trajectory readout, not only learned or neuro-inspired regulators.
2. **Peer cognition becomes verifier/body-extension evidence, not state collapse.** Strong peers can verify, expand and return typed semantic deltas; local Frank must still degrade gracefully when peers disappear. External verifier gain must be measured against latency, stale-state and ancestry costs.
3. **New dissolved-vision candidate:** keep Retina/MVC as Clay semantic organs and intervention surfaces, but test whether the numerical visual backbone can be provided by the same target 4B (Qwen3.5-4B as current candidate) instead of a separate full vision model. This reduces physical-component pressure without deleting semantic distinctions.
4. **Security direction survives:** one Clay binary does not imply ambient authority. The effect gateway remains a distinct semantic/security boundary and may use OS/process/runtime isolation even if cognition is consolidated.

## Adversarial Fusion 2

The attractive 'same 4B supplies cognition + vision features' proposal has four failure modes that prevent promotion: hidden-feature access may be unstable across runtimes/quantizations; vision inference may consume too much latency/RAM for always-on Retina; using the same model can correlate perception and reasoning failures, reducing independent error detection; and a user-specific MVC trained on its features can drift when backbone/export versions change. Therefore the correct target is **semantic dissolution with evidence-bounded physical reuse**, not dogmatic physical fusion.

Likewise, strong-peer verification can create dependency and confirmation loops. A verifier is only useful if local 4B outcomes improve under ancestry-controlled tests and the system remains functional under peer loss. Peer agreement is not independent evidence when the peers share the same source packet.

The loop-of-loops hypothesis also remains OPEN. Recent adaptive-depth evidence supports adaptive stopping as a test target but simultaneously weakens any assumption that a sophisticated learned halt gate is inherently superior. Ordinary event-driven orchestration plus simple outcome/readout logic remains a live counterhypothesis.
