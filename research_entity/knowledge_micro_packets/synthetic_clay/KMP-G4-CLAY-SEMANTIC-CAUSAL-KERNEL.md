### Core
G4's integrated architecture candidate is a **semantic causal kernel**, not a monolithic database or host OS. Canonical/versioned events feed incremental contextual and active projections; dynamic assemblies participate in receipt-linked GWT episodes; ClayCode carries typed transition proposals; a deterministic external capability/effect gateway authorizes side effects and returns receipts for re-entry.

### Evidence / boundary
This synthesis joins several independently supported G3 constraints with new G4 proxy evidence and current external implementation research. It remains an OPEN architecture hypothesis because no complete live FRANK shadow run has yet compared it against the existing system.

### Implication
Clay can feel like one coherent cognitive material while physical storage, IPC, model backends and host OS remain plural and replaceable. This preserves portability, recovery and security without forcing implementation choices into ontology.
