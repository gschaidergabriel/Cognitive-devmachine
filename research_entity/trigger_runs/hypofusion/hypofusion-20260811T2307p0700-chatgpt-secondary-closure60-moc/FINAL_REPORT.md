`same visible outcome != same causal closure`

The new architecture experiment therefore asks two distinct questions:

1. **Closure question:** Does the candidate preserve the causal loop properties required by Frank?

## 2. Fresh external research after the 60 hypotheses

### Adaptive recurrence is strengthened; blind recurrence is rejected

2026 self-correction/control research shows that repeated correction can improve or degrade depending on error-introduction/error-correction dynamics. Thinking-trap and adaptive-restart results show that longer deliberation can remain trapped in a wrong prefix and benefit from restart/reseed instead of continued elaboration.

**Fusion:** operational closure stays mandatory at the organism level; R1 deliberative recurrence becomes adaptive, budgeted and restart-capable.

### Execution-state memory strongly supports branching/repair

MAGE organizes long-horizon execution as a hierarchical active state tree with validation and revision, reporting large task-success gains and token savings over its tested baselines. WorldMemArena independently reframes memory inside an Action–World loop and shows that good storage does not imply successful retrieval/use/action.

**Fusion:** execution-state lineage should not be reduced to semantic RAG. Branch/path state is a serious candidate for both long-horizon execution and Hyperposition realization.

### Native workspace evidence refines recurrence scope

Anthropic's 2026 J-space work reports global-workspace-like functions inside language models. Crucially for MOC, model-local workspace/access functions need not imply a recurrent outer architecture: they can arise within model depth.

**Fusion:** MOC does **not** require every inner workspace or model operation to be recurrent. R0 native cognition can be feed-forward/shallow; R2/R3 persistent causal closure remains separate.

### Temporal/conflict memory strengthens state-role separation

MemConflict, A-TMA, MOSAIC and the very recent LatticeMind all point toward explicit handling of current/historical/transition/conflicting memories and toward diagnosing write/maintenance/retrieval/use separately.

**Fusion:** bitemporal/current-belief governance is strengthened as a candidate, but must beat Frank's existing epoch/provenance baseline before schema promotion.

### Provenance and authorization strengthen consumer-side validity

SLSA-style verification and the Aug-2026 CapLease result independently support a systems distinction already emerging inside Frank: recorded provenance or fresh token identifiers are insufficient if consumers do not bind exact artifact/action identity and durable authorization state.

**Fusion:** consume-bound verification is strengthened semantically; one universal CBPC runtime primitive remains unpromoted because branch-local typed guards are a valid simpler baseline.

### Reward research strengthens anti-Goodhart structure

Long-horizon credit work supports richer credit assignment, while 2026 reward-hacking work shows that optimizing observable proxy reward can widen the gap to hidden objectives and may resist ordinary credit/exploration fixes.

**Fusion:** verified outcome + causal credit remains upstream of material reward. One scalar reward is not promoted. The current deterministic DONE-receipt fold remains promising only when exact source-frontier/currentness is proven.

### Higher-order counterevidence is especially valuable

PEID supplies an interventionist path to synergistic causal effects. But a 2026 Physical Review Research result gives a direct warning: some higher-order-looking hypergraph dynamics are exactly reducible to weighted pairwise systems.

**Fusion:** `pairwise-first`. Hyperedges, higher-order coupling and emergently distributed organ claims require residual interventional irreducibility plus utility.

### Typed/compiled ClayCode is externally plausible and internally advancing

Text2DSL and type-constrained generation support structured grammar/API/type constraints. Compiler-oriented agent work supports slow strategic reasoning plus fast compiled control. Current Frank main already contains a bounded executable `decide_effect` evaluator/package slice with target evidence; later dual-backend work is advancing under Goodman ancestry constraints.

**Fusion:** do not invent semantics. Use existing typed ClayCode, executable differential tests, fail-closed unknowns, and progressively lower pure verified closures.

## 5. New architecture hypothesis — FRANK MOC-KERNEL

The MOC-Kernel is one complete ClayCode loop-core with **four nested rings**, all sharing one semantic/witness spine.

### R0 — Native Cognition

Model-local automatic processing plus optional NativeModelWorkspace/LCOP observation. Recurrence is **not required by MOC** here. Latent signals have no authority and become control candidates only after observability, actionability, incremental outcome value and build-transfer gates.

### R1 — Deliberative Regulation

Bounded self/world/memory assembly, prospection, control pressures, Hyperposition, ClayGWT, Needle and adaptive restart/reseed. This is the fast internal recurrent layer, but recurrence depth is conditional on unresolved pressure and expected verified benefit vs cost/error/instability.

### R2 — World-Causal Closure

`intent → effect gate → action → consequence → verified outcome → causal credit → admission → provenance-valid re-entry`

This is the material closure ring. If producer/state/frontier/authority/consumer bindings fail, the loop is not considered causally closed for learning even if the visible outcome happens to match.

### R3 — Slow Organism Regulation

Goals, reward/control successor, regulatory personality, consolidation, capability self-model, homeostasis, checkpoint/recovery. These states survive context/session boundaries and restart. Self-generated activity does not mint material reward; slow plasticity remains verified-outcome/credit gated.

### Shared semantic/witness spine

MOC proposes, as candidates to test rather than all-at-once implementation requirements:

- UnifiedDB authority with execution-state vs semantic-memory separation;
- immutable source episodes + current adjudicated beliefs + candidate valid/transaction time;
- selected continuation head and distinction between materialization identity and semantic identity;
- StateWitness / SelectionWitness / consume-bound validation at consequential use;
- ClayGraph derived-only and bound to source semantic root/head;
- Hyperposition branch/equivalence fabric, pairwise-first;
- `lease_epoch` for authority fencing and separate `stream_seq` candidate for client replay;
- ResumeCompatibilityFingerprint or explicit validated migration relation;
- CognitiveCycleShadow + LoopDynamicsReadout + resource shadow;
- Binary freeze to a robust operating region, not a transient peak.
