## 1. Executive result

G1d established a useful separation:

`authoritative exact/event state -> immutable semantic graph epoch -> sparse activation -> bounded Assembly -> optional graph escalation -> exact-anchor validation`.

G2a keeps that architecture but finds that one missing question is now more important than another graph data structure:

> **When should the latent field be allowed to influence the next Assembly, and how may outcome feedback update that field without creating a self-confirming memory loop?**

The run produces three main results.

### Result A — activation should be route-selective

A mixed exact/associative synthetic workload shows why one global retrieval policy is a bad default. Exact/high-confidence tasks benefit from bypassing background salience, while associative tasks benefit from truthful activation. The resulting candidate routing modes are:

`BYPASS | SUPPLEMENT | ESCALATE | QUARANTINE`.

The local 10,000-episode proxy measured:

- explicit-only overall top-1: **0.5569**;
- always-blend: **0.5752**;
- adaptive router: **0.9500**;
- shuffled blend: **0.0615**.

The reason is visible by query class:

- explicit exact top-1: **1.0**;
- explicit associative: **0.01446**;
- always-blend exact: **0.31904**;
- always-blend associative: **0.88879**;
- adaptive exact: **1.0**;
- adaptive associative: **0.88879**.

Therefore the useful hypothesis is not `activation beats retrieval`; it is:

> **route the memory mechanism according to the semantic query class and confidence.**

A compact E2B implementation independently reproduced the same direction, but not the exact local numbers. The exact E2B router subset had not produced a result artifact at the evidence cutoff, so exact remote replication is explicitly OPEN.

### Result B — truthful continuity adds value on a staged current-RAE self-use proxy

Cycle 4 could not execute G1d self-use. G2a now has an executable 23-node current-RAE mechanism graph and 12 cross-branch research questions.

Matched E2B/local results:

| Arm | Recall@5 | MRR |
|---|---:|---:|
| explicit-only | 0.583333 | 0.833333 |
| truthful prior activation | **0.756944** | **0.902778** |
| shuffled prior | 0.604167 | 0.736111 |

This is the first executable ClayGraph self-use mechanism result in this branch. It does not prove production retrieval superiority: the graph, questions and gold mechanism sets are manually curated and share RAE ancestry. Its value is narrower: truthful prior activation carries information beyond a lexical route in this staged corpus, while shuffled prior does not reproduce the same gain.

### Result C — naive utility learning can become a memory attractor even without an attacker

Hypofusion H1 warned that adaptive salience could become self-confirming. G2a turns that into an executable failure mode.

A skewed 25-topic online workload applies a naive scalar downstream success signal to all selected memories. At **0 injected poisoning**, the naive learner converges toward the frequent topic:

- top-1: **0.286667**;
- rare-topic accuracy: **0.016886**;
- false frequent-attractor top-1: **0.713333**.

A constructed governor using:

- context reachability gating;
- itemwise utility credit;
- bounded positive/negative salience;
- decay;
- per-topic mass cap;

produces in the same construction:

- top-1: **0.991**;
- rare-topic accuracy: **0.976548**;
- false frequent-attractor: **0.006**.

The same qualitative result survives 15% injected reward poisoning. E2B reproduced the anti-attractor metrics to reported precision.

This is a strong mechanism negative against **indiscriminate assembly-level reward propagation**, but not production evidence for the governor: the governed arm uses a synthetic 96% itemwise verifier. The real requirement is therefore:

> **utility credit must have a scope (`ITEM | PATH | ASSEMBLY | UNKNOWN`) and uncertainty; UNKNOWN credit cannot freely reinforce every surfaced memory.**

## 3. External research fusion

Current external work independently supports the broad mechanism class, while supplying important counterevidence.

### Active and typed/temporal graph memory

2026 systems including SYNAPSE, MAGMA, GAM, Temporal Semantic Memory, APEX-MEM, LiCoMemory and Hindsight use combinations of dynamic graph memory, spreading activation, inhibition/decay, temporal validity, orthogonal semantic/temporal/causal/entity relations, hierarchical retrieval and hybrid graph/vector/keyword paths.

Graphiti provides implementation precedent for temporal validity windows, episode provenance and incremental graph updates.

The transfer is not their benchmark scores. The useful convergence is:

> **persistent memory can be relational, temporal and incrementally active instead of only document top-k retrieval.**

### Counterevidence: more propagation/context is not automatically better

Current oversmoothing work analyzes graph message passing as a convergence/homogenization process and studies structural/signed methods to resist collapse. Long-context/context-rot work likewise shows that exposing more information can reduce effective use.

This supports bounded Assembly and anti-attractor controls rather than unlimited propagation or maximal context.

### Memory poisoning

Current 2026 memory-security work studies direct, compositional and context-triggered poisoning. A particularly important transfer is that write-time authenticity/integrity checks need not stop a memory that becomes harmful only when combined with a future context.

G2a therefore separates:

`source/provenance validity != use-time cognitive utility/safety`.

Role/time/context/poison gates operate at routing/Assembly time as well as ingestion time.

8. unknown causal credit remains bounded/uncertain rather than silently positive.

10. graph activation, GWT selection and model-internal uptake remain separate causal stages.

## 6. Research-tool learning

The new E2B path generated useful research-engineering negatives.

### NumPy dependency failure

The first remote execution failed because the E2B base image did not contain NumPy. The lab was rewritten to standard-library Python rather than silently installing an undeclared dependency.

### Evidence-output truncation

The next successful execution showed that the bridge intentionally truncates long string fields. A successful process therefore did not automatically preserve a complete scientific receipt. The lab was changed to emit compact summary receipts and decisive experiments were split.

### Compact reimplementation mismatch

A shortened remote implementation reproduced the main direction but slightly changed self-use/router numbers. The run preserves that as implementation sensitivity rather than calling it exact replication. The exact self-use subset was then separately replicated and matched local results.

These tooling results directly support the broader RAE principle:

> **portable research code and portable evidence receipts are separate requirements.**

## 10. Decision

**CASAR-G2a remains OPEN/HOLD.**

It is a meaningful improvement over G1d because it turns two vague ideas — "memory should influence thought" and "outcomes should tune memory" — into falsifiable routing and credit contracts.

The strongest current ClayGraph hypothesis is now:

> **keep persistent semantic memory rich and replayable; expose only a bounded task-conditioned Assembly; let truthful associative activation help where the query class needs it; and adapt salience only through scoped, uncertainty-aware utility receipts with anti-attractor controls.**

This is strong enough to guide the next implementation, but not strong enough to replace the accepted G0 graph or claim a live FRANK cognitive improvement.
