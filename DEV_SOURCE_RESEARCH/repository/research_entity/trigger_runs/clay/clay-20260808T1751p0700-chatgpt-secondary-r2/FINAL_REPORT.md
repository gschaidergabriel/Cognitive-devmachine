## 3. External research / Fusion 2 inputs

### Selection integrity
`arXiv:2606.12290` independently supports the mechanism that authenticated records may still be selected through attacker-controlled structure. Its key concept is **reallocatability**: if writable structural terms can move an O(1) share of top-k membership past a selected fact's margin, record-provenance defenses can be blind. This upgrades `record provenance != selection integrity` from project-internal architecture concern to externally supported mechanism, while leaving live FRANK transfer OPEN.

### Agent memory as lifecycle
The registered arXiv provider returned current work decomposing agent memory into representation/storage, extraction, retrieval/routing and maintenance; one 2026 systematic study reports that no architecture dominates all workloads and that localized maintenance can be more cost-efficient than global reorganization. This supports COVE's selective maintenance direction, not its exact implementation.

### Causal replay
Current 2026 work on Causal Agent Replay uses interventions/re-execution to attribute agent failures instead of relying on correlational step labels. Transfer: stage receipts should support replayable intervention, not merely observability.

### Targeted conflicts instead of universal locking
FoundationDB's strict-serializable model plus snapshot reads and narrow explicit conflict ranges provides an implementation precedent for validating only the dependencies that trusted semantics justify.

### Projection/order is causal input
ACL 2026 prompt-order work reports >14 percentage-point order effects in tested settings. Separate 2026 work across 44 models reports structured-output requests changing answer distributions. Reader projection is therefore an experimental variable, not neutral transport.

### Incremental/versioned runtime analogues
Differential Dataflow demonstrates computation that reacts where collections change rather than recomputing globally. Epoch-pinned/RCU-style publication supplies an implementation analogue for immutable old-or-new views with delayed reclamation. These are feasibility analogues, not FRANK performance results.

### Android / Qwen class
Current Qwen3-4B GGUF material specifies a 4.0B model with 32,768 native context and multiple quantizations; MLC Android exposes estimated VRAM and context/KV/prefill controls. Target-reader experiments must pin quantization, context, runtime and projection semantics, and must use sustained device traces.

## 5. Fusion 2

`FUSION2_HYPOTHESES.json` contains **18 transformed hypotheses**. The most important transformations are:

1. **Certified Causal Slice** — partition dependencies into native consistency domains; use local snapshot handles where possible and explicit cross-domain witnesses only where necessary.
2. **Selection Closure** — selector semantics, authorized input view, candidate membership and ranking become read dependencies when reallocative.
3. **SelectionReceipt** — bind selector semantics/version, authorized view, candidate-set hash, ranking outcome and selected anchors.
4. **Projection Proof Obligation** — hashes prove identity, not semantic correctness; trusted projection requires differential/reference/mutation testing.
5. **ClayCode deterministic-before-generative projection** — resolve sound deterministic semantics before the model and expose only unresolved semantics plus receipts.
6. **GWT intervention DAG** — identify effects at graph-prior, workspace, projection and re-entry stages separately.
7. **Candidate-set receipt as dual-purpose primitive** — useful for both causal science and effect security.
8. **Dual memory trust gates** — separate ingestion/write authority from retrieval/selection authority.
9. **Revocation dependency index** — allow dependency-scoped invalidation of latent support.
10. **Derived-memory GC as correctness/security support** — materialized and active budgets are separate.
11. **Read-aware adaptive rematerialization** — include future reads, query tax, memory and recovery risk.
12. **Negative/predicate dependencies** — causal slices include relevant absence/range/top-k-margin conditions, not only positively returned records.
13. **Immutable epoch publish + delayed reclamation** — derived views should be old-or-new to readers.
14. **Android governor with hysteresis/multi-timescale state** — burst optima need not be sustained optima.
15. **Reader identity is multidimensional** — model, quantization, context, runtime and projection semantics.
16. **Hard tripwires before Pareto optimization** — safety/recovery/authority constraints are not soft reward terms.
17. **Self-reference resolves to exact receipt refs** — prose self-report is not state evidence.
18. **Emergence certificate carries causal-slice basis** — lesion/rescue/OOD episodes must be basis-compatible.

## 6. COVE-G10 architecture

Machine-readable candidate: `COVE_G10.claycode.json`.

```text
operation intent
-> trusted operation semantics
-> compile CausalSlicePlan
   [positive reads, negative/predicate reads,
    consistency domains, selection dependency,
    projection dependency, capabilities]
-> acquire native snapshots/epochs + cross-domain witnesses
-> authorized selector -> SelectionReceipt
-> exact anchors -> candidates
-> GWT competition -> semantic WorkspaceEpisode
-> deterministic Reader ABI -> ProjectionProofReceipt
-> model proposal
-> trusted closure + capability gateway revalidates effect slice
-> idempotent effect intent/release -> outcome receipt
-> causally compatible re-entry
```

New/strengthened runtime concepts:
- `CausalSlicePlan`
- `ConsistencyDomainWitness`
- `SelectionReceipt`
- `ProjectionProofReceipt`
- `CertifiedOperationView`
- `EffectReceipt`
- `M.REVOCATION_DEPENDENCY_INDEX`
- hard-constraint-first multi-timescale resource governor

Hard invariants:

`truth != activation != candidate != ignition != projection != authority`

`record provenance != selection integrity`

`projection hash identity != semantic correctness`

`component freshness != causal compatibility`

`physical colocation != semantic unity`

`model output != execution authority`
