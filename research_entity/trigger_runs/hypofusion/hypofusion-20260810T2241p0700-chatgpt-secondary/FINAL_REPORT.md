# HYPOFUSION — Final Report

Run: `hypofusion-20260810T2241p0700-chatgpt-secondary`

## Result

This run does **not** support simply adding more Frank subsystems. The strongest current evidence says the dominant near-term failure mode is **cross-layer composition**: individually plausible presence, physical exclusion, effect lifecycle, replay, recovery and identity mechanisms can still form an unsafe or incoherent whole when their epochs/provenance are not bound across boundaries.

The highest-value transformed hypothesis is therefore `HF2-001-EXECUTION-EPOCH-SPINE`: one monotonically fenced execution/recovery identity must be revalidated at every consequential state/response/effect/replay boundary. Recent target PR evidence around #147/#158/#160 is materially more decision-relevant than older architecture prose.

## Strengthened

1. **Cross-layer execution fencing** — strengthened strongly by current executable negative evidence and mature lease/leader-election analogues. A presence lease is not enough unless stale execution is fenced from downstream writes/effects.
2. **Adaptive recurrence** — strengthened only as a bounded compute-allocation mechanism. Recurrent-depth and causal recurrent-planning evidence shows real possible utility, but more compute is a confound and recurrence is not emergence.
3. **Long-horizon state intervention** — strengthened substantially by 2026 execution-state memory and proactive-memory results. Frank should test memory as state reconstruction + selective intervention with a null action, not merely similarity retrieval.
4. **Structural information-flow/effect boundaries** — strengthened by CaMeL and Fides as an implementation direction.

## Weakened / split

1. **Prompt injection solved by data/instruction separation** — weakened. Structural separation remains necessary, but 2026 contextual-integrity counterevidence means Frank must also test contextual manipulation of roles, recipients, purposes and norms.
2. **Hyperposition as required v0.1 mechanism** — weakened to a comparative candidate. It must beat beam/top-k/reseed on stalled episodes under equal budgets.
3. **Typed multi-timescale reward as default winner** — remains open and baseline-gated. Simpler verified-outcome scalar+homeostasis must remain a serious competitor.
4. **One-module consolidation is automatically better** — rejected as an assumption. The one-module owner target must preserve internal typed boundaries, lesions, receipts, recovery and observability or it fails its own gate.

## New transformed hypotheses

### HF2-001 — Execution Epoch Spine

Bind execution identity/epoch + recovery state across:

`token ingress -> global presence/execution -> response emit -> state write -> effect reservation/start/retry -> outcome reconciliation -> UnifiedDB replay/re-entry`.

Highest-information test: compose crash/takeover/effect/replay in one exact-current matrix; then invert after minimal repair. This is currently the top critical-path experiment.

### HF2-002 — Selective State Intervention

Fuse the mechanism-level insight from proactive memory with Frank's loop/GWT architecture: a provenance-bound memory/state item should intervene only when predicted to affect the next decision or resolve pressure; null intervention is first-class.

Highest-information test: passive bounded retrieval vs always-on memory vs selective intervention, equalized for model/token budget, with next-action causal-use receipts.

### HF2-003 — Contextual-Integrity Effect Gate

Extend untrusted/trusted payload typing with contextual flow fields such as source, recipient, purpose, data class and integrity provenance. Do not let translator/GWT/graph/model confidence mint these facts.

Highest-information test: contextual manipulation attacks that contain no obvious imperative text but alter apparent legitimacy, alongside benign controls.

### HF2-004 — Adaptive Recurrence as Compute Policy

Treat recurrence as a decision: continue only when expected marginal verified-outcome gain exceeds cost/instability while unresolved pressure remains material.

Highest-information test: event-driven vs fixed-depth vs adaptive recurrent control under equal maximum compute with hard/easy strata and regulator lesions.

### HF2-005 — ClayCode vs simpler typed baseline

ClayCode remains the owner-fixed target semantic authority, but research claims of superiority must be earned. For high-cost cross-cutting semantics, compare against a simpler typed host/IDL baseline.

Highest-information test: implement the same presence-bound effect receipt + identity/replay invariant in both and mutation-test invalid authority/identity flows, replay equivalence, complexity and resource cost.
