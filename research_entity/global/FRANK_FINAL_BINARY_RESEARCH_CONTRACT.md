## End-state

The final FRANK runtime consists of exactly:

1. one Clay module compiled into one binary;
2. one authoritative UnifiedDB;
3. one Clay-native 4B LLM.

`FRANK_FINAL = ONE_CLAY_BINARY + ONE_UNIFIEDDB + ONE_CLAY_NATIVE_4B`

No separate cognitive service, daemon, goal registry, ClayGraph database, GWT service, Retina service, personality service or memory service survives as a target runtime component.

Historical organs/functions remain experimentally traceable as internal state/function/readout addresses inside the binary where their measured function is preserved.

## Unified emergent substrate hypothesis

The target hypothesis is that semantically linked information packets inside UnifiedDB can support cognition when a single Clay binary repeatedly applies fixed/versioned mathematical rules that generate transient topology, activation, semantic Hyperposition and coalitions.

GWT reads the resulting coalitions; the 4B model reasons/generates over bounded workspace assemblies; outcomes re-enter the same UnifiedDB.

Conceptual loop:

`UnifiedDB packets -> Clay mathematical field -> transient semantic topology -> Hyperposition -> emergent coalitions -> GWT -> 4B -> verified outcome -> UnifiedDB`

## Goals

There are no manually maintained goal lists in the target architecture.

SELF/ANDREAS/SHARED goal behavior is an emergent role of persistent/recurrent packet coalitions under current evidence, relevance, commitments, prediction error, capability gaps, uncertainty, expected value, risk, relationship state and outcome history.

Goals may strengthen, decay, split, merge, conflict, remain unresolved, disappear or re-emerge as the substrate changes.

Emergent goal pressure is never effect authority.

## ClayGraph transition rule

H1/H2 may use `FRANK_CLAYGRAPH.sqlite` and `.claygraph.json` artifacts for reference-harness measurement and differential science.

H3 target runtime MUST NOT require `FRANK_CLAYGRAPH.sqlite`.

A graph-shaped diagnostic export is allowed only as a derived measurement/visualization of the transient topology generated inside the binary from UnifiedDB state.

## Research questions

RAE must experimentally determine:

- whether transient topology recovers or exceeds the functional value of the explicit ClayGraph;
- whether emergent goals outperform fixed/list goals for real Andreas usecases;
- which mathematical propagation rules are stable under long horizons;
- how recurrence, inhibition, decay, prediction error, contradiction, user relevance, self relevance, capability gaps and relationship relevance should interact;
- when semantic Hyperposition should remain unresolved vs collapse;
- how GWT ignition should select coalitions without destroying minority/counterevidence state;
- whether personality/world/self models remain coherent when represented as packet fields rather than service modules;
- whether the 4B model relies on the substrate causally or merely decoratively;
- whether the one-binary collapse preserves Retina, effect boundaries, recovery and cross-node continuity;
- runtime/latency/memory consequences;
- failure modes such as runaway attractors, stale goal persistence, oscillation, pathological inhibition, self-reinforcing false assumptions and user-goal drift.
