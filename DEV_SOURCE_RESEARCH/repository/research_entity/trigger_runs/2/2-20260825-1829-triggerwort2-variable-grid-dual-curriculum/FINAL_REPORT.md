`DO_NOT_REDUCE_ENTIRE_ZERO_ENTITYOS_COGNITION_TO_THREE_CLASS_BINDING`

1. **Lane A — Binding micro-skill**: causal S3 episode-local codebook remapping, strict anti-leak controls, exact ABI/tokenizer materialization gate.
2. **Lane B — Cognitive-process trajectories**: structured Zero/EntityOS process transitions derived from the current census and owner architecture.
3. **Lane C — Selective composition**: overlay dynamic binding only where a cognitive process naturally contains a local routing/admission decision; score process semantics and binding separately.

No fixed binder/trajectory token mixture is claimed. The ratio should be selected only after frozen zero-cost local baseline/pilot evidence measures gain, interference and retention.
