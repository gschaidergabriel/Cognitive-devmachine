# CC9 Hypotheses — Certified Basis & Compositional Closure

All hypotheses are OPEN unless explicitly falsified in this run. Numeric current evidence is synthetic/runtime-proxy unless stated otherwise.

1. **H-CC9-001 — Typed causal basis.** Operations spanning exact state, CognitiveFrame, ClayGraph semantic epoch and activation epoch require an operation-specific typed basis certificate; independently reading each latest value can create a semantically torn combination. **Falsifier:** live/twin FRANK shows no incompatible combinations or one atomic snapshot handle fully determines all relevant dimensions.
2. **H-CC9-002 — Compatibility is operation-specific.** Requiring equality of every epoch is unnecessarily conservative; only dimensions in the trusted operation semantics should participate, with typed policies such as EXACT, causal ancestor/descendant or validated lineage. **Falsifier:** global tuple equality dominates on correctness and cost across target operations.
3. **H-CC9-003 — Transitive closure is mandatory.** Trusted dependency/effect summaries must include transitive callees, not only the root operation. **Falsifier:** root-direct summaries show zero escapes under full runtime interposition on representative operations.
4. **H-CC9-004 — Finite dynamic dispatch uses set closure.** When the runtime/compiler can conservatively enumerate all possible targets, closure over their union is safer than trusting one predicted target. **Falsifier:** complete-target union still misses observed accesses without an unmodeled channel.
5. **H-CC9-005 — Unknown dispatch maps to TOP/escalation.** Reflection, unrestricted FFI, plugin lookup or runtime code generation without a closed target set must broaden or reject rather than claim selective closure. **Falsifier:** an independent sound analysis proves a tighter finite closure for those cases.
6. **H-CC9-006 — Canonical resource identity precedes authority/conflict reasoning.** Aliases/symlinks/handles/logical IDs must normalize to an authority-relevant resource identity before comparison. **Falsifier:** raw symbolic identity yields equivalent conflict/capability safety on an alias-rich target corpus.
7. **H-CC9-007 — Predicate/invariant/volatile witnesses survive CC8.** Object/resource closure is still insufficient for negative predicates, n-ary invariants and temporal/environment inputs. **Falsifier:** target operation registry demonstrates those classes are absent or fully reducible to canonical resource versions.
8. **H-CC9-008 — Projection receipt.** Every model-facing ClayCode projection should bind semantic hash + projection-schema/dictionary hash + projection/wire hash so transport success cannot masquerade as semantic reconstruction. **Falsifier:** target reader and migration tests show no semantic ambiguity or dictionary drift without the extra receipt.
9. **H-CC9-009 — Compiled reader surface beats raw safety reasoning on small models.** High-stakes freshness/authority decisions should be deterministically precompiled, leaving the model to consume/relay bounded semantic facts. **Falsifier:** pinned Qwen3-4B raw-semantic arm equals or beats compiled arm on exactness, unsafe accept rate, tokens and repair cost.
10. **H-CC9-010 — Reader compactness and authority are separate optimization targets.** A compact projection may be used for cognition even when its reader is forbidden from making authority decisions. **Falsifier:** enforcing this separation causes unacceptable target quality/latency with no safety benefit.
11. **H-CC9-011 — ClayGraph activation is a basis/projection input, not truth.** `activation_epoch_id` may affect Assembly selection but cannot replace exact/provenance state or grant GWT/effect authority. **Falsifier:** target causal tests show activation alone is the canonical source of factual/effect state without inconsistency.
12. **H-CC9-012 — Closure width is a first-class cost shadow.** Conservative compositional analysis becomes less selective as dynamic target sets/aliases grow; the runtime should measure closure width and escalate/restructure hot paths rather than hide the cost. **Falsifier:** width is uncorrelated with validation/coordination cost on target workloads.
13. **H-CC9-013 — Self-hosting requires closure equivalence.** A Clay-written compiler/runtime is acceptable only if its derived basis/effect closure is semantically equivalent to the minimal trusted bootstrap implementation on a conformance corpus. **Falsifier:** independent bootstrap paths cannot agree reproducibly, or a smaller external verifier cannot check equivalence.
14. **H-CC9-014 — FRANK config is not ClayCode semantics.** Workspace channel count, ignition thresholds and device/backend parameters belong to versioned FRANK data/config unless independent evidence makes them language invariants. **Falsifier:** cross-version semantic necessity is demonstrated.
15. **H-CC9-015 — Causal basis can subsume snapshot identity without deleting state_root.** `state_root` remains immutable snapshot/provenance identity; the basis certificate determines which additional epochs/witnesses are required for an operation. **Falsifier:** additional witnesses never change accept/reject or reconstruction decisions on target traces.
16. **H-CC9-016 — Qwen3-4B remains decisive.** Groq 8B results only determine proxy hypotheses; reader-surface promotion requires a pinned Qwen3-4B factorial with exact tokenizer, OOD schemas, unknown/conflict/revoked states and zero-authority test cases.
