### Core
On an actual hosted 4B model, changing only the operation representation from raw multidimensional state to a deterministic compiled view changed basis-decision accuracy from 4/12 to 11/12. A separate shuffled relevance-prior arm also strongly altered downstream output while facts remained present.

### Evidence / boundary
These are reader-surface effects. They do not measure workspace selection, ignition, broadcast, internal uptake or re-entry.

### Implication
CSOC's rule is strengthened: representation/projection and graph prior must be pinned or independently manipulated before attributing behavior to GWT selection.

### Next test
Live projection-mediation factorial with semantic WorkspaceEpisode fixed and an independent uptake/effect receipt.
