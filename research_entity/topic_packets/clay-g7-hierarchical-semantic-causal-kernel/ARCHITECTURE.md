## Design rules

1. `M_delta` is a heterogeneous change-amplification model. Its spectral radius is a control diagnostic, never an emergence label.
2. The governor is hierarchical, not a monolithic scalar: hard/fast constraints can override slower semantic optimization; switching/chatter/recovery debt are explicit costs.
3. Coordination is paid only for authority/invariant dependencies actually requiring it. Pair/path-sensitive plans are allowed only with verified dependency coverage; unknown coverage fails closed.
4. Canonical event truth remains exact. Summaries, hot projections, KV-like representations and materialized arrangements are rebuildable derived states at different resolutions.
5. Gamma is state-rooted but cache invalidation is dependency-scoped. Semantic constraints cannot create capabilities.
6. Workspace evidence is a causal/intervention vector; no single marker and no self-report implies phenomenal consciousness.
7. Physical backends may differ by facet/device as long as semantic identity, receipts, provenance and replay contracts remain stable.
8. Edge inference is governed by sustained task utility, energy, latency, thermal state, memory and acceptance; peak tok/s is only a shadow metric.

Cross-cutting objective: **pay resolution, coordination and compute in proportion to causal necessity while preserving exact reconstructibility and external authority.**
