# KMP — Android Secondary Arm / Bidirectional Mesh Routing

**Status:** CURRENT PROJECT-OWNER ROUTING DIRECTIVE  
**Ancestry:** `ANDROID_SECONDARY_RESEARCH_ARM_CONTRACT.md`  
**Evidence:** governance/routing contract; not empirical support for Android feasibility

## Compact rule

FRANK remains Linux-primary. Android is a permanent secondary cross-cutting research arm used for edge feasibility and constrained-environment efficiency research.

Android MUST retrieve the complete current scientific mesh before research and MUST emit durable deltas back to all materially affected branches.

Affected/retrieval branches:
- clay
- frank
- gwt
- emergenz
- claycode
- hyperposition
- claygraph
- unifieddb

Because this packet explicitly names all authoritative branches and is stored in the shared Knowledge Micro-Packet corpus, normal branch preflights can retrieve the Android routing rule without adding Android as a ninth peer branch.

## Routing semantics

Android-specific device/API/thermal/vendor findings remain `ANDROID_LOCAL` unless they constrain another branch.

Generalizable efficiency findings become `GENERALIZABLE_CANDIDATE` and are routed to affected branches, for example:
- Clay/ClayCode representation density, parser/lowering/serialization cost -> clay, claycode, frank;
- model/context/KV/quantization/runtime cost -> frank, clay, claycode;
- candidate/broadcast/projection/re-entry cost -> gwt, clay, frank;
- graph activation/Assembly/traversal cost -> claygraph, clay, gwt;
- query/replay/storage/write amplification -> unifieddb, claygraph, frank;
- topology/process/IPC placement -> hyperposition, frank;
- causal/emergence instrumentation -> emergenz, gwt;
- authority/safe-effect failures -> clay, frank, claycode, hyperposition.

Cross-branch reuse preserves Android experiment ancestry and is not independent replication.

## Required Android feedback receipt

Every full Android run produces `BRANCH_FEEDBACK_MANIFEST.json` with a material delta or explicit `NO_CHANGE` for each of the eight branches. Material deltas are compiled into normal branch-addressed packets so later branch runs ingest them automatically.
