# FUSION 1 — current problem surface for IAC-001

## Current organism

Frank v0.1 is converging toward one executable loop-core, not a fleet of cognitive microservices. The owner-fixed loop-of-loops contract already requires adaptive recurrence: continue only while another recurrence has positive expected marginal utility under cost, instability and unresolved-pressure constraints. It explicitly distinguishes convergence, productive cycles, stall and overthinking.

The current mesh is simultaneously closing storage, execution identity, effect authority, V17 causal support, token transport, translator hard-fields and ClayCode lowering. Those lanes make this a poor moment to invent another authority, database or terminal-state mechanism.

## Fresh gap

The recurrence controller has a conceptual quantity — marginal utility of another recurrence — but not yet a cheap exact **sufficient** condition for zero decision value. Current generic signals can all be misleading:

- low state delta can mean convergence or stagnation;
- high epistemic uncertainty can remain after the correct action is already invariant;
- high action confidence can hide a low-mass but materially different action branch;
- one-step value-of-computation can miss multi-step information synergy;
- fixed budgets waste work on easy action-invariant cases and stop too early on difficult cases.

The selected question is therefore narrower than generic metareasoning:

> Given the **currently represented, coverage-certified Hyperposition alternatives** and the **current decision/effect semantic mapping**, can any live alternative still change the immediate action semantic key?

If no, an additional recurrence has zero *branch-discriminating* value for the immediate action even though epistemic uncertainty remains. That is a sufficient stop condition, not a claim that the agent knows the world state or that no future evidence could matter.

## Safety boundary

The condition is invalid if branch coverage is incomplete/unknown, if the decision/effect mapping epoch changed, or if the action key omits material target/scope/effect-class/confirmation differences. It never mints effect authority. The normal deterministic effect gate still decides ALLOW/CONFIRM/DENY/PROPOSAL.

## Strongest baseline before invention

The strongest baseline is ordinary rational metareasoning/value-of-computation plus the existing loop-dynamics controller. A second deliberately simple baseline is even harsher: project each live branch to an ordinary action-semantic key and test whether the resulting set has cardinality one. If that reproduces IAC exactly, IAC is not a distinct runtime architecture.
