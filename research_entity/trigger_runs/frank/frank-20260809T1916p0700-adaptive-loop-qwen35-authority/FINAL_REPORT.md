## 3. External primary-source research

### 3.1 Recurrent depth

Primary preprints:

- Kohli et al., `arXiv:2604.07822`, *Loop, Think, & Generalize* — recurrent depth can extend compositional reasoning depth in controlled experiments, but excessive recurrence causes overthinking and prediction degradation.
- Oncescu et al., `arXiv:2604.21215`, *The Recurrent Transformer* — recurrent memory/depth can improve parameter-matched language modeling in the tested 150M/300M regimes and trade depth/width while preserving autoregressive decoding structure.

Interpretation for FRANK: recurrence is a plausible compute mechanism, but useful recurrence depth is task/state dependent. This supports retaining separate typed residual pressure, marginal-utility, budget and overthinking observables rather than equating more loops with better cognition.

### 3.2 Current Qwen-class 4B candidate

Official Qwen sources checked 2026-08-09:

- `QwenLM/Qwen3.6` lists Qwen3.6 releases at 35B-A3B and 27B, while the small March release remains Qwen3.5 9B/4B/2B/0.8B.
- `Qwen/Qwen3.5-4B` is a post-trained 4B causal language model with a Vision Encoder, 32 language layers, and an `8 x (3 x Gated DeltaNet + 1 x Gated Attention)` hidden layout; the official model card exposes image-text use.

This does **not** promote Qwen3.5-4B as the final Clay-native model. It makes it the current high-information candidate to benchmark against the previous Qwen-class assumption.

New leverage: because it is already multimodal, its visual representation may be reusable as one candidate frozen feature source for the mandatory user-adaptive Micro Visual Classifier. The competing hypothesis is that using the whole 4B visual path on a frequent visual heartbeat is too expensive and a dedicated cheap backbone remains superior.

### 3.3 One deployable binary vs security authority

Primary runtime/kernel sources:

- Wasmtime/Component Model denies component system-resource access by default and exposes typed imports supplied by the host.
- WASI 0.3 (ratified 2026-06-11) gives the host runtime native async scheduling across components. Toolchain support is still landing, so this should not automatically become a v0.1 release dependency.
- Linux Landlock provides additive unprivileged access-control restrictions; seccomp-bpf reduces syscall surface but kernel documentation explicitly warns seccomp alone is not a complete sandbox.

Architecture implication: `ONE_BINARY` does not logically require `ONE_AUTHORITY_DOMAIN` or even `ONE_PROCESS`.

Three H3 realization candidates should be compared without changing the owner-fixed one-binary target:

A. memory-safe in-process capability gateway;
B. embedded Wasm component guest with host-owned effect imports;
C. the **same Frank executable** self-spawned in a restricted `effect-broker` mode, preserving one deployable binary file while creating a process/OS sandbox boundary.

Candidate C is an inference/new hypothesis, not an owner-fixed interpretation. It is rejected if the one-binary contract is later adjudicated to require one process, or if latency/recovery complexity outweighs its isolation value.

## 4. Executed discriminator A — overlapping-regime synthetic ablation

A fixed-seed synthetic Monte Carlo generated 200,000 readouts: 50,000 each for CONVERGED, STALLED, PRODUCTIVE_CYCLE and OVERTHINKING, with overlapping noisy feature distributions.

Controller A used only `state_delta < threshold -> HALT`, otherwise continue.

Controller B used the typed architecture candidate: state delta + residual pressure + marginal utility vs recurrence cost + recurrence budget + overthinking signal.

Results:

- CONVERGED correct: A 99.006%, B 97.920%
- STALLED correct: A 1.020%, B 100.000%
- PRODUCTIVE_CYCLE correct: A 99.798%, B 94.904%
- OVERTHINKING correct: A 0.000%, B 99.788%
- macro average correct: A **49.956%**, B **98.153%**
- critical failure: delta-only controller falsely halted **98.980%** of constructed stalled cases.

Evidence class: `SYNTHETIC_CONSTRUCTED_DISCRIMINATOR` only. The distributions and target labels encode the intended regime definitions, so this is not empirical proof that live FRANK has those distributions. It demonstrates that state-delta-only stopping is structurally incapable of distinguishing low-change convergence from low-change unresolved stall when those states overlap in delta.

### H-FRANK-VISION-008 — model-native vision features may collapse duplicate feature work

OPEN. Qwen3.5-4B vision features may serve as one Micro Visual Classifier backbone candidate, reducing redundant representation work while preserving a fast familiarity/open-set path.

Counterhypothesis: invoking or extracting those features is too expensive/unstable for the normal visual heartbeat; a small dedicated frozen encoder wins on MVC-E1/E2/E5/E6/E7.

### H-FRANK-AUTH-009 — one binary can preserve an independent effect boundary

OPEN. The owner-fixed one-binary target can retain nonambient effect authority using either embedded component sandboxing or a same-executable restricted broker process, without restoring a separate cognitive daemon/service.

Counterhypothesis: same-binary multi-process or embedded Wasm introduces unacceptable latency/complexity/recovery cost, or one-process memory-safe capability handles are already sufficient.

### H-FRANK-GRAPH-010 — current V7 persistent ClayGraph is a migration oracle, not H3 necessity

OPEN realization claim under fixed final-binary contract. V7 `FRANK_CLAYGRAPH.sqlite` should be used to generate regression/differential fixtures for graph-shaped behavior while H3 derives equivalent transient topology from UnifiedDB and emits diagnostic exports only.

Falsifier: matched H1/H2/H3 benchmark shows that persistent separate graph materialization is necessary for required latency/replay/causal behavior and cannot be achieved as derived/rebuildable topology within the target contract without unacceptable loss.

## 7. Preserved counterhypotheses / negative evidence

- H0-A: ordinary event-driven orchestration may reproduce useful behavior without recurrent-model mathematics.
- H0-B: a single global stability controller may damage heterogeneous timescales; local typed controllers may be required.
- H0-C: historical neuro-inspired Thalamus/NAcc/Amygdala variables may remain descriptive rather than causally useful.
- H0-D: Jacobian/spectral diagnostics may predict numerical stability but not cognitive usefulness.
- H0-E: apparent cycles may be timing artifacts rather than useful causal recurrence.
- The new synthetic discriminator is constructed and cannot promote a live FRANK claim.
- 8 local unit tests do not establish target-Ubuntu runtime behavior, integration or performance.
- Qwen3.5-4B official benchmark/model-card evidence does not establish local FRANK superiority.
- Native multimodality does not eliminate Digital Retina provenance, open-set routing, adaptive visual learning or effect-authority requirements.
- WASI/Wasmtime is evidence for a realizable capability architecture, not a mandated ClayCode backend; WASI 0.3 tooling maturity is still evolving.
- The actual Frank repo remains a valuable lineage/regression source but its V7 process/storage structure is not the current H1 target architecture.
