## Four topologies must remain distinct

1. semantic topology;
2. active propagation topology;
3. coordination/invariant topology;
4. physical execution topology.

Hard distinctions:

`semantic_colocation != physical_colocation`

`shared_state != shared_authority`

`graph_connectivity != causal_use`

`low_latency != semantic_equivalence`

## ClayGraph — mandatory topology/substrate input

Every run deeply inspects current ClayGraph architecture, accepted/candidate graph versions, dynamic Harness graphs, relation/activation semantics, self-use benchmarks and negative results.

Research explicitly:

- pairwise edges vs relation nodes vs n-ary/hyperedge representation;
- contextual alternatives coexisting without destructive collapse;
- UNKNOWN/CONFLICT/REVOKED/stale propagation;
- spreading activation preserving vs destroying higher-order structure;
- incremental invalidation vs cascading recomputation;
- semantic vs active vs coordination vs physical topology;
- locality/cache layout vs semantic benefit;
- cases where isolation is safer than unification;
- Harness graph interventions that expose real causal dependence.

A result changing graph assumptions must be written back to ClayGraph. Agreement alone is not independent evidence.

## UnifiedDB — mandatory persistence/query/transaction input

Inspect current UnifiedDB store roles, query/selection identity, collection semantics, consistency/transaction boundaries, replay/derived views and placement experiments.

Research:

## Higher-order irreducibility

For each claimed higher-order relation, compare the full representation against the best pairwise/state-machine reduction under matched information/input conditions.

Measure where feasible:

- prediction loss;
- intervention-response mismatch;
- state/replay divergence;
- synergy difference;
- causal effect difference;
- workspace/selection difference;
- runtime cost difference.

A hyperedge/higher-order primitive is justified only when it preserves or exposes semantics/coupling that simpler forms lose or distort.

## Primary research questions

- How should mutually context-dependent states coexist without destructive collapse?
- Which higher-order relations truly require n-ary representation?
- Can explicit dependency structure support only-causally-affected recomputation?
- Can active topology/assemblies replace repeated serialization/retrieval/reconstruction?
- Which physical boundaries can approach near-zero software overhead without losing semantic/authority distinctions?
- Where does tighter coupling increase contention, cascading failure, noise or recovery cost?
- Which mechanisms improve real FRANK/ClayGraph/UnifiedDB paths rather than only synthetic benchmarks?
- Which observed macro effects survive lesions, null models and implementation changes?

## Scientific boundary

Higher-order coupling, irreducibility, topology effects and functional emergence are system-level evidence only. They do not by themselves establish phenomenal consciousness.
