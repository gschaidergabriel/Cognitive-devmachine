## New highest-information finding

`R2_B11_CROSS_TASK_GATE_IS_NOT_RUNTIME_EVIDENCE_AUTHENTICATOR`

The v2 cross-task gate can adjudicate caller-supplied numerical attestations but does not itself cryptographically bind those numbers to exact model execution receipts, exact prompt bytes, exact vector/cvec bytes, exact challenge row identities, or exact runtime-produced control observations.

Observed source discriminators:

- Search of current repository source for `runtime_receipt_sha256` scoped to `trigger1_cross_task_abstract_control_gate_v2` returned no binding field.
- The gate accepts `basis_family_directions[*].direction` as arbitrary finite vectors of length >= 3. It does not enforce Qwen3-0.6B hidden dimension 1024.
- `primary_settings` checks claimed GGUF hash, llama.cpp commit, gain, layer and token scope strings, but those claims are not tied to a runtime receipt in this gate.
- `geometry_permutation_null` accepts caller-supplied q95 thresholds plus a provenance boolean; the gate does not reconstruct the null from immutable permutation rows.
- causal rows accept caller-supplied `target_margin`, token counts, topology IDs, demo IDs and control labels without per-row runtime-receipt hashes.
- task-grammar/family distinctness is enforced by string IDs, not by byte-derived prompt/grammar signatures.
- geometry directions are not cryptographically bound to the exact cvec/vector bytes applied in causal rows.

Consequently, a synthetically constructed JSON object can in principle satisfy the static predicates without being evidence that Qwen3-0.6B actually produced the claimed measurements. This does **not** make the gate useless: it remains a valuable schema/policy validator. It means its PASS must be named `STATIC_ATTESTATION_CONSISTENCY_PASS` until a producer/binder proves the evidence chain.

## New causal-identification finding

`R2_B12_MATCHED_ONLY_ROWS_DO_NOT_ESTABLISH_FULL_INTERVENTION_X_STATE_SPECIFICITY`

The v2 causal schema has `vector_state_id` and `requested_code`, but no independent evaluator/probe-state identity that forces every state vector to be tested against every evaluator state under identical target-blind prompt conditions.

This leaves an important counterhypothesis alive:

> A generic direction that increases classification confidence or codebook separability across all states could improve each matched row when the caller labels each row with the intended `vector_state_id`, without proving that S0, S1 and S2 interventions selectively move the model toward distinct internal states.

Promotion-grade evidence should therefore bind an explicit matrix:

`INTERVENTION_STATE_3 x EVALUATOR_STATE_3 x OUTPUT_CODE_3 x POLARITY_2 x TASK_FAMILY x REPLICATE`

with target-blind model-facing bytes wherever possible. Required matrix properties:

- diagonal intervention effects positive and above null in every state/family/polarity stratum;
- off-diagonal effects lower than the corresponding diagonal effect under a preregistered margin/equivalence criterion;
- rank-1 case: signed-coordinate ordering/reversal must be coherent across all three states;
- rank-2 case: state-to-state displacement must follow the admitted simplex/subspace coordinates; a single sign flip is not treated as the universal semantic opposite;
- identical vector hashes for distinct state IDs are forbidden unless the admitted rank model explicitly proves equivalence;
- the exact vectors used in the matrix must be the vectors whose geometry was admitted.

## Two-stage external research fusion

### Steering reliability / causal representation literature

- Braun et al. (2025), *Understanding (Un)Reliability of Steering Vectors in Language Models*, reports large per-sample variance and prompt-type dependence, while higher directional coherence predicts more reliable steering. This supports treating cross-family geometric coherence and prompt/task structure as causal nuisance tests rather than cosmetic controls.
- Geiger et al. (2021), *Causal Abstractions of Neural Networks*, formalizes representation claims around interventions that verify causal properties of aligned internal variables. This supports requiring intervention-state specificity, not only readout separability or matched margin shifts.
- Arjovsky et al. (2019), *Invariant Risk Minimization*, motivates searching for mechanisms stable across distinct environments rather than trusting one training/task environment. Here task grammars/families are useful scientific environments, not independent evidence unless runtime ancestry is also independent.

### Cross-topic geometry / context fusion

- Hu, Niu & Varma (2026), *Language Models Represent and Transform Concepts with Shared Geometry*, argues that context transforms concept geometry rather than leaving a single stationary object. This makes `context-invariant global vector` a stronger claim than current evidence supports and motivates environment-conditioned geometry tests.
- Official Qwen3-0.6B config reports hidden size 1024 and 28 transformer layers. A Qwen-specific evidence validator should bind those dimensions/identities rather than accept arbitrary >=3-dimensional vectors.

External literature informs method only. It grants zero Clay/Qwen runtime credit.

## Single-module implementation concept for later ClayCode translation

### Module name

`JSPACE_CAUSAL_EVIDENCE_CAPSULE_GATE`

### Purpose

One module, not a new subsystem family. It composes the useful current successor primitives into one fail-closed evidence capsule that answers a single question:

> Do immutable model-facing bytes, exact executed runtime receipts, exact state-vector bytes and cross-environment causal measurements jointly support a bounded Qwen3-0.6B abstract native-control component candidate?

### Inputs

1. authority + source head identity;
2. exact Qwen GGUF/tokenizer/llama.cpp consumed identity;
3. frozen challenge bundle with byte-derived task-family/grammar signatures;
4. calibration basis/subspace receipt;
5. rank verdict and admitted orthonormal coordinates;
6. exact nuisance basis + rank receipt;
7. exact cvec/vector bytes and hashes per state/control;
8. per-row runtime receipts for every intervention/control;
9. full intervention-state x evaluator-state matrix rows;
10. off-target rows and frozen uncertainty/null protocol.

### Internal phases

1. `AUTHENTICATE`: recompute hashes; reject caller-only booleans where derivation is possible.
2. `BIND_MODEL`: enforce exact GGUF/tokenizer/runtime/build identity and Qwen hidden dimension 1024.
3. `BIND_PROMPTS`: derive prompt bytes, task grammar signatures, lexical/position/proof-topology signatures and family ancestry from actual strings/tokens.
4. `BIND_GEOMETRY`: bind state vectors/subspace coordinates to exact cvec bytes used in runtime; preserve rank-1 vs rank-2 semantics.
5. `BIND_NUISANCE`: require causal coverage of every admitted nuisance axis or exact proof of rank 1.
6. `CAUSAL_MATRIX`: require all intervention-state x evaluator-state pairs, factorialized against code/polarity/family/replicate.
7. `COUNTERFACTUAL_CONTROLS`: NULL, sign reversal/displacement, orthogonal, permuted, all nuisance axes, generic compliance and off-target tasks.
8. `STATISTICS`: frozen family-level permutation/equivalence bounds; no pooled average may hide a failing state/family/polarity cell.
9. `ADJUDICATE`: output bounded component candidate only; never mint canonical semantics/HCU/EntityOS/training credit.

### Required fail-closed invariants

- no runtime receipt -> fail;
- receipt does not bind exact prompt bytes -> fail;
- vector dimension != 1024 for pinned Qwen3-0.6B -> fail;
- vector hash not identical between admitted geometry and applied cvec -> fail;
- task-family/grammar distinctness asserted only by caller strings -> fail;
- missing intervention x evaluator-state off-diagonal -> fail;
- nuisance rank exceeds causally tested nuisance-axis count -> fail;
- any required family/state/polarity diagonal effect fails -> fail;
- any preregistered sign/displacement reversal fails -> fail;
- off-target equivalence fails -> fail;
- exact source/runtime ancestry ambiguous -> fail;
- static gate PASS without authenticated producer evidence -> `STATIC_ONLY`, never runtime credit.
