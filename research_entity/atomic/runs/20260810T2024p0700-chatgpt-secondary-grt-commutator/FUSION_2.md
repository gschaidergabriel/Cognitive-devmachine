# FUSION 2 — external collision + live-repo recombination

## What collapsed
- `H1-CAUSAL-SHADOW` is weakened: counterfactual/twin reasoning is established, and the live UnifiedDB lane already contains a twin-GWT challenger designed to reduce to a simpler control when it does not earn distinct mechanism value.
- `H1-PERCEPT-TRANSITION-FIRST` is not selected because q23 is already actively exploring a Visual State Transition Graph with alias controls. Duplicating it would violate swarm collision avoidance.
- `H1-COMP-DELTA-BASIS`, `H1-AGENCY-WAVEFRONT`, and `H1-LANG-EFFECT-ALGEBRA` remain useful but their core mechanisms are closer to known delta encoding, event indexing, and effect-system work.
- `H1-ALIEN-SYMPLECTIC` remains speculative and currently lacks a cheaper discriminator tied to the BASE critical path.

## What strengthened
The live WP03 typed-IR bridge introduced an explicit distinction between semantic identity and epoch/version-bound runtime state identity. This is exactly the missing safety condition for state-dependent commutativity: a commutation result must be bound to one state instance/epoch and must never be reused as timeless truth.

External prior art strengthens the feasibility of semantic commutativity as a compiler/runtime concept while simultaneously collapsing any claim that commutativity itself is novel. This redirects novelty pressure toward **topology formation** rather than the primitive test.

## Selected candidate
**Causal Commutator Fabric (CCF)**

CCF treats eligible pure deterministic ClayCode transitions as local state operators. For each potentially dependent pair at the current epoch, it compares the two local compositions. A non-zero semantic commutator creates an interaction edge. Connected components of noncommuting edges become temporary coordination cells. Commuting regions need no permanent global workspace merely because they coexist.

This is a GRT-level architecture proposal: fixed GWT is not assumed as the outer architecture. GWT can remain a fallback/derived coordination geometry for opaque, stochastic, model-mediated, cross-resource, or globally coupled components where exact commutation cannot be established.

## Strongest counterhypothesis after Fusion 2
CCF is semantic conflict analysis plus a dynamic dependency graph. Its apparent cognitive novelty may disappear under a good compiler scheduler. Pairwise interaction tests may scale badly, and real Frank transitions are frequently opaque/stochastic enough that the eligible subset is too small to matter.

## Discriminator
A first proxy therefore tests only the narrow claim CCF must earn before any architectural discussion: for typed deterministic local transitions, can sparse semantic commutation recover full replay's order-sensitivity exactly while exposing materially more safe independence than conservative read/write conflict analysis at much lower cost than whole-state replay?

No target/runtime/cognitive superiority claim is permitted from this proxy.
