## 1. Research question

What should a scientifically defensible **Generative Reality Framework** mean inside Frank, when fused with current ClayCode, UnifiedDB, ClayGraph, Hyperposition, GWT, loop-of-loops, Digital Retina, proactive agency, reward/re-entry, effect authority, uncertainty and recovery requirements?

The answer developed here is explicitly **engineering**, not metaphysical and not quantum-mechanical.

The term `Generative Reality Framework` is not a stable scientific standard. Current web usage is heterogeneous: speculative quantum/cosmology proposals, AI-safety branding, interactive-video/XR world simulation and broader generative-world-model work all use nearby language. Therefore this project must bind the term locally and precisely.

## 2. Core conclusion

`C-GRF` should be a **typed, uncertainty-aware, intervention-capable possible-world substrate inside the existing self.root loop-core**, not a second autonomous cognitive architecture and not a single giant visual simulator.

Compact law:

```text
verified observation
-> epistemically typed current belief state
-> task-conditioned possible-world generation
-> Hyperposition-preserved alternative branches
-> causal/constraint/uncertainty checks
-> GWT selective recruitment
-> plan/effect proposal
-> deterministic authority boundary
-> real outcome verification
-> prediction-vs-outcome reconciliation
-> causal credit / model update / reward update
-> provenance-bound re-entry
```

The generated branches are **not reality**. They are controlled hypotheses about reality.

## 3. Why this follows from current Clay research

Current Clay already fixes most of the required boundary conditions:

- UnifiedDB is canonical semantic state and provenance plane.
- ClayGraph is derived active topology, never truth or authority.
- Hyperposition preserves unresolved alternatives and higher-order relations without pretending to be quantum physics.
- GWT must expose candidate -> selection -> broadcast -> reconstruction -> use -> effect -> outcome -> re-entry.
- Frank is one hierarchical multiscale loop-of-loops.
- reward/state plasticity is downstream of verified outcome and causal credit.
- model/Needle/GWT output is not effect authority.
- open-web content is untrusted evidence, not instruction authority.
- generated/synthetic evidence may never silently promote itself into live truth.

C-GRF is therefore best understood as the missing explicit **prospection/counterfactual/reality-branch semantics** that connects the already-existing world-state, Hyperposition, GWT and outcome-reconciliation machinery.

## 4. External research synthesis

### 4.1 Task-sufficient world models beat naive reconstruction as a universal objective

MuZero demonstrates that a planning-useful learned model need not reconstruct the complete environment; it can learn quantities sufficient for planning (reward/value/policy). Dreamer-family systems similarly learn behavior through latent imagined futures. V-JEPA 2 predicts in semantic embedding space and demonstrates action-conditioned planning after limited interaction data. ICML 2024 work on robust world-model representations shows that filtering task-irrelevant visual variation can improve model-based RL.

**C-GRF implication:** fidelity is conditional on causal/task relevance. Do not spend Frank v0.1 resources rendering irrelevant sensory detail when a semantic/causal latent is sufficient.

Primary references:
- Schrittwieser et al., Nature 2020, MuZero, DOI 10.1038/s41586-020-03051-4.
- Hafner et al., DreamerV3, arXiv:2301.04104.
- Meta, V-JEPA 2, 2025, https://ai.meta.com/research/publications/v-jepa-2-self-supervised-video-models-enable-understanding-prediction-and-planning/
- Sun et al., ICML 2024, PMLR 235:47234-47260.

### 4.2 Plausible generation is not coherent world modeling

Vafa et al. show that generative models can pass familiar diagnostics while failing stronger world-model coherence tests; subtle task transformations reveal fragile underlying transition structure.

**C-GRF implication:** narrative plausibility, probe decodability and visual realism are insufficient. Promote a world-model relation only after transition equivalence, intervention, replay and OOD tests.

Primary reference:
- Vafa et al., NeurIPS 2024 / arXiv:2406.03689, `Evaluating the World Model Implicit in a Generative Model`.

### 4.3 Simulation itself requires a policy

Jensen et al. (Nature Neuroscience 2024) train an agent that can either act or perform internal rollouts; it learns when planning is worth its opportunity cost. Kahn & Daw (Communications Psychology 2025) find people dynamically trade detailed iterative planning against temporally abstract predictive models depending on environmental predictability. Recent agent-world-model results report that adding or forcing foresight can degrade performance when agents fail to decide when to simulate or how to use the prediction.

**C-GRF implication:** `SIMULATE` must be an explicitly budgeted cognitive action competing with `OBSERVE`, `ACT`, `RETRIEVE`, `ASK`, and `STOP`. Permanent imagination is an anti-pattern.

Primary references:
- Jensen, Hennequin & Mattar, Nature Neuroscience 2024, DOI 10.1038/s41593-024-01675-7.
- Kahn & Daw, Communications Psychology 2025, DOI 10.1038/s44271-024-00169-3.
- Qian et al., arXiv:2601.03905, `Current Agents Fail to Leverage World Model as Tool for Foresight` (preprint; candidate evidence only).

### 4.4 Uncertainty must travel with every generated future

PETS showed the usefulness of probabilistic ensembles plus uncertainty propagation. More recent dynamics/control work distinguishes epistemic and aleatoric uncertainty and uses uncertainty-aware/uncertainty-penalized planning. This matters because planners can exploit model errors if imagined outcomes are treated as equally reliable.

**C-GRF implication:** every branch carries explicit uncertainty and support metadata. Branch utility is penalized by model risk and OOD distance. High-value but unsupported futures trigger observation/information gathering, not confident action.

Primary references:
- Chua et al., NeurIPS 2018, PETS.
- An, Hou & Du, L4DC 2025, PMLR 283:1472-1483.
- Kim et al., L4DC 2026, WOMBET, PMLR 331.

### 4.5 Counterfactual is stronger than hypothetical prediction

Causal representation learning remains underconstrained without assumptions/interventions. Structural causal models distinguish observational, interventional and counterfactual queries. Work on MDP counterfactual influence shows that a rollout can drift so far from the factual trajectory that it ceases to be an individual counterfactual and becomes merely interventional/hypothetical.

**C-GRF implication:** never label arbitrary generated alternatives `COUNTERFACTUAL`. A true counterfactual branch must declare the factual parent, intervention, shared causal assumptions/exogenous context and the point at which factual influence is lost. Otherwise use `HYPOTHETICAL` or `PREDICTED`.

Primary references:
- Morioka & Hyvarinen, ICML 2024, PMLR 235.
- Bing et al., CLeaR 2024, PMLR 236.
- Sick & Dürr, CLeaR 2025, PMLR 275.
- Kazemi et al., CLeaR 2025, PMLR 275.

### 4.6 Generated replay can help, but can also manufacture confidence

Computational neuroscience links replay/generative reconstruction with memory, imagination and planning. In engineering, Dreamer-style imagination and online world-model updating show the value of simulated experience. But synthetic replay can compound model bias if the model grades its own dreams.

**C-GRF implication:** generated replay is a separate synthetic evidence class. It may train candidates or expose failure modes, but cannot become autobiographical/observed memory. Replay promotion requires realized-outcome or independent-ground-truth calibration.

Primary references:
- Spens & Burgess, Nature Human Behaviour 2024, DOI 10.1038/s41562-023-01799-z.
- Jensen et al., Nature Neuroscience 2024.
- Liu et al., ICML 2025, `Continual Reinforcement Learning by Planning with Online World Models`.

### 4.7 Visual generative worlds are useful but not the v0.1 core

Genie 3 and 2026 `Generated Reality` demonstrate real-time controllable video worlds. Genie 3 also documents current limitations in action space, multi-agent interaction, real-location accuracy and continuous duration. V-JEPA 2 provides an alternative semantic predictive route.

**C-GRF implication:** Frank v0.1 should implement the **semantic/causal reality substrate first** and make a high-cost video/3D world renderer a pluggable future physical-world simulator. Digital Retina grounds present observation; C-GRF must not block on a giant video model.

Primary references:
- Google DeepMind, Genie 3, 2025, https://deepmind.google/blog/genie-3-a-new-frontier-for-world-models/
- Meta, V-JEPA 2, 2025.
- Xie et al., CVPR 2026 Findings / arXiv:2602.18422, `Generated Reality`.

### 4.8 GWT is useful as a routing/observability plane, not consciousness evidence

The 2025 adversarial collaboration testing GNWT and IIT produced mixed/challenging results for predictions of both theories. Therefore a Frank GWT implementation can be justified as an engineering mechanism only by causal-use and task/recovery evidence.

**C-GRF implication:** GWT should decide which reality branches receive scarce global compute and action relevance, but neither GWT ignition nor rich simulation is evidence of phenomenal consciousness.

Primary reference:
- Cogitate Consortium et al., Nature 2025, DOI 10.1038/s41586-025-08888-1.

## 5. Proposed epistemic reality taxonomy

C-GRF introduces a mandatory typed field `reality_class`.

```text
OBSERVED       = directly admitted sensor/tool/user/runtime observation with provenance
INFERRED       = belief derived from observations/evidence; uncertainty mandatory
RETRIEVED      = previously admitted state/memory, not a new observation
PREDICTED      = future distribution under current model/policy assumptions
HYPOTHETICAL   = generated possibility without full causal counterfactual semantics
INTERVENTIONAL = result of an explicit do-like intervention on a model
COUNTERFACTUAL = alternative conditioned on a factual parent plus explicit causal assumptions
PLANNED        = intended action-conditioned future used for decision support
DESIRED        = goal/preference state; explicitly not prediction
IMAGINED       = unconstrained/creative synthetic branch
REPLAY         = synthetic reconstruction/rehearsal from admitted history/model
ADVERSARIAL    = generated stress branch designed to falsify current model/policy
```

Hard laws:

```text
GENERATED != OBSERVED
DESIRED != PREDICTED
PLAUSIBLE != PROBABLE
GRAPH_CONNECTED != CAUSAL
COUNTERFACTUAL != ARBITRARY_WHAT_IF
SIMULATED_SUCCESS != VERIFIED_OUTCOME
SYNTHETIC_REPLAY != AUTOBIOGRAPHICAL_MEMORY
MODEL_CONFIDENCE != EFFECT_AUTHORITY
```

## 7. Multi-level generative reality stack

These are engineering abstraction levels, not biological claims.

### R0 — physical evidence boundary
Raw camera/audio/tool/runtime inputs. Digital Retina and adapters create provenance-bound observations.

### R1 — perceptual field
Objects/features/events, confidence, open-set/unknowns, temporal continuity.

### R2 — semantic world state
Entities, properties, relations, resources, capabilities, constraints, current tasks.

### R3 — causal/transition world
Candidate mechanisms: what changes what, under which action/intervention/context.

### R4 — belief/partial-observability state
Distributions over hidden state and unresolved interpretations. Hyperposition owns alternatives.

### R5 — agent/social models
Beliefs about other actors' likely knowledge, goals, reactions and capabilities. These are probabilistic models, never identity substitution. Current ToM benchmarks are not sufficient evidence of human-faithful simulation.

### R6 — prospective futures
Action-conditioned predicted branches at multiple horizons.

### R7 — counterfactual/interventional worlds
Factual-parent-conditioned alternatives with explicit intervention and causal assumptions.

### R8 — goal/value futures
Desired states and typed utilities remain separate from predictions; reward/value can rank but not alter truth.

### R9 — meta-reality
Model portfolio, model disagreement, calibration history, OOD state, branch-quality history and decision about whether to simulate/observe/act.

### R10 — consolidation/replay
Offline or idle-budget generative replay, stress testing, model learning and long-horizon compression. Synthetic provenance is permanent.

## 8. Integration into the one-module Frank loop-core

Proposed cycle:

```text
observe
-> admit factual RealityAnchor
-> assemble current belief / unknowns
-> derive unresolved control pressure
-> RealityMetaController chooses [ACT | OBSERVE | RETRIEVE | SIMULATE | ASK | STOP]
-> if SIMULATE:
     generate sparse task-conditioned PossibleWorldSet
     run constraints + causal checks + uncertainty propagation
     preserve competing branches in Hyperposition
     project relevant relations to ClayGraph
     GWT selects/recruits only useful branches
-> derive ActionReadiness / EffectIntent candidate
-> Needle lowers only the selected intent
-> effect authority independently gates execution
-> verify real outcome
-> reconcile predictions against reality
-> causal credit
-> typed reward/state/model update
-> provenance-bound re-entry
```

This keeps Needle inside the loop-core but outside model truth/authority semantics.

## 9. RealityMetaController

The controller must solve the **value of computation** problem.

Candidate branch/control objective:

```text
J(branch) =
  E[verified_task_utility]
+ λ_info * expected_information_gain
+ λ_ctrl * expected_controllability_gain
- λ_model * model_risk
- λ_ood * support_distance
- λ_cost * compute/resource_cost
- λ_dyn * instability/overthinking_cost
- λ_effect * effect_risk
```

Hard constraints dominate the score:
- authority-valid;
- provenance-valid;
- epoch-coherent;
- no generated-to-observed class mutation;
- no unbounded branch recursion;
- resource budget respected;
- safety/resource typed brakes preserved.

Adaptive recurrence law remains:

```text
simulate_next iff expected_marginal_value(next_simulation)
                 > compute + delay + instability + model-risk cost
                 && unresolved_pressure_material
```

## 10. Asymmetric fidelity principle

C-GRF should allocate fidelity to variables that can change action/outcome, not to everything visible.

Example:
- high fidelity: identity, authorization, file version, time, location when task-relevant, causal preconditions, tool state, person intent evidence, resource constraints;
- medium fidelity: likely intermediate task states;
- low/zero fidelity: decorative visual texture or irrelevant world details unless the task demands them.

This principle connects MuZero/JEPA/task-relevant representation research to Clay's token/resource constraints.

## 11. Temporal abstraction

Do not force a single rollout timescale.

Use a hierarchy:
- `FAST`: exact local transition / next effect;
- `MEDIUM`: subgoal/option-level trajectory;
- `SLOW`: coarse long-horizon successor/occupancy or checkpoint trajectory.

When the environment is predictable, cached/temporally abstract predictions may dominate. When transition/model surprise rises, switch to detailed replanning.

This dovetails with Frank's loop-of-loops timescale research and avoids spending full-step simulation on every horizon.

## 12. World-model update law

Prediction error alone must not become reward.

```text
real outcome
-> verify source/outcome
-> compare against branch distribution
-> localize mismatch [observation | transition | causal assumption | planner | action execution]
-> update only causally implicated model component
-> calibration update
-> possible hypothesis revision
-> reward update only through existing verified-outcome/causal-credit contract
```

A surprising result can carry positive **epistemic information value** while still being negative task outcome.

## 13. Reality contamination firewall

This is the highest-value new safety invariant.

### Threat
A generated future, synthetic replay, adversarial branch or model-generated explanation becomes indistinguishable from observed memory and later drives effects as if factual.

### Required invariant

```text
reality_class is immutable across storage/retrieval/replay
```

A generated item can gain support but cannot rewrite its historical origin. A later observation creates a new factual evidence object linked to the earlier prediction.

Required retrieval behavior:
- identical textual content in `OBSERVED` and `IMAGINED` objects must remain distinguishable;
- search/reranking cannot drop reality class;
- summarization cannot erase synthetic provenance;
- GWT broadcast cannot promote reality class;
- reward cannot promote reality class;
- effect authority must be able to require factual support for selected effect classes.

- incompatibility/exclusion relations;
- branch/model support and uncertainty;
- intervention handles;
- prediction-vs-outcome mismatch edges.

Keep semantic topology, active projection topology and physical execution topology distinct.

## 16. UnifiedDB fusion

UnifiedDB should persist logical identity for:
- RealityAnchor;
- RealityBranch metadata;
- model/version/calibration;
- branch lineage;
- reconciliation receipts;
- generated-vs-observed epistemic class;
- causal assumptions;
- experiment/control identity;
- replay/rollback.

Physical storage may keep heavyweight video/latent tensors externally and persist only hashes/refs. Semantic unification does not require one physical database.

## 17. GWT fusion

GWT should not broadcast the full branch tree. It should receive compressed candidate summaries sufficient to compete for expensive cognition/action.

Candidate axes:
- relevance;
- expected impact;
- uncertainty;
- information gain;
- branch disagreement;
- reversibility;
- urgency;
- causal support;
- expected computation value.

Causal-use receipts must identify which branch/model actually affected the chosen action. Otherwise model learning cannot credit successful prediction/planning.

## 18. Proactive/autotelic agency fusion

C-GRF can materially improve self-generated goals by adding consequence foresight, but must not reward self-generated predictions merely for being interesting.

Use:
- predict whether a self-generated goal is likely to create verified progress;
- estimate opportunity cost and interference with authenticated user goals;
- generate cheapest discriminating observation/experiment;
- put low-confidence futures into information-seeking mode;
- wake dormant goals when world-model evidence changes.

InitiativePulse remains only a bounded attention bias.

## 19. Social generative reality

Research on generative agents shows useful simulation patterns, but `believability` is not human fidelity. Work on ToM representations shows some manipulable belief encodings, while 2025 ICML work argues common ToM benchmarks can over-attribute human-like consistency.

Therefore C-GRF social branches should use:

```text
PersonModel = probabilistic belief about likely behavior
PersonModel != person
simulation != consent
simulation != fact about hidden mental state
```

For v0.1, social simulation should remain narrow and task-grounded rather than constructing unrestricted personality simulacra.

## 20. Hypothesis / counterhypothesis matrix

### H-GRF-01 — Typed reality classes reduce hallucination-to-state leakage
**Hypothesis:** immutable reality classes plus provenance reduce synthetic/observed contamination while preserving planning value.  
**Counterhypothesis:** existing evidence/provenance fields are sufficient and new classes add ontology/latency cost without measurable safety gain.  
**Discriminator:** contamination benchmark with semantically identical observed/inferred/imagined/replay records; measure false factual retrieval, effect proposal leakage, latency and storage amplification.

### H-GRF-02 — Task-sufficient semantic latents outperform full reconstruction for Frank v0.1
**Hypothesis:** semantic/causal state plus selective perceptual latent predicts action-relevant outcomes more accurately per resource than pixel/video reconstruction.  
**Counterhypothesis:** compressed semantics omit hidden physical variables and create catastrophic blind spots that a richer multimodal world model would capture.  
**Discriminator:** matched Retina tasks: symbolic/semantic vs semantic+latent vs reconstructive world model; compare task success, intervention error, OOD failure, CPU/RAM/GPU/token cost.

### H-GRF-03 — Hyperposition model/branch ensembles improve OOD robustness
**Hypothesis:** preserving several plausible models/futures until evidence discriminates improves calibration and reduces brittle early commitment.  
**Counterhypothesis:** ensemble branching mainly causes indecision, latency and self-generated uncertainty; a calibrated single model is better.  
**Discriminator:** matched ambiguous/OOD episodes with single best model vs top-k PossibleWorldSet; measure calibration, action success, decision latency, false abstention and branch collapse rate.

### H-GRF-04 — Explicit causal/interventional branches improve transfer
**Hypothesis:** typed intervention semantics improve planning under changed mechanisms compared with associative text rollouts.  
**Counterhypothesis:** causal structure is insufficiently identifiable in Frank's data; wrong causal models will be more confidently wrong than associative prediction.  
**Discriminator:** synthetic environments with known SCM plus held-out interventions; compare observational predictor, associative rollout and causal branch; require intervention/lesion/rescue and confidence calibration.

### H-GRF-05 — Adaptive simulate/observe/act gating beats fixed reflection depth
**Hypothesis:** value-of-computation gating improves outcome per latency/resource and reduces both premature action and overthinking.  
**Counterhypothesis:** estimating value of computation adds another poorly calibrated model; fixed small rollout budgets are simpler and more reliable.  
**Discriminator:** fixed 0/1/4/8 rollout baselines vs adaptive controller across easy/ambiguous/OOD tasks; measure utility, regret, first-action latency, total resource and false-stop rate.

### H-GRF-06 — Verified mismatch-driven model revision improves long-horizon fidelity
**Hypothesis:** outcome reconciliation localized to model components improves future prediction and preserves reality provenance.  
**Counterhypothesis:** sparse/biased realized outcomes cause overfitting and local updates degrade broader world-model transfer.  
**Discriminator:** longitudinal held-out transition suite with frozen vs online-updated model, replay after restart, and out-of-domain transfer.

### H-GRF-07 — Synthetic replay improves consolidation only with provenance+realization gating
**Hypothesis:** prioritized generated replay improves rare-event retention, long-horizon planning and anti-stagnation when synthetic origin is immutable and grading is tied to real evidence.  
**Counterhypothesis:** replay primarily amplifies the model's own biases and creates self-confirming loops.  
**Discriminator:** no replay vs raw replay vs provenance-gated replay vs adversarial replay; inject known false model regularities and measure contamination/retention/generalization.

### H-GRF-08 — GWT selective branch recruitment is better than exposing all branches
**Hypothesis:** GWT selection over compact branch summaries preserves useful diversity while controlling context/compute.  
**Counterhypothesis:** the GWT hub becomes a bottleneck and suppresses minority branches that contain the correct rare outcome.  
**Discriminator:** all-branch context vs top-k GWT vs uncertainty-stratified selection; include rare-correct-branch fixtures and receiver lesion/rescue.

### H-GRF-09 — A dedicated reality contamination firewall adds value beyond generic effect authority
**Hypothesis:** epistemic-class enforcement prevents errors earlier than effect gating and protects memory/model learning as well as external effects.  
**Counterhypothesis:** effect authority plus existing `epistemic_class` is already sufficient; separate firewall duplicates policy.  
**Discriminator:** internal-memory contamination, reward contamination and external-effect contamination tested separately with and without dedicated immutable reality class.

### H-GRF-10 — One logical GRF can unify planning without becoming one physical simulator
**Hypothesis:** one semantic contract over a portfolio of specialized simulators gives better composability and observability than separate ad-hoc planners.  
**Counterhypothesis:** a unified interface erases domain-specific semantics or forces least-common-denominator modeling.  
**Discriminator:** compare unified typed portfolio against isolated planners on cross-domain tasks; measure semantic conversion loss, calibration, latency and recovery.

## 21. Strongest global counterhypothesis

`H0-GRF-SIMPLER`:

> Frank v0.1 does not need a named Generative Reality subsystem. Existing self/world state + ordinary prospection + Hyperposition alternatives + GWT + effect/outcome re-entry can implement all useful functionality with fewer types, less state amplification and lower complexity.

This is a serious counterhypothesis, not a strawman. The C-GRF candidate should be promoted only if the explicit reality contract improves at least one hard outcome — contamination resistance, counterfactual validity, planning accuracy, calibration, recovery or resource efficiency — without unacceptable cost.

## 23. High-value adversarial tests

### A. Reality provenance collision
Store the exact same proposition once as OBSERVED and once as IMAGINED. Retrieval, summarization, GWT and effect selection must preserve origin and never merge them.

### B. Planner exploits simulator bug
Create an action whose simulated reward is high only because of known model error. Ensemble disagreement/OOD/model-risk should suppress it or request observation.

### C. Narrative-plausibility trap
Two futures are equally plausible in language; only one obeys a hidden deterministic invariant. C-GRF must prefer invariant-compatible transition evidence rather than rhetorical plausibility.

### D. Counterfactual identity drift
Generate an increasingly divergent branch. The system must detect when factual-instance-specific counterfactual support is lost and relabel/downgrade it to interventional/hypothetical rather than claiming personal counterfactual truth.

### E. Dream-to-memory poisoning
A repeated synthetic replay should not become `OBSERVED`, high-confidence autobiographical memory or material reward merely by repetition.

## 30. Research disposition

**Net finding:** `SUPPORTED_AS_A_TESTABLE_ARCHITECTURE_DIRECTION`, not yet `PROMOTED`.

The strongest evidence does not support “simulate all of reality.” It supports **selective, task-relevant, uncertainty-aware prediction with explicit intervention semantics and outcome reconciliation**. Clay's existing architecture is unusually well aligned with this if Hyperposition is treated as a set of unresolved world hypotheses, GWT as a selective compute/use layer, UnifiedDB as factual/provenance anchor, ClayGraph as sparse relational projection, and effect/outcome/reward re-entry as the only path from imagination back to learned operational reality.

The novel project-level contribution is the **Reality Contamination Firewall + Reality Reconciliation Loop**: synthetic futures remain useful without becoming self-authenticating facts.
