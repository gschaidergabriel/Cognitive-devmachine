# Candidate Architecture — Dual Workspace Causal Closure

## Current FRANK mapping first

The newest source-grounded FRANK architecture identifies `services/workspace_broadcast.py` as the current cognitive workspace. Six source channels compete; the winner may cross configured `ZUENDSCHWELLE=0.55`; one focus receives full detail; a semantic workspace row is persisted to `consciousness.db.workspace_broadcast`; Core reads the newest row into `[INNER_STATE]`; Qwen consumes that semantic projection. This mapping remains OPEN pending independent live code/trace reproduction.

Do not confuse the six competing source channels with six proven downstream broadcast audiences. Multi-audience physical multicast is a candidate future architecture unless target tracing identifies those consumers.

## Planes

`LATENT_WS` is optional and model-internal. It may expose J-space-like coordinates, latent probe windows, intervention handles and confidence. It is never authority. In the current FRANK mapping its most useful prospective role is as an independent **model uptake observability channel** for whether `EVENT_WS` semantic content was reconstructed inside Qwen.

`EVENT_WS` is refined as:

`candidate → competition → selection → gate_event → logical workspace register → transport/read → projection/reconstruction → receiver uptake → effect proposal → external authority/effect gateway → outcome → causal-freshness gate → re-entry`.

## Gate event is not scientific ignition evidence

`gate_event` records the actual configured controller rule, including `ZUENDSCHWELLE`, winner score, runner-up score, margin and policy version. It may be binary.

`ignition_evidence` is a separate observational/interventional certificate and should include where measurable:
- pre-gate input/activation curve;
- 10–90% transition width or comparable continuous sharpness metric;
- ambiguity-trial bimodality/commitment;
- threshold-shift anchoring slope when configured threshold is varied in replay/shadow mode;
- up/down sweep hysteresis;
- persistence after transient input;
- feedback/re-entry lesion effect on sharpness/persistence/hysteresis;
- broadcast/reconstruction/effect consequences.

A transition that follows the configured threshold one-for-one is controller evidence, not endogenous ignition evidence. A static software gate must never automatically satisfy the metric used to evaluate scientific ignition.

## Receiver contract

Delivery is decomposed into four receipts:

1. `transport_receipt` — payload/hash successfully persisted/delivered/read.
2. `projection_receipt` — receiver-specific deterministic/typed projection or semantic adapter succeeded and preserves declared invariants.
3. `uptake_receipt` — receiver state/representation or validated behavior indicates the content became locally available for use.
4. `effect_receipt` — a downstream state/action/effect is causally linked to that uptake.

For deterministic modules, projection/uptake can use parse, roundtrip, state-hash or invariant checks. For Qwen, a validated latent probe may provide an independent uptake channel, while behavior/effect remains a separate causal endpoint.

## Workspace Register and delivery modes

Global availability remains a semantic/logical property, not a requirement to physically push every payload to every module. After current consumer topology is measured, candidate delivery modes are:
- `SELECTIVE_PUSH`;
- `PULL_RESCUE`;
- `WIDENED_PUSH`;
- `FULL_PUSH`.

The controller must monitor causal consumer recall, misses, rescue latency, false/irrelevant delivery, fanout, energy/cost and perturbation amplification. Sparse delivery is never declared equivalent merely because mean task accuracy is unchanged.

## Required receipts

- `candidate_id`: producer, payload ref/hash, score vector, uncertainty, dependencies.
- `competition_id`: candidates, winner, runner-up, margin, policy version.
- `gate_event`: configured threshold/policy, winner score, margin, decision.
- `ignition_evidence_ref`: pre-gate curve, threshold-shift, bimodality, hysteresis and lesion metrics; optional until empirically demonstrated.
- `broadcast_id`: logical scope, consumer plan, routing confidence, fanout budget, payload hash.
- `transport_receipt`: destination, mode, transport/read status and latency.
- `projection_receipt`: receiver transform/schema/invariants and reconstructed hash/status.
- `uptake_receipt`: receiver-local availability evidence, including optional latent probe ref.
- `effect_receipt`: effect identity, causal parent, authority reference, effect hash.
- `outcome_receipt`: measured outcome/utility vector/environment delta.
- `reentry_receipt`: outcome source, target decision, delay, truth-binding hash, source-state hash, validity epoch/regime tag, age-at-use, predictive-freshness estimate and stale/reject reason.
- `latent_bridge_ref`: model call + latent probe window when available.

## Causal Freshness Gate

A re-entry payload is not accepted simply because it is truthful and recent. At consumption time evaluate:

`truth binding + source-state compatibility + validity epoch + age-at-use + estimated predictive/causal value`.

Keep the existing 60 s heartbeat as a spontaneous/idle candidate while testing semantic-dirty/high-salience/pre-query refresh. TTL remains task/regime dependent.

## Dual-workspace cross-lesion preregistration

Use paired compute-matched 2×2 interventions:
- serial `LATENT_WS → EVENT_WS`: both single lesions large; double approximately occludes stronger single;
- redundant parallel: single lesions modest; double strongly worse;
- additive parallel: double approximately additive;
- latent epiphenomenal: latent lesion near-null, event lesion large;
- event epiphenomenal: event lesion near-null, latent lesion large.

For current FRANK, add a receiver-specific hypothesis: `EVENT_WS publication → Core projection → Qwen LATENT_WS uptake → behavior/effect` may be a serial chain. This is not established until cross-lesion/mediation evidence exists.

## Causal Workspace Closure Certificate (CWCC)

CWCC remains vector-valued. Track competition/margin, configured gate state, endogenous ignition evidence separately, logical consumer scope, transport, projection/reconstruction, uptake, causal consumer recall, rescue, effect mediation, outcome, re-entry sensitivity, age-at-use, stale-apply/reject rate, predictive freshness, next-state influence, capacity/load, physical fanout, perturbation amplification, latent/event concordance and cost/recovery shadows.

## Authority rule

Workspace selection, gate crossing, routing, reconstruction, uptake or freshness acceptance never grants execution authority. Effect proposals still pass the external capability/root/nonce/expiry/invariant/rollback gateway.
