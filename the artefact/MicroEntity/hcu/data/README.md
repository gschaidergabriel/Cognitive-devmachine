# HCU data

All HCU-specific durable data artifacts generated by research/build/calibration work should be stored under this subtree when they are suitable for source control/package inclusion.

Examples:

- bounded benchmark summaries;
- resource/capacity measurements with exact source/model/runtime identity;
- calibrated horizon/confidence tables;
- anonymized/deduplicated feeder statistics;
- topology/resource snapshots.

Canonical Mini Entity truth still lives in MiniUnifiedDB at runtime. Files here are package/evidence artifacts, not a competing truth database.

Never store secrets, API tokens, raw credential-bearing requests, or unrestricted private transcripts here.
