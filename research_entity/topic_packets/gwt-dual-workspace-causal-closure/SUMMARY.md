# GWT Dual Workspace and Causal Closure — Summary

Status: **OPEN architecture/research delta**. No live-FRANK or phenomenal-consciousness promotion.

The current candidate separates two workspace layers. `LATENT_WS` is an optional model-internal substrate such as the 2026 Anthropic J-space: sparse, intermediate-layer, limited-capacity, broadly readable/writable and causally involved in some flexible reasoning, but not a complete recurrent GWT architecture. `EVENT_WS` is FRANK's system-level causal cycle: `candidate → compete → ignite/select → logical workspace register → causal push router ↔ query/pull rescue → reconstruct → effect → outcome → freshness-gated reenter`, linked by episode identity and receipts.

The key bridge hypothesis remains that strong GWT evidence should triangulate `LATENT_WS` and `EVENT_WS` when both exist: align external episode receipts to latent probe windows, then independently lesion each channel. A preregistered 2×2 cross-lesion matrix can distinguish serial mediation, parallel redundancy/additivity and epiphenomenal channels.

Synthetic `EXP-GWT-RUN-ADAPTIVE-001` established an interior capacity optimum, truth-bound re-entry benefit and an overcoupling/corruption tradeoff in one proxy. New `EXP-GWT-MULTICAST-002` shows that logical global availability can be separated from all-to-all physical push: with a synthetic router AUC≈0.921 and 95% pull-rescue sensitivity, relevant coverage was ~98.73% while physical deliveries fell ~67.64% and irrelevant deliveries ~89.77% versus full broadcast. This is not functional equivalence because causal misses remain.

New `EXP-GWT-FRESHNESS-003` turns re-entry delay into a measurable control variable. In a synthetic AR(1) process the last useful delay increased from 1 to 29 steps as process persistence `rho` rose from .60 to .98; the constructed crossover tracked correlation half-life closely. Cross-domain Age-of-Information-at-Query research independently supports evaluating freshness when information is actually consumed rather than maintaining indiscriminate push freshness.

Architecture delta: preserve **logical global availability**, use **adaptive selective push + pull rescue**, emit reconstruction/effect receipts, and gate re-entry by **causal freshness at use time** using age, source-state compatibility/validity epoch and predictive value. Extend CWCC with causal audience recall, missed-audience rate, rescue latency, age-at-query, stale-apply rate and physical fanout.

Highest-information next steps: live FRANK re-entry freshness factorial → live/twin multicast shadow mode → open-model latent/event cross-lesion → reconstruction lesion → ignition interpolation.
