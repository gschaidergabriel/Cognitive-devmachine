# FUSION 2 — after external research + concurrent-mesh refresh

## Destroyed/retired directions
- Generic counterfactual credit is not radical: Counterfactual Shapley, C3 and other current methods directly occupy it.
- Individual microlesions are useful as an exact local discriminator but are too close to leave-one-out counterfactual families to justify ATOMIC novelty.
- A learned critic is a strong conventional baseline; in a stationary synthetic environment it matched the first microlesion estimator to the same order of MAE, so “always lesion instead of model” is rejected.
- A new provenance algebra alone is weakened by CARF's fresh result: a conventional typed factorized DAG + explicit responsibility evaluator matched the CARF runtime candidate exactly in its synthetic semantics.
- A new quotient/fusion compiler would duplicate concurrent CQC.

## Surviving problem
Exact tests are valuable but expensive. Current Frank requires causal evidence before material plasticity and requires historical-organ lesion/rescue evidence before dissolution. These obligations create a potentially large experimental search space.

## Surviving mechanism
CIT-001 treats a safe internal group lesion as a *projection measurement* of a sparse unknown causal field. Multiple randomized masks can identify a small candidate set using sparse recovery. The reconstruction itself is not causal truth. Each positive candidate must then receive an exact individual lesion/rescue or strong responsibility witness before it can contribute to material causal credit.

This creates a two-tier path:

`large candidate cone -> pooled safe probes -> sparse candidate ranking -> exact confirmation -> typed causal witness -> verified-outcome-gated reward/reentry`

## Why this is different from CARF
CARF answers “given an adequate dependency structure, what is each atom's exact responsibility under bounded contingencies?” CIT answers “when exact testing of a large/uncertain cone is expensive, which atoms are worth spending exact tests on first?” CIT can therefore die without harming CARF, and CARF can remain the confirmation baseline.

## Why this is different from CQC
CQC uses protected interventions to determine whether module/state boundaries can be safely quotient-merged. CIT may later optimize which intervention combinations are information-rich, but it cannot authorize a quotient certificate or fusion.

## Strongest counterhypothesis after Fusion 2
The strongest null is not “CIT cannot reconstruct sparse vectors.” It plainly can in favorable synthetic regimes. The null is:

> A normal active-testing scheduler using single lesions, dependency-graph pruning and/or a learned counterfactual critic will achieve equal end-to-end confirmed-cause yield at lower total complexity once fallback/audit cost and nonlinearity are included.

That null remains unresolved and blocks promotion.

## Safety transformation
The original direct-credit interpretation is rejected. CIT is now a `PROBE_SCHEDULER_ONLY` candidate. No compressed estimate may become RewardOutcomeEvidence.causal_credit directly.
