### Missing distinction: integrity is not cognitive correctness

The current architecture has become very good at specifying what deterministic infrastructure can certify:

- canonical identity;
- provenance ancestry;
- causal basis/epochs;
- selector/query-plan identity;
- exact reader view;
- capability/effect scope.

But a fully authentic, epoch-valid association can still be the **wrong association for the task**. Structural certification can detect invalid ancestry or an illegal authority cast; it cannot generally prove cognitive relevance.

Therefore the whole system requires two validation layers:

1. **deterministic integrity gate** — identity, basis, collection algebra, selection, projection and authority;
2. **empirical cognitive gate** — truthful-vs-shuffled controls, task utility, lesion/rescue, OOD and stage-orthogonal causal testing.

### Fresh dependency: collection algebra is causal identity

Fresh in-progress ClayCode CC12 material introduced explicit lowering for `SET`, `ORDERED`, `MULTISET` and weighted semantics. Fusion executed the declared typed lowering locally against SQLite.

Across 30,000 seeded cases:

- correct typed lowering mismatches: **0**;
- type-erased `DISTINCT` route mismatches: **16,947**;
- type-erased bag/ordered route mismatches: **16,609**.

This matters far beyond database correctness. If a lowerer changes multiplicity or order, it can change:

`query result -> candidate set -> GWT competition -> model projection -> action`

while every individual record remains authentic.

Therefore **collection semantics belongs inside MOSAIC/UnifiedDB query-selection identity and downstream receipts.**

## 4. External research delta

F5 executed a focused external check rather than treating branch citations as sufficient.

### Dynamic memory

ACL 2026 **Synapse** independently models agent memory as a dynamic graph using spreading activation, lateral inhibition and temporal decay, combined with embedding and traversal. This strengthens the plausibility of the ClayGraph latent-field direction as a memory mechanism.

It does **not** validate FRANK's between-call C3F mechanism, canonical event spine or GWT interaction.

### Latent rails

ACL 2026 **Interlat** demonstrates direct hidden-state communication between agents, including heterogeneous models, and reports major compression/latency gains in its tasks.

This independently supports CC11's P3/latent rail as technically plausible. It does not make hidden state canonical truth or authority.

### Capability boundaries

ACM CAIS 2026 **Securing Agents With Tracked Capabilities** independently supports structurally tracked authority rather than free model/tool access.

This reinforces C7/H4's isolated effect/capability broker and the rule:

`model output != authority`.

### Same-process data plane

Current Apache Arrow documentation explicitly says its C Data Interface permits zero-copy sharing between independent runtimes/components in the **same process** and lists cross-process sharing/persistence as non-goals.

This is a useful correction to any architecture shorthand that says “Arrow solves IPC.” It does not.

### Transactional authority domain

FoundationDB's transaction interface explicitly presents a transaction as a mutable snapshot with atomicity, isolation and durability at commit.

This independently supports the architecture pattern of a clearly defined authoritative commit domain rather than pretending arbitrary derived engines are synchronously atomic.

### Agentic data movement

2026 **AAFLOW** reports agentic-pipeline speedups from Arrow/Cylon, batching and reduced serialization/data movement while keeping model generation throughput comparable.

This strengthens CORF's focus on data-plane/serialization overhead as a real systems target, but AAFLOW is a preprint and not validation of FRANK.

## 9. What the fusion changes conceptually

Before this fusion, the project could be summarized as:

> Build one Clay-native cognitive organism with persistent relational memory, GWT, multi-rail model communication and a unified persistence fabric.

After F5 the more precise statement is:

> **Build one Clay-native semantic organism whose persistent state can continuously reshape what becomes cognitively available between model calls, while deterministically certifying identity/causal/selection/authority integrity and separately testing whether the authentic associations actually improve cognition.**

That separation matters because it prevents two opposite errors:

1. treating fast/continuous associative memory as untrustworthy merely because it is non-authoritative;
2. treating perfectly authenticated associative memory as cognitively correct merely because it is well receipted.

The first loses the potential benefit. The second creates a dangerous false confidence.
