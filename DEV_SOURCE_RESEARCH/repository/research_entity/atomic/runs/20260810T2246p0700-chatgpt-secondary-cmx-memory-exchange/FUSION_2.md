# Fusion 2 — external collision and narrowed question

The first fusion made utility-governed memory look attractive because Frank needs bounded context, causal credit and anti-self-echo behavior. Fresh research destroys the broad novelty claim. Expected-value replay, utility-driven forgetting, cost-sensitive routing, context reinstatement, conflict-aware structured memory and reward-trained memory updates are all already populated mechanism families. Most importantly, 2026 RoMeRL explicitly names a memory-reward trap in which co-retrieved memories receive misleading shared utility.

This changes the candidate question. CMX is no longer selected as a likely new architecture. It is selected as a high-information destructive test of one narrower proposition: does *per-memory marginal counterfactual credit plus context rent* add value beyond simple versioned/provenance memory under drift and noisy procedural feedback?

The scope is narrowed to procedural/strategy memory. Factual evidence, identity anchors, user intent, authority receipts and effect authorization are excluded from capital competition. A procedural memory can become useful or useless; that must never convert it into true/false evidence authority.

The strongest baseline is upgraded from semantic similarity to `latest verified exact context -> recency-weighted verified cluster fallback`, plus a provenance-weighted fixed-k baseline and reward-weighted baseline. If CMX cannot beat the latest/supersession baseline on clean evidence, or if removing its counterfactual coupon/rent improves results, the defining mechanism is refuted even if some composite CMX configuration happens to score well.
