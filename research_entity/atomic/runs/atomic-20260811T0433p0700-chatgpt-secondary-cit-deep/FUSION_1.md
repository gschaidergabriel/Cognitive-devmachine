# FUSION 1 — current problem surface

## Identity lock
Clay is the research entity. `self.root` is the separate target; `Frank` is its human-surface name. self.root cannot authorize its own Harness mutation. No training/effect authority is created by this run.

## Selected gap
The current reward successor already requires `verified_outcome + causal_credit` before material plasticity, but `causal_credit(verified, workspace)` is an under-realized bridge. CARF concurrently narrows exact credit to a typed responsibility witness over a factorized dependency DAG and correctly kills a separate runtime data structure. That still leaves a measurement problem when the candidate causal cone is large, partly latent, stochastic, or expensive to test one element at a time.

The high-leverage question is therefore not “invent another credit algebra.” It is:

> Can Frank/Clay identify a small set of *worth-exactly-testing* causal candidates with substantially fewer sandbox interventions than exhaustive one-at-a-time lesions, while ensuring the compressed screen itself can never mint material credit?

## Current invariants
- activation/salience/GWT ignition != causal credit;
- successful outcome does not credit every active state;
- material reward requires verified outcome and positive causal credit;
- causal/probe evidence != truth, identity, user intent or effect authority;
- external effects must not be replayed merely to measure internal credit;
- stale/mismatched snapshot probes are invalid;
- negative results and fallback costs are data;
- any compressed screen must have a deterministic path to ABSTAIN/FALLBACK.

## Bottlenecks
1. Exhaustive individual lesions scale linearly with candidate count.
2. Exact responsibility can become expensive with large active causal cones and contingencies.
3. Learned counterfactual critics can be cheap but need validity monitoring under distribution shift.
4. Static dependency graphs can be incomplete for stochastic/model-mediated behavior.
5. Replay fidelity can silently turn counterfactual evidence into stale-state fiction.

## Existing occupied solution space
- GAR: generative/scoped authority; runtime candidate lost to conventional scoped capability.
- PSW: sparse alternative-state representation; distinct architecture lost to conventional overlays+memoization.
- ACEF: unified transaction geometry; simpler transactional counterbaseline unresolved.
- CARF: exact causal responsibility contract; distinct runtime representation refuted.
- CQC: intervention-scoped quotienting for safe organ fusion; synthetic only.

## Baseline set for this run
A. exhaustive individual leave-one-out (LOO) lesions — safety/reference ceiling;
B. random individual lesions at matched probe budget;
C. learned/fixed counterfactual critic where applicable;
D. strong factorized-DAG responsibility when the dependency graph is trusted;
E. shuffled intervention masks;
F. stale/mismatched replay controls.

## Architecture pressure
A radical candidate is only useful if it reduces *measurement search cost*, not if it creates a second truth system. The correct place to innovate is the experimental scheduler between a large candidate cone and exact confirmation.
