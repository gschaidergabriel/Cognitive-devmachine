### Core
A rescue is not strong evidence for causal necessity merely because it restores the current output. In E1's constructed mediator system, an endpoint-only patch reduced current MSE to zero exactly like true mechanism restoration, while future/re-entry MSE remained 0.2774; true mechanism restoration returned future/re-entry MSE to zero.

### Boundary
This is a synthetic mechanism counterexample, not a measured FRANK effect size. It falsifies the general shortcut `current endpoint recovered -> mechanism rescued`.

### Implication
Emergent-organ certificates should require restoration of the lesioned causal path or an independently justified equivalent mechanism, plus downstream/re-entry trajectory recovery and OOD verification.
