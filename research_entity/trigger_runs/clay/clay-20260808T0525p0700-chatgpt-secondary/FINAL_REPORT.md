## Executive synthesis

G6 retains the G4/G5 Semantic Causal Kernel but corrects two oversimplifications.

1. **Causal budget should be a vector, not one scalar.** Context/KV, active-workspace capacity, incremental recomputation, coupling/re-entry, speculation and coordination face different non-collinear pressures. A constructed four-regime controller test found a vector controller reduced normalized allocation loss by 84.2% relative to a one-scalar controller.
2. **Selective distributed closure cannot be classified only by external effectfulness.** Internal concurrent state transitions may still violate shared invariants. Coordination should occur when either external authority/freshness requires it **or** the operation set is not invariant-confluent under the applicable invariant.

The resulting G6 candidate is:

`canonical events/provenance -> conflict-preserving contextual state -> incremental causal projections -> vector-governed activation/assemblies/GWT -> intervention-tested latent-workspace cross-check -> root/epoch-bound state-aware ClayCode -> invariant/authority closure gate -> effects -> outcome/re-entry`.

For edge deployment the same control principle extends downward: backend, frequency, KV precision/context and speculative decoding should be feedback-controlled by thermal state, memory pressure, acceptance rate and task quality rather than fixed globally.

## External research synthesis

### Workspace evidence must remain multi-marker and intervention-first

Gurnee et al. (`arXiv:2607.15495`) report a verbalizable J-space with functional global-workspace properties. Rahbar (`arXiv:2608.05160`) proposes an Ignition Index that distinguishes abrupt ignition-like dynamics across architectures. These are different functional surfaces and should not be collapsed into one consciousness or workspace scalar. G6 therefore requires cross-intervention: perturb receipt-defined FRANK workspace state and latent workspace state independently, then compare function-specific downstream effects. High observational predictivity alone is insufficient.

### Invariant confluence changes the distributed boundary

Bailis et al., *Coordination Avoidance in Database Systems* (`arXiv:1402.2237`), formalize invariant confluence: coordination is necessary only where independent operations can violate the application's invariants when merged. This directly weakens G5's simple 'effectful vs pure' synchronization boundary. CRDT/local-first implementations such as Automerge demonstrate mature coordination-free mergeable state, but they do not make arbitrary invariants coordination-free.

### Incremental computation supports shared arrangements, not unlimited coupling

Differential Dataflow maintains computations as inputs change and supports shared indexed arrangements. This supports Clay's active/faceted projections and shared materializations, but the benefit still depends on change locality. G6 keeps `R_delta` as a runtime tripwire and tests whether early cascade observations can predict the full recomputation regime.

### State-aware constrained decoding needs freshness and safety boundaries

Decode-Time Grammars (`arXiv:2607.18357`) instantiate grammar fragments from runtime environment Γ and prove support-set guarantees for Γ-typed references. This strengthens state-aware ClayCode generation. However, G6 adds a root/epoch requirement: a correct grammar over stale Γ can still emit references invalid in the current state. Separate 2026 work on grammar-constrained decoding as a jailbreak surface (`arXiv:2606.11817`) further reinforces that syntax/semantic restriction is not a security policy and must remain outside the authority decision.

### Mobile inference requires sustained-load governance

Current Qualcomm GenieX exposes CPU/GPU/NPU paths and Qwen3-4B-class on-device deployment. Sustained-load mobile work (`arXiv:2603.23640`) reports thermal behavior as a primary constraint, and EnerInfer (`arXiv:2606.23001`) shows that the most efficient NPU/DDR setting changes with model/runtime conditions and that online thermal feedback can improve efficiency. Adaptive KV work such as ARKV (`arXiv:2603.08727`) and adaptive on-device KV quantization (`arXiv:2604.04722`) independently support per-state rather than fixed memory allocation. Practitioner llama.cpp reports also show speculative-decoding gains vary sharply with workload/acceptance.

### Emergence remains higher-order and interventionist

PEID (`arXiv:2605.03267`) provides an interventionist decomposition of unique and synergistic causal contribution. G6 therefore keeps pairwise correlation/transfer metrics as diagnostics only; an emergent-organ claim still requires recurrence, lesion, function-specific and compute-matched rescue, OOD stability, higher-order synergy/macro causal contribution, robustness and cost shadows.

## G6 experiments

### EXP-G6-INVCONFLUENCE-001 — effect-only vs invariant-aware closure
200,000 pairs of concurrent internal allocation updates were generated against a shared capacity invariant. If 'internal/non-effectful' was treated as automatically coordination-free, **34.8425%** of merged pairs violated the invariant. An invariant-aware classifier coordinated exactly the risk pairs and allowed **65.1575%** to remain local in this constructed model. This is a counterexample to universal effect-only closure, not a database benchmark.

### EXP-G6-BUDGET-VECTOR-002 — scalar vs vector causal budget
A four-regime synthetic workload used non-collinear optimal allocations for context, incremental maintenance and coordination. Test loss: fixed vector `0.19108`, scalar-pressure controller `0.18102`, vector controller `0.02862`. The vector reduced loss **84.19%** relative to the scalar controller. This falsifies a universal one-scalar budget in the constructed regime; it does not establish the optimal FRANK controller.

### EXP-G6-STALE-GAMMA-003 — state-aware decoding under stale runtime state
A dynamic symbol environment was simulated with 3% churn per step. Grammar-only generation referenced an invalid current symbol **63.874%** of the time. State-aware decoding from a snapshot up to ten steps old reduced this to **11.911%**, but only fresh state reached 0%. A current-root validator caught the remaining stale proposals. Conclusion: Γ-aware decoding must be paired with freshness/root semantics.

### EXP-G6-RDELTA-ESTIMATOR-004 — early cascade prediction
30,000 branching-process cascades with true reproduction parameter 0.4–1.6 were observed for the first three generations. The early offspring estimator predicted whether total cascade size reached 100 with ROC AUC **0.9561** and correlated `0.8829` with log final cascade size. This supports testing an online `R_delta` estimator on real FRANK invalidation traces.

### EXP-G6-DUALWS-INTERVENTION-005 — observation vs causation
Two synthetic systems produced strongly predictive receipt/latent workspace observations. In the causal-mediator model, receipt lesion changed normalized outcome by ~`0.372`; in a common-cause proxy model, observational R² remained `0.678` but direct receipt lesion had exactly `0` structural effect. This validates the experiment design principle: prediction/alignment cannot substitute for intervention.

### EXP-G6-THERMAL-GOV-006 — sustained thermal governor
A constructed sustained-load device proxy compared static max-speed, static eco and a hysteretic thermal governor. Static max-speed thermally collapsed to mean `16.92` normalized tok/s; static eco sustained `42.0`; adaptive sustained `46.23`, ~**10.1%** above eco while remaining below the throttling threshold. This is an architecture sanity check grounded by external sustained-load results, not a phone benchmark.

### EXP-G6-SPEC-GOV-007 — task-conditioned speculation
A 50,000-request synthetic mix used high, medium and low draft-acceptance regimes. Normalized latency: speculation off `1.000`, always on `0.7423`, adaptive per-task acceptance governor `0.7300`. The governor learned to disable speculation for the low-acceptance reasoning regime. This supports acceptance-conditioned speculation rather than a universal setting.

### EXP-G6-HIGHERORDER-008 — pairwise blindness sanity check
For an XOR system, empirical `I(X;Z)` and `I(Y;Z)` were approximately zero while `I((X,Y);Z)` was ~`1 bit`. This does not establish emergence but demonstrates why pairwise-only dependency maps can miss purely synergistic mechanisms and motivates PEID/PID-style tests for candidate assemblies.

- **N-G6-001:** 'Only externally effectful transitions require synchronous closure' is not generally valid. Internal transitions may require coordination when independent execution is not invariant-confluent.
- **N-G6-002:** One scalar causal budget is not generally sufficient; a non-collinear constructed workload strongly favored vector control.
- **N-G6-003:** State-aware grammar validity does not imply current-state validity when Γ is stale; root/epoch freshness is required.
- **N-G6-004:** Observational agreement between receipt and latent workspace channels does not establish a shared causal workspace.
- **N-G6-005:** Maximum instantaneous inference throughput is not a sufficient sustained mobile objective under thermal throttling.
- **N-G6-006:** Pairwise information alone cannot detect all higher-order causal/synergistic mechanisms.

## G6 architecture delta

### Causal Budget Vector

Use a state-dependent vector rather than a scalar:

`B_t = [context_KV, active_workspace, recompute, coupling_reentry, speculation, coordination]`

Controller observations should include at minimum `R_delta` estimate + uncertainty, causal-path completeness, task uncertainty/novelty, workspace divergence, invariant/conflict risk, thermal state, memory/KV pressure, speculative acceptance and recovery/error signals. Separate dimensions may share a controller but must remain independently adjustable.

### Invariant-Confluent Closure Gate

A transition may remain local/speculative only when all applicable conditions hold:
- reversible/quarantinable before authority;
- no real-world capability has been exercised;
- current root/epoch is known where state semantics matter;
- concurrent/merged execution preserves declared invariants, or an explicit merge proof/class says it is invariant-confluent;
- replay/recovery receipts remain available.

Otherwise it enters a coordination/authority path. This replaces G5's effect-only classifier.

### Freshness-bound ClayCode

ClayCode decode-time Γ should be derived from a specific state root/epoch. Proposal records carry that root. Validation fails closed on stale or revoked roots. Grammar/state constraints reduce impossible proposals; external capability/policy/nonce/rollback/effect-receipt checks remain authoritative.

### Intervention-first Dual Workspace

Workspace evidence is a vector of markers, not one score: receipt-defined causal episodes, ignition dynamics, latent verbalizable workspace, downstream mediation, lesion/rescue and temporal re-entry. Divergence between these channels is itself diagnostic. None of these markers alone implies phenomenal consciousness.

### Edge Runtime Governor

The portable FRANK runtime should expose backend/frequency/thermal/KV/speculation telemetry to a governor. Policy optimizes sustained task utility under latency, energy, memory, thermal and recovery constraints, not peak tok/s.
