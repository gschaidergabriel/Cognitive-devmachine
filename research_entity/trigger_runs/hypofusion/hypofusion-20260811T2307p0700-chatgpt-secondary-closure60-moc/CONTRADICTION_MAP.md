# Contradiction Map — Closure60

## C1 — Closure required vs recurrence everywhere

**Resolved distinction:** organism-level operational closure is a required Frank architecture hypothesis; recurrence is **not** required inside every subcomputation. Anthropic's 2026 J-space is important counterevidence against equating workspace function with recurrent wiring. MOC therefore separates local/native within-pass workspace from persistent cross-cycle closure.

## C2 — User correction vs older H0-A wording

Older project counterframing allowed: ordinary persistent event-driven orchestration may provide most benefit. The current owner/user refinement rejects only the **architecture-equivalence** interpretation. A durable workflow remains a comparator for latency, memory, routing and isolated outcomes. The scientifically valid counter is architecture compression **inside a closed loop**.

## C3 — Re-entry as structure vs re-entry as ID continuity

Current GWT OOB work demonstrates a dangerous possibility: a provenance-broken shuffled re-entry can preserve outcome and caller-carried identifiers yet look closed. Therefore `same outcome + matching IDs != closed causal loop`. Closure requires producer/storage/consumer binding.

## C4 — GWT valuable vs NativeModelWorkspace already exists

The 2026 native-workspace evidence makes ClayGWT neither redundant nor proven. It creates a factorial question: complementary, redundant, antagonistic, or model-specific. MOC keeps R0 NativeModelWorkspace optional and R1 ClayGWT explicit until the queued experiment resolves interaction.

## C5 — Higher-order representation vs pairwise reducibility

PEID/PID-like work supports genuine synergy; 2026 hypergraph reducibility research demonstrates that some higher-order-looking systems are exactly pairwise-reducible. Resolution: pairwise-first + irreducibility gate. Higher order is earned, never assumed from representation form.

## C6 — Event sourcing/replay vs UnifiedDB simplicity

Event-sourced agent research gives replay/fork/lineage benefits but does not establish outcome superiority. Frank v0.1 has one active cognitive presence and SQLite-centric state. Resolution: selective event sourcing for replay/authority-critical transitions, rebuildable projections elsewhere; universal event sourcing remains countercandidate.

## C7 — Bitemporal truth vs existing epochs

Temporal-memory work strengthens valid/current/historical separation. But Frank already has epochs and provenance. Resolution: bitemporal semantics are a candidate only if they beat epoch-only state on conflict/stale-fact tasks at acceptable write/storage cost.

## C8 — Reward fold exactly-once vs currentness

The current reward candidate passes duplicate-safe bounded folding but the parallel Hypofusion identifies source-frontier completeness as independent. Resolution: `exactly-once != current snapshot`. Reward projection must bind exact authoritative frontier or prove writer exclusion.

## C9 — Consumer verification general law vs universal CBPC implementation

SLSA/CapLease-like evidence strengthens consumer-side verification and durable authorization state. Yet build/state/GWT/reward/data domains differ. Resolution: common semantic vocabulary is plausible; one universal runtime primitive remains unpromoted until it beats local typed guards.

## C10 — Strong typing vs compiler practicality

Current main now has a bounded executable ClayCode evaluator/package slice with 200,576 `decide_effect` comparisons and zero mismatches, while much of the language/compiler frontier remains open. Resolution: maximize semantic hardness at critical boundaries, fail closed on unknowns, lower verified pure closures incrementally; do not invent missing language semantics to satisfy architecture enthusiasm.

## C11 — Latent observation useful vs control fragility

LCOP/J-space/NLA/persona work supports observation and some causal interventions, but decodability, actionability, identifiability and transfer are distinct. Resolution: R0 latent plane is optional evidence; no control promotion without observability→intervention→incremental-outcome triad and exact-build transfer tests.

## C12 — Higher-order Frank value not one scalar

The user's claim is deliberately not collapsed into a single benchmark scalar. MOC predicts a **signature** across state continuity, recovery, goal persistence, causal correction, provenance-valid learning, adaptive recurrence and OOD/interruption behavior. Failure to find one scalar does not by itself falsify operational closure; failure of lesions/compressions to create any structured difference would weaken specific MOC rings/mechanisms.
