# Avatar GO G1 — timebase + opt-in measurement

## Exact files changed
- `buehne.html`
- `G1_REPORT.md`

## Concrete defect / hypothesis
The live breathing oscillator advanced by a fixed `0.006` radians per rendered frame. Its period therefore depended on display/render FPS; at ~60 fps it was ~17.45 s, outside the accepted 3.8–5.6 s breathing contract. This is a temporal-coherence defect, not an art-style change.

## G1 change
- Advance breathing from rAF elapsed milliseconds.
- Bound each breathing period to 3800–5600 ms.
- Clamp one-frame dt to 50 ms to avoid tab/GC jumps.
- Add zero-dependency performance instrumentation only for `?probe=1`; normal rendering returns immediately from the probe script.
- No eye, mouth, asset, head-registration, film-look, background, or identity change in G1.

## Why this should improve realism
Breathing cadence becomes physiologically plausible and invariant to monitor/render FPS. Existing transform amplitudes and image identity remain unchanged.

## Possible regressions
- Existing downstream code might have implicitly depended on the old slow phase velocity.
- Long-task/heap fields are browser-dependent and may be null/unsupported.
- Headless measurements are diagnostic, not equivalent to the visible X11 window.

2. Assert old frame-count phase increment absent.
3. Assert rAF calls `atmen(t)`.

5. Load without `probe=1` and verify no `#frank-perf-probe` element.
6. Compare p95/p99/max/long tasks and JS errors before promotion.
