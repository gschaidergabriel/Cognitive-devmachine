# FRANK C6 — Negative Results, Boundaries & Non-Claims

The Clay-native FRANK target itself is owner-fixed. These negative results constrain **how** it can be realized and what evidence must not be overstated.

## N-C6-001 — Prompting/few-shot is not Clay internalization

An untrained Groq `llama-3.1-8b-instant` was given Mini-Clay rules and then eight demonstrations. It still ignored the requested target protocol and generated an attempted Python interpreter. A simplified precompiled view also elicited Python rather than the requested decisions.

**Result:** current proxy rejects “a few examples make a generic small model native in Clay.”

**Does not imply:** full-model target training will fail.

## N-C6-002 — Clay loss/purity cannot be the only training target

External language-adaptation work shows target-language CPT can lose downstream/source capabilities before target validation perplexity clearly reveals it. Full fine-tuning in a 2026 language-adaptation study produced much larger source-task degradation than a protected-update method.

**Result:** Clay perplexity/output purity alone is not a promotion metric.

**Consequence:** every checkpoint carries retained-capability and OOD execution shadows.

## N-C6-003 — “Everything Clay” does not mean “everything textual”

C6 deterministic sizing shows a text representation of high-dimensional numeric arrays can be >2x the bytes of an illustrative typed binary layout before tokenizer/KV overhead is even counted.

**Result:** literal text is not the universal Clay physical representation.

**Consequence:** ClayVector/Tensor semantics use typed headers + compact numeric payloads.

## N-C6-004 — “Everything Clay” does not require one physical database

ClayGraph G1d and FRANK C5/G10 retain exact authority, graph projections, effect/outbox and isolated transactional boundaries. One semantic world can be implemented by plural physical stores.

**Result:** physical merge is an optimization hypothesis, not part of the fixed Clay-native concept.

## N-C6-005 — Shared language does not solve stale/mixed causal state

CC9/C5/H3 already show that graph epoch, activation epoch, exact frame, selector and projection can advance independently.

**Result:** semantic unity does not remove epochs, basis witnesses or operation-specific causal slices.

## N-C6-006 — Shared language does not collapse GWT causal stages

GWT Run 4 constructed a null where a bundled graph+workspace+projection contrast was large while the clean workspace effect was exactly zero by construction.

**Result:** `GRAPH_PRIOR`, candidate formation, workspace selection/ignition, projection/uptake and re-entry remain separately intervenable even when every representation is Clay.

## N-C6-007 — Native ClayGraph/model coupling is not automatically safe

2026 memory-poisoning research shows persistent/graph memory can steer tool selection and agent behavior even when poisoned information appears as ordinary memory. G9/G10 independently identify record-vs-selection integrity.

**Result:** tighter native alignment can plausibly amplify a bad relation/selector as well as a good one.

**Consequence:** epistemic typing, selection receipts, exact anchors and effect-bound revalidation become stronger requirements.

## N-C6-008 — Record provenance is not selector provenance

Authentic records can be routed into cognition by a corrupted/noisy graph/query structure.

**Result:** cryptographically or provenance-valid records alone do not secure native ClayGraph cognition.

## N-C6-009 — Hash/version identity is not semantic correctness

C6 synthetic cache test caught stale schema versions but deliberately wrong semantic computations that produced a valid new hash remained undetected.

**Result:** `hash == expected` only proves identity/integrity relative to what was hashed.

**Consequence:** critical Clay compilers need differential/reference/property/mutation tests.

## N-C6-010 — Typed ClayVector metadata is not mathematical truth

Axis/unit/basis typing catches many interface faults; semantic wrong-result-with-valid-rehash does not.

**Result:** typed values prevent classes of mismatch, not incorrect algorithms.

## N-C6-011 — Pairwise relations remain lossy

Hyperposition H3 shows pairwise flattening can create false role combinations as relation overlap grows.

**Result:** a native language cannot recover information that the storage representation discarded. Relation-instance/n-ary role identity stays canonical.

## N-C6-012 — Activation is still not truth

A Clay-native activation token/value is still a salience/accessibility state. It cannot change evidence status, semantic fact status or capability authority.

## N-C6-013 — Activation is still not GWT ignition

ClayGraph activation can bias candidate availability; GWT competition/selection/ignition is a downstream causal stage.

## N-C6-014 — Same-language recurrence is not emergence

Emergenz E1 strengthens this boundary: recurrence can be produced by echo, role identity can be faked by member overlap, endpoint-only rescue can mimic success and stage bundling can inflate causal effects.

**Result:** Clay-native continuity/self-reference does not by itself establish causal emergence, still less phenomenal consciousness.

## N-C6-015 — Hidden activations are not proven to be literal discrete Clay

Even if the model generates only Clay and explicit deliberation is Clay, transformer hidden states remain continuous distributed representations.

**Result:** “FRANK thinks in Clay” is a target engineering statement about its native explicit symbolic cognition and learned causal features, not evidence that every hidden tensor is a Clay sentence.

## N-C6-016 — The simple homoiconic injection sanity test was non-discriminating

Both an untyped and a typed 8-case Groq memory test returned the underlying facts. The typed arm even drifted from the requested output format.

**Result:** this toy does not demonstrate that typed Clay solves prompt/memory injection.

**Next:** adaptive indirect-injection, graph-poisoning and privilege-confusion tests on the trained target.

## N-C6-017 — Native full fine tune may overwrite abliteration changes

Full-model optimization changes the complete parameter set. The project cannot assume properties of the starting abliterated checkpoint survive Clay adaptation.

**Result:** abliteration-relevant behavior/activation probes must be rerun at major training checkpoints.

## N-C6-018 — Full-model target does not make frozen/LoRA evidence irrelevant

Selective/frozen methods remain useful *scientific comparison arms* for measuring forgetting/plasticity tradeoffs.

**Boundary:** they are not the target architecture/training recipe.

## N-C6-019 — Old vocabulary need not be deleted for Clay to be the native output language

Removing/reindexing the entire pretrained vocabulary would discard useful input/knowledge interfaces and create a large embedding relearning problem.

**Result:** preserving old token IDs for input while enforcing/training Clay canonical output is a stronger first candidate than purity-by-deletion.

## N-C6-020 — Needle independence does not imply Needle accuracy

The C6 reference router correctly prevented model/memory overrides of Needle's route class. That says nothing about whether Needle itself classified correctly.

**Result:** Needle needs its own confusion/abstention/latency/poisoning benchmark.

## N-C6-021 — Needle is not effect authority

Needle can be the sole foreign semantic classifier and route source without becoming permission authority. Capability/effect validity remains deterministic Clay-authored semantics enforced by compiled runtime.

## N-C6-022 — Self-description is not self-authority

The architecture being written in the same language the model speaks creates powerful self-inspection, but an ordinary model-generated Clay proposal cannot rewrite owner-fixed contracts or grant capabilities.

## N-C6-023 — Semantic monism does not mean one update timescale

Weights, persistent ClayGraph state and transient activation/KV remain distinct memory lifecycles.

**Result:** current mutable world facts should not be baked into weights merely for semantic purity.

## N-C6-024 — Current ClayGraph G1d is still HOLD

Making the target model Clay-native increases the importance of G1d, but does not retroactively prove its cognitive benefit. Current activation measurements show implementation feasibility, not improved target cognition.

## N-C6-025 — Current 8B proxy is not target 4B/full-FT evidence

Groq `llama-3.1-8b-instant` experiments are explicitly `8b_proxy_for_4b`. They are useful baselines/representation probes only.

## N-C6-026 — Cross-branch agreement is not independent replication

C6, Clay G10, CC9, C5, H3, GWT4 and E1 share substantial same-day evidence/actor ancestry. Goodman/ancestry collapse remains mandatory.

## N-C6-027 — Human-readable output is not a second internal semantic architecture

If FRANK exposes human-language surface text, it must be treated as an I/O projection/payload of Clay semantics, not an alternate persistent cognitive truth system. The production realization mechanism remains open.

## N-C6-028 — Compactness is not automatically reasoning quality

Past XENO/ClayCode experiments show token/output efficiency can improve while current untrained small-model interpretation remains brittle. Full native training must demonstrate semantic execution, not just shorter sequences.
