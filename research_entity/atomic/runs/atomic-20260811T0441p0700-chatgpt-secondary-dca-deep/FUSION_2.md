# FUSION 2 — after external collision

Broad DCA novelty collapses. Relevance-preserving compression, hypothesis-discriminating information selection, query-relative completeness and why-not provenance are established research families.

The surviving Frank-specific composition is narrower:

`authoritative current UnifiedDB projection`
`-> task/decision/hypothesis material distinction set`
`-> mandatory hard witnesses (identity, direct user intent, authority/recovery constraints as applicable)`
`-> cost-bounded conventional distinguishing selector`
`-> selected evidence payload`
`+ DistinctionWitness (which material alternatives remain distinguishable / unresolved)`
`+ QueryCompletenessWitness (for which negative claims absence is actually certified)`
`+ CurrentnessWitness (semantic/state epoch + selector/dependency hashes)`
`-> model-visible CognitiveView`

The model-facing semantic domain becomes at least three-valued for missing material:

- PRESENT_IN_ASSEMBLY;
- CERTIFIED_ABSENT_FOR_QUERY_SCOPE;
- NOT_LOADED_OR_INCOMPLETE_UNKNOWN.

A fourth operational state, STALE_CERTIFICATE, forces refresh and may not be interpreted as absence.

## Important collision with current G9

G9 already contains `ViewDelta.dependency_hash` and `selector_hash`. Therefore DCA should reuse those primitives rather than invent a second invalidation subsystem. The research delta is an interface law around those existing mechanisms, not a parallel database.

## Strongest conventional competitor

Normal query-aware CognitiveView + decision-focused weighted set cover + ordinary query-completeness metadata + existing dependency/selector hashes can plausibly implement identical semantics. DCA survives only if making these components one typed, non-collapsible boundary prevents measurable model/runtime errors or bypasses that the conventional composition misses.

`NOVEL_COMBINATION_CANDIDATE / PROJECT_SPECIFIC_CONTEXT_BOUNDARY`
