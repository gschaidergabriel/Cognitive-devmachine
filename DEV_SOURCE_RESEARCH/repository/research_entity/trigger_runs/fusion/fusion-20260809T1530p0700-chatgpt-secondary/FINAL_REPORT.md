## F1 — Whole-mesh synthesis

### Synthesis A — Unified Memory helps perception only through evidence-constrained priors

The owner-fixed architecture remains intact:

`Retina sees now + Unified Memory knows before -> compare -> recognize / uncertain / conflict -> learn back into Unified Memory`

Fusion strengthens the boundary rather than weakening it:

This directly preserves the target that more verified knowledge should help FRANK recognize familiar things more efficiently while preventing memory-driven hallucinated perception.

### Synthesis B — Two independent gates are required as the current best working architecture

Several post-L0 fields initially look similar because they all touch adaptive visual memory. Anti-echo analysis shows they are not the same control surface:

**Gate 1 — durable adaptive-state promotion**

Controls whether candidate learned state may become persistent/current:

- GOLD/SILVER evidence admission;
- provenance and trusted-example lineage;
- candidate/current version identity;
- poisoning/staleness checks;
- atomic promotion;
- last-known-good rollback;
- crash/replay receipt.

**Gate 2 — current recognition/familiarity validity**

Controls whether current perception may take a fast familiar path:

- classifier/prototype version coherence;
- feature-backbone compatibility;
- calibration domain/version/age/validity;
- open-set/near-confuser evidence;
- context/semantic consistency;
- explicit conflict/unknown state.

The first prevents bad learning from becoming durable truth-like state. The second prevents a cleanly learned but stale, shifted or context-incompatible state from being over-trusted during recognition.

The invalidated concurrent familiarity field remains useful evidence, but receives zero independent-replication credit because its ancestry substantially overlaps Proof-Carrying Adaptive State.

### Synthesis C — adaptive update policy should be regime-conditioned

CAMRL/reconsolidation-style gating is plausible for abrupt contradiction or shock, but the preserved synthetic negative result matters: the conservative CAMRL-like policy was about **96.6% worse MSE than EWMA on clean smooth drift**.

Fusion therefore rejects a universal reconsolidation gate. The stronger architecture hypothesis is:

- coherent smooth drift -> low-friction bounded incremental update;
- abrupt conflict/prediction error/version break -> challenged candidate, extra sensing, context/view split, reconsolidation-like validation;
- raw prior observation provenance is never overwritten.

The biological reconsolidation literature is used only as an analogy supporting the existence of boundary conditions/prediction-error-sensitive update regimes; it is not FRANK evidence.

### Synthesis D — causal re-entry needs an evidence ladder, not a directionality score

The new common-driver experiment demonstrated a critical identifiability failure: strong lagged directed prediction can arise even when the direct A->B causal edge is zero. Conditioning removed the spurious coefficient in the simple known-driver setup; matched lesion cleanly separated the zero-edge and true-edge systems.

Fusion therefore refines the evidence ladder:

1. association / lagged prediction;
2. directed-flow / TE-like screening;
3. conditioned flow with explicit conditioning-set/common-driver identity;
4. intervention-supported edge;
5. rescue/restoration-supported edge;
6. replicated live/generalized causal status where warranted.

ClayGraph should preserve these statuses as different edge evidence types. GWT and Emergenz must not convert level 1–3 into causal truth. Hyperposition must treat shared scheduler/state/topology as candidate common drivers and retain topology/delay/intervention identity in receipts.

## F3 — Fusion experiment: two-gate adaptive-memory proxy

A 100-replicate synthetic online proxy compared:

1. naive self-training;
2. evidence-admission-only updates;
3. evidence admission plus an independent imperfect context/validity gate.

Mean results:

- naive unknown false familiarity: **85.48%**;
- admission-only unknown false familiarity: **78.93%**;
- dual-gate proxy unknown false familiarity: **14.66%**;
- admission-only bad persistent update fraction: **0%** in this setup;
- dual-gate known fast-path acceptance: **83.22%** versus **90.10%** for admission-only.

Interpretation:

- update admission can stop self-generated bad state from contaminating persistent learning;
- that alone does not solve open-set recognition;
- a second recognition-validity surface can sharply reduce false familiarity, but trades off fast-path coverage;
- therefore both gates should be independently ablated and jointly optimized on real Retina replay.

This is a 2D synthetic proxy and **not** a live FRANK/Retina result.
