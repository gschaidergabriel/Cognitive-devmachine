# FUSION 2 — external collision and recombination

External research collapses the broad novelty claim. Counterexample-/oracle-guided synthesis is established; SyMO explicitly supports black-box oracles that can compile or execute functions that are hard to encode in SMT. Active automata learning likewise infers black-box behavioral models, while its literature warns that active interaction overhead can become the bottleneck. Proof-carrying agent actions and information-flow control also remove any claim that witness-bearing governance or deterministic authority labels are novel by themselves.

Therefore ECT is narrowed to a **project-specific composition**:

`finite declared CallContract domain + current self.root/epoch binding + sandbox-only verifier + distinguishing diagnostic witness + exact final verification + fail-closed unresolved Hyperposition`.

The key scientific boundary is oracle strength. Tests cannot prove a general opaque callable contract. Exact admission is defensible only when the candidate domain is finite and complete for the obligation and the verifier/witness semantics are independently trusted for that domain. If the verifier supplies only Boolean mismatch, ECT should not pretend to have learned semantics. If exact authenticated metadata exists, use it directly.

No ClayCode language change is required by the proxy: current records, sets, epochs, provenance and effect boundaries can express the candidate.
