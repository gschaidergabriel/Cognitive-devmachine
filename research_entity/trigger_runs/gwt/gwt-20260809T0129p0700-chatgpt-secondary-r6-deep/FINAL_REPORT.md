## 1. Executive result

R5's strongest correction was:

> `system WorkspaceEpisode != model-internal workspace != effect authority`

R6 keeps that separation and finds that the word **broadcast** itself is still too compressed.

The new core law is:

> **`global addressability != delivery != reconstruction != uptake != causal use != outcome != re-entry`**

A workspace item can be globally addressable yet unused. It can be delivered but reconstructed incorrectly. It can be reconstructed correctly but ignored by the receiver. A receiver can take it up without a measurable local effect. A set of receiver effects can still fail to produce the expected joint outcome or future re-entry.

R6 therefore proposes **Receiver-Causal Workspace Closure (RCWC)**. Instead of scoring one scalar such as “globality” or “broadcast strength”, a workspace episode carries:

`BroadcastEnvelope -> ReceiverReceipt[] -> CausalBroadcastMatrix -> BroadcastClosureReceipt -> provenance-bound re-entry`.

The corresponding ignition correction is:

> **`gate opening != sigmoid steepness != endogenous ignition != causal broadcast`**

And the learning correction, strengthened by fresh Hyperposition H6, is:

> **`broadcast topology != causal-credit topology != authority topology`**

The engineering implication is potentially important for FRANK: a useful artificial global workspace may be **globally addressable but selectively causally delivered**, instead of literally pushing every selected state to every possible consumer. That is an OPEN efficiency hypothesis, not yet a promoted architecture fact.

### 3.2 Clay G12 — continuity is not cognitive correctness

Clay G12 established the project-side law:

> `certified continuity != cognitive correctness != authority`.

Its collection-topology calibration is directly relevant to GWT: type-erasing collection semantics changed top-1 candidate outcomes in **48.381%** of 100,000 cases and top-3 membership in **72.679%**. ### 3.3 ClayGraph — activation is a prior, not ignition

Current ClayGraph work separates:

`query -> route -> candidate search space -> activation/Assembly -> CandidateSet`.

Truthful graph activation can improve candidate recall before workspace competition; shuffled activation can harm it. Therefore a change in output after “enabling the workspace stack” is not attributable to GWT if graph field/search-space identity changed at the same time.

### 3.4 UnifiedDB — query and search-space identity are causal state

UnifiedDB U2 retains one logical semantic fabric while preserving physical and epistemic role distinctions. For GWT attribution, R6 treats at least these as causal identity:

- query identity;

### 3.5 ClayCode — exact semantics before model interpretation

CC12 established that `SET`, `ORDERED`, `MULTISET`, and `WEIGHTED` semantics cannot be erased safely. R6 extends the same principle to receiver receipts: exact causal primitives that can be computed deterministically should not be rediscovered from prose by a small reader model.

R6's receiver causal matrix is a better input to later emergence testing than a broadcast counter, but does not itself establish emergence.

## 4. External research synthesis

R6 separates primary/peer-reviewed work, preprints, implementation code and community evidence.

### 4.1 Strongest current model-internal workspace evidence

Gurnee et al. (2026), `Verbalizable Representations Form a Global Workspace in Language Models`, report a compact internal **J-space** in Claude-family language models. Its contents are verbalizable, task-modulatable, used in multi-step internal reasoning and flexibly reusable by downstream computations. Intervention and lesion results make this substantially stronger than passive probe correlation.

The same work also states important limits: transformer LMs do not cleanly reproduce the full biological architecture of specialized encapsulated processors, their within-pass broadcast differs from biological recurrence, and sharp biological-style ignition remains unclear.

R6 therefore accepts:

> **model-internal workspace-like mechanism: externally supported**

but rejects:

> **Claude J-space == complete biological GNW == FRANK/Qwen GWT**.

### 4.2 Broadcast is not generic integration

Network-neuroscience work on GNW distinguishes broadcasting from generic communication/integration. One-to-all directed dissemination is a more specific mechanism than high graph integration. This matters because many passive network/globality signatures can arise without a causal workspace broadcaster.

R6 operationalizes this with explicit common-driver and addressable-but-ignored nulls.

### 4.3 Prompt/projection order is causal

ACL Findings 2026 reports more than 14 percentage points of order sensitivity across tested prompt arrangements and attributes it to causal-attention visibility. For FRANK this means reader projection/order cannot be treated as cosmetic serialization after a WorkspaceEpisode has been selected.

### 4.4 Causal abstraction as intervention framework

The 2025 JMLR causal-abstraction framework provides a useful general language for relating activation interventions, patching, tracing, steering and higher-level causal claims. R6 uses the same discipline conceptually: passive decodability is weaker than intervention-mediated causal abstraction.

### 4.5 Adversarial consciousness-theory evidence

The 2025 preregistered adversarial collaboration testing GNWT and IIT found results that support some predictions while challenging key tenets of both theories. R6 takes the methodological lesson rather than claiming theory resolution: preregister differential predictions and preserve disconfirming evidence.

No AI workspace result in R6 is interpreted as phenomenal-consciousness evidence.

### 4.6 Ignition Index — useful proposal, insufficient alone

The 2026 `Ignition Index` preprint operationalizes sigmoid-like transition steepness and reports architecture-level differences, including stronger recurrence-axis ignition in Huginn. This is an interesting descriptive candidate metric.

R6's countermodel shows why steepness alone cannot carry a mechanistic claim: a history-free configured threshold can generate an excellent sigmoid without endogenous recurrent ignition.

### 4.7 Qwen3-4B J-space and quantization

A 2026 preprint (`Silent Alarm`) applies a J-space-style protocol to Qwen3-4B and other models across BF16/INT8/INT4 and reports internal-recognition changes across precision regimes. This is important because it makes the target-model research direction technically plausible and warns that quantization belongs inside the GWT experimental identity, not only the deployment metadata.

It remains preprint evidence and is not a FRANK result.

### 4.8 Latent communication and efficient rails

Recent multi-agent latent-communication work reports substantial communication/inference savings in selected settings. These papers support testing compact or latent receiver rails, but do not establish GWT broadcast, semantic equivalence or authority safety. RCWC therefore requires receiver reconstruction and causal-use receipts even when a compressed rail performs well on average.

### 4.9 Community Qwen stress tests

A Qwen3-4B community J-space entropy stress test across thousands of examples reports that entropy can catch some high-confidence factual errors but transfers poorly to internalized misconceptions and uses task-dependent thresholds. R6 treats this only as community evidence, but it reinforces a useful constraint:

> **workspace clarity/entropy != truth**.

## 5. Fusion 1 — the missing variable is the receiver

Earlier GWT work had already separated:

- candidate generation;
- competition;
- selection;
- gate;
- projection;
- outcome;
- re-entry.

R6 asks a stricter question:

> If an episode is “broadcast”, which receiver actually received which content, reconstructed it how, used it how, and caused what?

Without that information, at least four failure modes are observationally confounded:

1. **COMMON_DRIVER_FANOUT** — workspace and receivers covary because another state causes both;
2. **ADDRESSABLE_ONLY** — everyone could read the workspace, but nobody causally uses it;
3. **RECONSTRUCTION_FAILURE** — correct episode, wrong receiver view;
4. **UPTAKE_FAILURE** — correct receiver view, but no causal use.

That motivates RCWC.

## 6. RCWC architecture

The full machine-readable candidate is in `RCWC_R6_ARCHITECTURE.json`.

### Stage chain

`canonical basis/event state`
`-> UnifiedDB query/search-space/TCQS selection`
`-> ClayGraph route/activation/Assembly`
`-> CandidateSet`
`-> competition`
`-> winner/WorkspaceEpisode`
`-> BroadcastPlan/BroadcastEnvelope`
`-> receiver delivery`
`-> receiver reconstruction`
`-> receiver uptake`
`-> receiver local causal effect`
`-> joint outcome`
`-> provenance-bound re-entry`
`-> next eligible state`.

### BroadcastEnvelope

Declares:

- episode/basis/candidate/winner identity;
- receiver-universe identity and hash;
- broadcast policy;
- projection identity;
- capacity policy;
- source epoch/provenance.

It proves **intent and identity**, not receiver uptake.

### ReceiverReceipt

Records per receiver:

- addressability;
- actual delivery;
- payload hash;
- reconstruction identity/validity;
- uptake measurement/intervention;
- local effect receipt;
- authority-boundary receipt.

### CausalBroadcastMatrix

R6 refuses to reduce the entire mechanism to one scalar. Each episode × receiver cell carries a stage vector:

`addressable, delivered, reconstructed, uptake, local_effect, outcome_contribution, reentry_contribution`.

### BroadcastClosureReceipt

A workspace claim moves from OPEN/PARTIAL toward causal closure only after:

- receiver universe is declared;
- common-driver null is addressed;
- addressable-but-ignored null is addressed;
- causal receiver set is identified;
- joint outcome is linked;
- re-entry is separately measured where claimed.

### Broadcast policies

RCWC distinguishes:

- `ALL_TO_ALL` — literal push to full receiver universe;
- `SELECTIVE_CAUSAL` — push only to predicted relevant receivers;
- `GLOBAL_ADDRESSABLE_PULL` — globally readable, pulled on demand;
- `HYBRID` — selective push plus audited pull access.

This lets FRANK test an efficient engineered workspace without silently redefining every routing mode as the same biological broadcast mechanism.

> **High global correlation/integration cannot certify workspace broadcast.**

This is a method-level result, not a live FRANK estimate.

## 8. Experiment B — configured thresholds can fake ignition-like curves

`EXP-GWT-R6-CONFIGURED-IGNITION-CONFOUND-002` asks whether a steep nonlinear response requires endogenous ignition.

### History-free threshold arm

A continuously varying internal evidence variable passes through a simple deterministic threshold.

Results:

- sigmoid fit `R² = 0.9998416`;
- `P(on|-3) = 0.000625`;
- `P(on|0) = 0.487`;
- `P(on|+3) = 0.998875`;
- mean up/down difference: **0.003166**.

The curve looks almost perfectly ignition-like, yet the mechanism has no recurrent amplification or history dependence.

### Recurrent toy control

A toy recurrent mechanism produced:

- mean up/down gap **0.0682**;
- maximum gap **0.43**;
- substantial history-sensitive region around the transition.

### E2B replication

Independent E2B threshold control:

- `P(-3)=0.001`;
- `P(0)=0.50125`;
- `P(+3)=0.99875`;
- mean up/down difference **0.0042869**.

### Consequence

R6 does **not** reject sigmoid steepness as a useful descriptor. It rejects the inference:

> `steep sigmoid -> endogenous GWT ignition`.

A stronger `IgnitionReceipt` should include a configured-threshold null plus at least one history/recurrence or mechanism-specific lesion/rescue discriminator.

## 10. Experiment D — generic 4B receiver reconstruction

This is the most operationally useful new R6 result.

### Model

`nvidia/nemotron-mini-4b-instruct` through NVIDIA Hosted NIM.

This is a **generic 4B proxy**, not Qwen3-4B and not live FRANK.

Final validation: GitHub Actions run `31273195345`, job `93142504735`.

The task was deliberately simple: classify 12 receiver receipts as:

- `BROADCAST` if `do(W)` has a nonzero receiver effect, positive or negative;
- `COMMON_DRIVER` if `do(W)=0` and a common-driver test is positive;
- `ADDRESSABLE_ONLY` otherwise.

### Arm A — prose/list + raw numeric effect arrays

- prompt tokens: **524**;
- output completeness: **11/12**;
- accuracy counting omission as wrong: **4/12 = 33.3%**.

The reader repeatedly failed to infer the causal label from raw effect arrays.

### Arm B — typed IDs + raw numeric effect arrays

Final repeat:

- prompt tokens: **650**;
- completeness: **10/12**;
- accuracy: **2/12 = 16.7%**.

A prior provider execution at temperature zero produced a different answer profile. R6 preserves this as runtime/serving nondeterminism evidence rather than choosing the nicer run.

Important result:

> **typing and IDs alone did not solve the problem.**

The model was still being asked to perform exact causal normalization from raw arrays.

### Arm C — typed IDs + deterministic causal normalization

Before the model call, exact arithmetic was lowered into:

- `doW_effect = ZERO | NONZERO`;
- `common_driver = TRUE | FALSE`;
- sign retained where relevant.

Results:

- prompt tokens: **410**;
- completeness: **12/12**;
- accuracy: **12/12 = 100%**.

### Interpretation

This is not a pure “format A versus format B” result. Arm C deliberately **moves an exact computation out of the model**.

That is precisely the architecture hypothesis:

> **deterministic facts should be deterministically lowered before a small generative receiver interprets them.**

The raw evidence and provenance remain available for audit, but the model does not have to rediscover arithmetic, identity or authority-critical predicates from prose.

This creates a much sharper definition of **receiver reconstruction** inside GWT. A workspace can be perfectly selected and delivered, yet the cognitive effect can fail because the receiver reconstructs the causal state incorrectly.

## 12. Broadcast versus learning credit

Hyperposition H6 creates a second major R6 correction.

Suppose a workspace episode is selected, broadcast, used by several receivers and the final outcome is good. It still does not follow that every exposed candidate, graph item or receiver deserves positive learning credit.

R6 therefore keeps four different topologies:

1. **selection/workspace topology** — what wins;
2. **broadcast topology** — what is addressable/delivered to whom;
3. **causal-credit topology** — what is allowed to learn from which outcome;
4. **authority topology** — what is allowed to act.

No one topology may silently derive the next.

## 13. Re-entry and recurrent closure

R5 already proposed external re-entry as a plausible scaffold for multi-turn recurrence. R6 tightens the required evidence.

A re-entry result counts as GWT support only if:

- the source episode is identified;
- provenance and source epoch are valid;
- truthful re-entry changes later state/behavior in the predicted direction;
- shuffled/stale/revoked re-entry does not provide the same rescue;
- restoration survives beyond the current endpoint into future trajectory.

This separates real recurrent causal closure from persistence that merely looks continuous.

The key nested prediction remains:

> if external re-entry truly compensates for limited model-internal recurrence, truthful re-entry should partially rescue cross-turn performance when the internal workspace is lesioned, while shuffled/stale re-entry should fail.

## 21. What would count as evidence for the new model?

RCWC gains support if target-Qwen/live-FRANK experiments show all of the following:

1. workspace interventions cause receiver-specific effects after upstream candidate/query identity is pinned;
2. common-driver and addressable-only controls do not show the same causal effect;
3. receiver reconstruction/uptake receipts predict failures that a single globality score misses;
4. internal-workspace lesions interact with system workspace and/or truthful external re-entry in the predicted way;
5. projection rail/order changes receiver reconstruction without changing WorkspaceEpisode identity;
6. at least one selective/hybrid broadcast condition improves cost without losing causal receiver utility;
7. re-entry restoration changes future trajectory and beats shuffled/stale controls.

RCWC is weakened if these receiver stages add no predictive/interventional value beyond the existing WorkspaceEpisode/outcome model.

## 25. Final synthesis

The deepest R6 change is conceptual but directly implementable:

> A global workspace is not adequately characterized by “something became globally available.”

For an engineered cognitive system, the scientifically useful chain is:

> **what became eligible -> what won -> what was declared available -> what each receiver actually got -> what each receiver reconstructed -> what it used -> what changed -> what outcome followed -> what legitimately re-entered the system.**

This makes GWT research simultaneously more causal, more debuggable and safer.

It also exposes a new optimization target. FRANK may not need to push every workspace item everywhere. A better artificial workspace might maintain **global addressability, bounded competition and audited causal reach**, while delivering only to receivers that need the state and preserving pull access for the rest.
