FranKenstein terminal organ. Foreground owner UI over the EXISTING
FranKenstein runtime. This module is an adapter, not a second brain: no
daemon, no new database, no direct SQLite writes. Session/turn state enters
through the installed ``stern.py`` hooks, DB continuity through ``handoff()``,
ChatGPT through the existing browser harness, and completion through
``reconcile()``. Browser replies are harvested ONLY from the exact
conversation URL created by this turn. The old global ``chatgpt_ernten()``
scans a shared backlog and is therefore intentionally not the interactive-
terminal path.
