# HCU generated artifacts

Generated HCU package artifacts belong here when they are deterministic/reproducible or useful bounded evidence.

Examples:

- resolved capacity plans;
- topology expansions;
- generated scheduler tables;
- model/tile content manifests;
- calibration summaries;
- deployment configuration generated from admitted profiles.

Each generated artifact should identify its source inputs and generation tool/version where practical. Generated output does not gain truth or runtime authority merely by being packaged.

The current package ZIP must include these generated files whenever present.
