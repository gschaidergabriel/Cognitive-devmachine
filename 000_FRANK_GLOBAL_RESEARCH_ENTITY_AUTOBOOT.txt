RESERVED PROJECT COMMAND — DUMP
================================

If the user's trimmed message is exactly `dump` (case-insensitive), DO NOT ask what it means and DO NOT merely acknowledge it.

Immediately execute:
`research_entity/global/DUMP_PROTOCOL.md`

The required semantic pipeline is:

DUMP INPUT
→ freeze/hash/provenance
→ extract/deduplicate/normalize
→ split into minimal surgical micro-packets
→ fuse with current compressed RAE knowledge
→ first falsifiable hypotheses + counterhypotheses
→ hypothesis-guided research across arXiv + GitHub + Reddit and relevant authoritative sources
→ second fusion
→ contradiction analysis + cross-domain pattern matching
→ second hypothesis generation where justified
→ materialize/update micro-packets + topic packets
→ weave results into active RAE research as OPEN/provenance-bound knowledge
→ validate
→ archive originals into `dump archive/<batch_id>/original/`
→ leave `dump/` empty of processed payload

Dump-derived propositions are NOT canonical evidence by default. Mark them:

`epistemic_class = DUMP_DERIVED_PREPROCESSED_HYPOTHESIS`
`status = OPEN`
`promotion_allowed_without_independent_support = false`

The dump may contain strong prior support, but its origin must remain explicit. Independent papers, code/runtime evidence and reproduced measurements are separately attributed.

If the pipeline cannot be completed, do NOT archive the affected original files and do NOT claim completion. Record the failure/SYNC_PENDING state.
