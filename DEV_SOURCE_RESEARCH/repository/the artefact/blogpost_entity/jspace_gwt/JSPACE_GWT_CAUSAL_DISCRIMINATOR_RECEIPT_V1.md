## Why this exists

ZERO must distinguish three different statements:

1. a J-Space/workspace observation existed;
2. that observation was projected/displayed/injected somewhere;
3. changing the J-Space/workspace state causally changed downstream cognition/behavior.

Only (3) is a causal-use question. A normal runtime receipt that contains J-Space references or a GWT winner cannot establish it.

This contract therefore binds one exact matched discriminator:

```text
baseline
vs
TARGET: J-Space / workspace perturbation
vs
CONTROL: capacity-matched non-J-Space perturbation
```

The receipt is intentionally non-promotional. A single valid discriminator may be retained as bounded research evidence, but it MUST NOT mint causal-use, Whole-GWT, factual-truth, model-quality, consciousness, AGI, or whole-product credit.

Required law:

```text
JSPACE_OBSERVED != JSPACE_CAUSALLY_USED
JSPACE_PROJECTED != JSPACE_CAUSALLY_USED
ONE_MATCHED_DISCRIMINATOR != CAUSAL_PROMOTION
JSPACE_CAUSAL_DISCRIMINATOR_RECEIPT/v1 -> causal_use_credit = ZERO_SINGLE_TRIAL
```

## Two admitted discriminator modes

### `LOCAL_LATENT`

For the bundled/open hookable cognition core when exact activation access exists.

Required arms:

- `baseline`: no intervention;
- `target`: `JSPACE_TARGET_ABLATION`;
- `control`: `MATCHED_NON_JSPACE_ABLATION`.

The three arms must bind the same task, input, decoding configuration, engine identity and entity generation. The control must consume a comparable intervention budget/capacity while targeting a non-J-Space direction or population under the experiment protocol.

This mode requires local hidden-state access and is offline under the current local discriminator contract.

### `COMPILED_EXTERNAL`

For Claude Code or another closed/non-hookable inference engine.

Required arms:

- `baseline`: full admitted compiled workspace projection;
- `target`: `JSPACE_WORKSPACE_PROJECTION_ABLATION`;
- `control`: `MATCHED_NON_JSPACE_CONTEXT_CONTROL`.

This is only a **system-level causal coupling** test. It must not claim access to the external model's private residual stream or hidden activations.

Required law:

```text
COMPILED_EXTERNAL_CAUSAL_TEST = SYSTEM_LEVEL_ONLY
COMPILED_EXTERNAL != HIDDEN_STATE_INTERVENTION
```

## Mandatory three-arm matching

The receipt requires all of:

- same task;
- same input;
- same decoding configuration;
- same engine identity;
- same entity generation;
- only the intended intervention differs;
- control capacity is matched.

Every arm binds:

- unique run id;
- entity generation;
- input digest;
- decoding-config digest;
- engine-identity digest;
- intervention kind and digest;
- workspace-projection digest;
- candidate-result digest;
- behavior-measurement digest;
- telemetry digest;
- actual execution state;
- hidden-state access/claim flags.

The baseline intervention digest is required to be null. Target and control intervention digests are required, and target/control may not alias to the same digest.

## Comparison fields

The receipt records one named metric from a bounded set:

- `TASK_SCORE_DELTA`;
- `OUTPUT_KL`;
- `TOP1_FLIP`;
- `WORKSPACE_RECALL_DELTA`.

It records non-negative target/control effect magnitudes and a declared minimum margin. The validator recomputes:

```text
target_minus_control_margin = target_effect - control_effect
```

and rejects a self-reported mismatch.

Meeting the declared margin is returned only as a descriptive field. It does not promote causality. Replication, cross-task aggregation, negative controls, exact runtime evidence and a later promotion contract remain required.
