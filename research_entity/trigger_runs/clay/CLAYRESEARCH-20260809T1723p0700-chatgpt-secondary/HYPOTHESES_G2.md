# Fusion-2 transformed hypotheses

Run: CLAYRESEARCH-20260809T1723p0700-chatgpt-secondary
Status: OPEN; transformed after internal evidence, external research and synthetic instrument tests.

### H2-CR4-01 — LOOP-OF-LOOPS CONTRACT
Represent FRANK as a typed heterogeneous recurrent graph: each loop has state identity, epoch, timescale, dependencies, budget, local stop condition, intervention handle, and re-entry receipt. This is architecture semantics, not an instruction to make every component one literal while-loop.

### H2-CR4-02 — LESS CHANGE MORE COMPILE
Do not add ClayCode surface syntax for recurrence now. First compile the existing state/control/GWT semantics into a frozen loop-of-loops exemplar; only an executable semantic gap can justify a language change.

### H2-CR4-03 — INCREMENTAL SCHEDULER
Use dependency-triggered/event-driven scheduling as the default candidate; retain periodic/global sweeps only as explicit loops where evidence requires them. Measure affected-set density before optimizing.

### H2-CR4-04 — TWO-TIER HALTING
Initial runtime stopping should combine loop-local stability/novelty criteria with hard global deadline/resource budgets. Learned halting gates are a later model experiment, not a runtime authority root.

### H2-CR4-05 — COUPLING REGIME
Treat gains, delays and timescales as measured parameters with oscillation/overcoupling tripwires; no fixed coupling coefficient is canonical without sweeps.

### H2-CR4-06 — CAUSAL GWT CLOSURE
A workspace episode is closed only when delivery -> receiver reconstruction -> causal use -> outcome -> provenance-bound re-entry has receipts; broadcast flags alone are observational metadata.

### H2-CR4-07 — EVENT-SOURCED REENTRY
Persist re-entry by episode/event identity and loop cursor/epoch so duplicate, delayed, shuffled and provenance-broken controls are mechanically expressible and replayable.

### H2-CR4-08 — EFFECT EXIT
Cognitive loops may propose effects, but physical effects leave the recurrent fabric through a deterministic capability/effect broker. Child code must remain effect-subset constrained.

### H2-CR4-09 — MODEL-INDEPENDENT FIRST
Implement and test FRANK recurrence around the current conventional 4B adapter first. Looped/recurrent-depth model architectures become a post-BASE comparative model track, not a prerequisite.

### H2-CR4-10 — IMPLEMENTATION-INVARIANT LOOP GRAPH
H1/H2/H3 should be compared by causal loop/state-transition graph and Golden interventions, not by service/process/module count. H3 may collapse deployment boundaries without deleting causal distinctions.

### H2-CR4-11 — MULTI-AXIS EMERGENCE
Keep emergence as an evidence bundle: nulls/interactions, directed flow, interventionist synergy, macro gain, lesion/rescue, re-entry specificity, transfer, robustness and cost. Never fuse these into one truth scalar.

### H2-CR4-12 — SAFE UTILITY JOINT TEST
Any Safe-Effect result must jointly measure ordinary task utility and reachable protected damage. A refusal-only or sandbox-only result cannot establish the intended mechanism.

### H2-CR4-13 — ASSEMBLIES AS TEMPORARY LOOP COALITIONS
Treat Assemblies as temporary coalitions of recurrent states/relations with explicit formation reason, budget, TTL/teardown, expected outcome and receipts; permanent modules remain allowed where causal evidence demands persistence.

### H2-CR4-14 — EQUIVALENCE OPTIMIZATION FIREWALL
Equality-saturation/e-graph methods are candidates for preserving multiple computationally equivalent Clay transforms, but equivalence optimization must be firewalled from epistemic status, activation and authority.
