## Executive synthesis

G5 retains the G4 **Semantic Causal Kernel** but changes its control model. The integrated candidate is now:

`canonical events/provenance → conflict-preserving contextual state → incremental causal projections → bounded activation/assemblies → receipt-defined GWT ↔ optional latent model-workspace probes → typed/state-aware ClayCode proposal → external capability/effect gateway → outcome/re-entry`.

The main new delta is fourfold:

1. **Change Reproduction Number `R_delta`**: overcoupling can be operationalized as the expected number of consequential downstream invalidations caused by one changed state. Near/exceeding one, sparse changes can enter large recomputation cascades.
2. **Dual Workspace Evidence**: FRANK event receipts and latent model-workspace probes should be treated as independent evidence channels. Strong workspace claims require causal cross-intervention, not labels, self-report or one scalar marker.
3. **State-aware ClayCode decoding**: grammar constraints can move syntax checks into decoding; runtime-state constraints can move some semantic checks left; authority remains a separate external capability/root/nonce/rollback/effect-receipt decision.
4. **Selective Distributed Closure**: pure cognition and reversible state proposals should remain local/speculative where possible. Only externally effectful or genuinely conflicting transitions should pay synchronous global ordering/authority cost.

## External research synthesis

### Global workspace / mechanistic interpretability

Anthropic's July 2026 research reports a small latent `J-space` with reportability, deliberate modulation, flexible downstream use and causal mediation of higher-order tasks. Gurnee et al., `arXiv:2607.15495`, presents the underlying preprint. Rahbar's `arXiv:2608.05160` proposes an ignition-like measure. G5 treats these as functional/mechanistic evidence only: neither ignition, reportability nor a latent workspace establishes phenomenal consciousness. A stronger FRANK test is cross-lesion agreement between receipt-defined GWT and an independently measured latent workspace.

### Emergence

Hoel, `arXiv:2503.13395`, formalizes unique causal contribution across scales. G5 therefore keeps macro causal contribution separate from mere compression and requires recurrence, lesion, specific rescue, compute-matched rescue, OOD recurrence, higher-order synergy, robustness and cost shadows before any emergent-organ designation.

### Incremental / distributed state

Timely/Differential Dataflow provide real implementation evidence for low-latency incremental and iterative computation over changes rather than full rebuild. Automerge provides mature local-first/CRDT evidence for concurrent mergeable state. These support a split architecture: mergeable non-authoritative cognitive state can be local-first, while external effects still require stronger authority and conflict closure.

### ClayCode / constrained generation

Park et al. `arXiv:2502.05111` and Li et al. `arXiv:2608.03065` support efficient grammar-constrained decoding. Nagy et al. `arXiv:2509.00360` extends toward semantic constraints. G5 implication: state-aware ClayCode generation is plausible and useful, but semantic validity still does not imply permission to act.

### Mobile / edge

Current Qualcomm GenieX / AI Hub paths support Qwen3-4B-class Android deployment on Qualcomm CPU/GPU/NPU stacks. MNN is a separate Android inference implementation. Current 2026 KV-cache work (`arXiv:2604.04722`, `2606.24467`, `2607.17715`) strengthens the view that context/KV memory is an adaptive resource. llama.cpp practitioner issue evidence also shows speculative decoding can slow down badly when draft acceptance is low. FRANK should therefore adapt model/context/backend/thermal/speculation policy rather than hard-code a universal runtime choice.

### Capability boundary

Wasmtime/WASI is strong implementation evidence for capability-oriented sandboxing. 2026 Wasmtime security advisories simultaneously show why the sandbox itself remains part of the trusted computing base. `sandboxed` is not equivalent to `authorized`; FRANK still needs application-level capability/root/nonce/rollback/effect-receipt checks.

## Fusion 2 — new cross-domain model

A single **causal budget** appears across five layers: RAE retrieval, Qwen context/KV, Clay active projections, GWT workspace capacity and incremental dependency propagation. Instead of separately maximizing recall, context, fanout, broadcast or cache size, G5 proposes a budget controller that allocates resources to causal-path preservation while tracking change amplification, cost and recovery.

Authority boundaries also coincide with latency boundaries. Pure/reversible computation can be speculative and local. Externally effectful operations are where freshness, capability scope, ordering and rollback become mandatory. This moves synchronous coordination to the effect boundary rather than every internal transition.

## Experiments

### EXP-G5-RDELTA-001 — change propagation
Synthetic branching proxy with a 5,000-state ceiling. Mean affected fraction rose from ~0.000345 at `R_delta=1.0` to ~0.01539 at 1.2, ~0.08046 at 1.4 and ~0.24029 at 1.8. Stochastic extinction remained common, so this is not a universal phase-transition proof. It supports `R_delta` as an overcoupling diagnostic.

### EXP-G5-CONTEXT-002 — causal-path context budget
Constructed 100-item tasks with six-item causal chains. At budget eight, chain-complete rate was 0.000 for recency, 0.002 for noisy salience, 0.881 for the constructed causal selector and 0.469 for a hybrid. This is a sanity-check toy deliberately containing causal labels; it demonstrates why chain completeness is a different objective from salience/recency.

### EXP-G5-DUALWS-003 — dual-channel mediation proxy
Constructed common-cause model: outcome AUC 0.623 from receipt-only, 0.658 from latent-only, 0.681 from both. Because the common cause was built into the generator, this validates only the triangulation test design.

### EXP-G5-SPECULATE-004 — quarantined speculation
Toy with 20 ms authority validation and 60 ms pure compute. At 10% invalid proposals: serial mean latency ~73.92 ms, quarantined speculative ~55.95 ms, ~24.31% latency reduction, with ~6.08 ms/request wasted compute. Speculation is useful only while effects remain quarantined and waste is measured.

### EXP-G5-STATEGRAMMAR-005 — syntax/state/authority separation
Constructed symbol-state toy: grammar-only semantic validity ~20.0%; state-aware grammar 100%; independent capability+fresh-root checks still rejected ~19.18% of state-valid proposals. This is a designed separation test, not model-performance evidence.

### EXP-G5-DISTCLOSURE-006 — selective distributed closure
Synthetic 200k-operation workload, 10% effectful operations, 3% partition probability. Strict global synchronization: mean available latency ~50.26 ms, unavailable rate ~3.024%, p95 ~132.6 ms. Effect-only synchronization: ~6.73 ms, ~0.3005%, p95 ~35.8 ms. Strongly motivates a real FRANK partition/latency benchmark but does not establish production performance.

## Architecture delta

1. **Canonical event/provenance plane** — append/version identities, evidence, claims and effect receipts.
2. **Contextual hyperposition plane** — branch/conflict/unknown/revocation remain first-class; portable role-aware relation ABI, replaceable backend.
3. **Incremental causal projection plane** — disposable derived views, track `R_delta`, change amplification and rebuild crossover.
4. **Bounded activation/assembly plane** — relevance not truth; joint budget across records, context/KV and broadcast fanout.
5. **GWT plane** — `candidate→compete→ignite→broadcast→reconstruct→effect→outcome→reenter` with episode identity and receipts. Latent workspace probes are independent evidence, not authority.
6. **ClayCode plane** — typed `PURE_TRANSFORM`, `STATE_PROPOSAL`, `EFFECT_PROPOSAL`; grammar constraint → state constraint → deterministic validation.
7. **Authority/effect gateway** — capability scope, root freshness, nonce/expiry, invariants, rollback, effect receipt.
8. **Execution plane** — pure/state work may be speculative/local; effect/conflict boundaries pay synchronization.
9. **Platform adapters** — Linux reference plus Android/edge and other hosts implement the same semantic contract with hardware-specific inference policy.
