# DUMP INBOX

Drop arbitrary research-relevant files here.

Reserved project command: `dump`

When a project worker receives exactly `dump`, it must execute `research_entity/global/DUMP_PROTOCOL.md`.

This directory is an intake queue, not canonical evidence. Files remain here until the batch completes and verifies. Successful batches move to `dump archive/<batch_id>/original/`.

Do not place credentials, private keys, passwords, cookies or access tokens here.
