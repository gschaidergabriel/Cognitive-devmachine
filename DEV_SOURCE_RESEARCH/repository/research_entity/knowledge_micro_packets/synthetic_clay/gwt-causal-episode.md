### Core
A meaningful GWT engineering contract should link `candidate → compete → ignite → broadcast → reconstruct → effect → outcome → reenter` by episode identity, predecessor relations and receipts. Merely observing all labels or modules is insufficient to establish a closed functional workspace episode.

### Evidence / boundary
The G1 line developed causal validators and observatory metrics in synthetic traces. Later project work strengthened this direction. It still requires live FRANK trace replication.

### Implication
Emergence/GWT experiments should manipulate and verify links between stages, not only count activations.

### Next test
Synchronize one live FRANK episode, then perform separate selection, reconstruction, effect and re-entry lesions with rescue.
