# Contradiction Map — Fusion 2

## C1 — Richer architecture vs simpler exact substitutes
Project direction: Hyperposition/higher-order topology preserves alternatives and higher-order codependencies.
Counterevidence: some higher-order dynamical classes admit exact weighted pairwise reductions, while other work shows representation choice can materially alter dynamics.
Resolution: OPEN, narrowed. Higher-order representation is conditional on measured irreducibility. Pairwise is mandatory baseline; no universal Hyperposition promotion.

## C2 — Adaptive recurrence vs fixed/event-driven control
Project direction: adaptive recurrence can allocate compute while pressure remains material.
External analogue: adaptive computation time demonstrates input-dependent recurrent compute, but benefits are task-dependent rather than universal.
Resolution: OPEN. Retain adaptive recurrence as candidate, with fixed/event-driven comparator and measurements for false halt/stall/divergence plus outcome gain per cost.

## C3 — Workspace ignition/integration vs causal broadcast
Project invariant: delivered != reconstructed != used != local effect.
External critique: integration can arise under multiple communication mechanisms and does not alone identify global broadcast.
Resolution: strengthens the receipt-chain requirement. Ignition/integration is an observation, not causal credit or consciousness evidence.

## C4 — Idempotency key presence vs time-bounded retry authority
Prior implementation gap: UNKNOWN retention still authorized uncertain mutating retries.
Primary provider evidence: real APIs expose finite/prunable idempotency horizons.
Resolution: counterhypothesis refuted for mutating retry authority. UNKNOWN/EXPIRED retention fails closed; read-only reconciliation remains separately typed.

## C5 — V17 local self-verification vs actual causal referential closure
Prior candidate behavior: terminal DONE could be accepted while V15 remained IDLE, V16 execution was unbound and fabricated causal-support identifiers were absent from canonical stores.
Resolution: local self-verification is insufficient. Exact execution generation and canonical support identities, or explicit no-learning semantics, become the next gate.

## C6 — Source/epoch equality vs unique SELF continuation
Negative evidence: same-source/same-metadata state siblings can diverge semantically.
New target evidence: selected-head exact-parent CAS admitted one of two semantic twins and rejected the other.
Strongest remaining counter: selected-head authority itself may be rolled back/lost or lack trusted builder provenance.
Resolution: candidate supported, not promoted. Compose semantic-lineage selection with independent rollback anchor and artifact attestation rather than treating CAS as complete identity. Late worker evidence additionally shows GitHub private-repository attestation capability is UNKNOWN and must not be assumed.

## C7 — SQLite package version vs actual WAL safety
Observed target: Ubuntu Noble libsqlite3 3.45.1-1ubuntu2.7, WAL mode.
Upstream: documented WAL-reset bug covers upstream versions through 3.51.2 under a specific concurrent topology.
Counter: Ubuntu may have an unadvertised backport or Frank may not instantiate the trigger topology.
Resolution: UNRESOLVED_FAIL_CLOSED. Version string alone proves neither vulnerability nor safety; close via exact source/build backport evidence, known-fixed upgrade, or machine-checked topology exclusion.

## C8 — Timestamp as event identity vs durable event-instance identity
Late worker evidence: equal timestamps can alias distinct V16 continuity events. A local 8x32 concurrent micro-replica using durable sequence identity produced unique reconstructible hashes but exposed contention tail latency.
Resolution: timestamp is timing evidence, not event identity. Exact target PR lane remains required and latency is part of acceptance.

## C9 — Semantic unity vs physical unity
Late Fusion worker hypothesis: one release-critical semantic value should preserve identity across cognition, typed IR, authority, persistence, lowering, outcome and re-entry, but this does not imply a single physical storage image.
Resolution: semantic continuity spine is strengthened; physical EUDI/single-image layout remains a separately measured candidate and cannot mint truth/identity/authority by placement.
