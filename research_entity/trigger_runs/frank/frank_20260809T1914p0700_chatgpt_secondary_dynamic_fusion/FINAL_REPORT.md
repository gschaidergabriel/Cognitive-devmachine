## 4. Cross-branch synthesis

### GWT / loop-of-loops
Adaptive recurrence remains OPEN. Synthetic work supports a candidate controller basis of unresolved pressure + multi-step progress/expected marginal gain + compute/instability cost + remaining budget + regime identity. It does not establish GWT focus as the controller. Fixed budgets and ordinary event-driven scheduling remain required baselines. Recent adaptive-depth research strengthens a key methodological warning: learned halting/readout can become entangled with the trajectory it is supposed to judge, so fixed-trajectory/post-hoc readout baselines are required.

### ClayGraph / Hyperposition
Reversal-Aware Binding remains OPEN/HOLD. Provenance-diverse slow promotion sharply reduced false reversal from duplicated source echo in synthetic tests, but did not improve ordinary true-reversal adaptation and can slow it under noise. Context identity itself explains much of context-bifurcation performance. Required semantics are therefore context, ancestry/provenance family, validity/version, conflict/shadow state and rollback; a richer lattice is not promoted.

### Emergenz / observability
Instrumentation is a possible intervention until calibrated. Aggregate outcome distributions can look unchanged while paired episode/winner identity changes. H1 emergence/GWT/re-entry tests therefore require common-snapshot low/no-observation controls, paired-trajectory comparison, timing slack and observation-mode identity.

### UnifiedDB / semantic fabric
Current direction is canonical semantic state with typed forward/reverse dependencies, affected-closure invalidation, epoch publication and prepared views/Assemblies. No additional manually maintained possibility store is justified. SQLite remains a plausible H1 physical mechanism, but its single-writer/snapshot behavior makes stale read-to-write snapshots, busy/retry policy, crash/WAL handling and replay order explicit test targets.

### Needle
The newest Needle work correctly pushes toward fail-closed schema canonicalization, alias-collision rejection, malformed/unoffered/blocked tool rejection, tamper-evident hashes and `authority=NONE` when no valid tool proposal exists. Grammar/schema-constrained generation can reduce syntactic escape, but cannot prove semantic tool correctness or mint authority. Deterministic post-validation and effect-authority closure remain mandatory.

### ClayCode
The highest-value result of the current BASE burst is not a new language feature. It is movement from grammar repair toward deterministic semantic identity while preserving the program law `less change, more compile`. WP01 is now frozen; WP02->WP04 must prove that the frozen semantics survive canonical IR, typing/effects and authority separation without hidden host-language semantics.
