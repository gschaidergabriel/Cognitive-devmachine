# CONTRADICTION MAP — FUSION 1855

## C1 — “AI-native language” as one object

**Conflict:** The supplied sources use the same phrase for human intent programming, canonical machine/agent IR, endogenous discrete communication and symbolic neural reasoning.

**Resolution:** `CLAY-L4` separates L0 Intent, L1 Canonical Semantics, L2 Native Deliberation and L3 Physical Neural/Runtime. Shared Clay meaning does not erase causal-stage identity.

**Status:** REVISED / high confidence as taxonomy; target performance implications remain open.

---

## C2 — Intent-first programming vs deterministic semantics

**Conflict:** Medium/Vibe Coding emphasize expressing desired behavior rather than specifying implementation; COVE/CC9/H4 require exact causal/authority semantics for consequential actions.

**Resolution:** Intent is upstream input, not canonical truth. Compile L0 into L1 typed goals, hard constraints, soft preferences, assumptions and explicit unknowns; fail/escalate unresolved effect-critical ambiguity.

**Negative:** “vibe” must never silently become FACT_EXACT/AUTHORITY/EFFECT semantics.

---

## C3 — AI-native IR vs AI mother tongue

**Conflict:** AINL demonstrates an agent-oriented graph IR/runtime but does not require model-native internal language. AIM studies learned discrete symbols but not a deterministic programming runtime.

**Resolution:** L1 and L2 are independent scientific mechanisms. A target can possess either, both or neither. FRANK's fixed target is both canonical Clay and native Clay deliberation, but evidence must be measured separately.

---

## C4 — Native Clay vs Reader/View Compiler

**Conflict:** If the model natively understands Clay, it may appear that C5/G10 reader projection is redundant.

**Resolution:** Native fluency does not perform trusted filtering, exact joins/min/max, privilege separation, basis pinning, selection attestation or authority validation. C6 already retains a Clay View Compiler. AINL independently reinforces compile-before-runtime reasoning.

**Status:** strengthened architecture hypothesis, not live target proof.

---

## C5 — Discrete symbols vs continuous hidden state

**Conflict:** “Mother tongue” rhetoric can imply that hidden cognition literally becomes discrete symbolic sequences; C6 explicitly preserves continuous transformer tensors.

**Resolution:** Clay-native refers to explicit generated/deliberative semantic representation and learned use of Clay constructs. Hidden computation remains continuous unless a specific bottleneck is introduced. A VQ codebook is an optional experimental mechanism, not a definitional requirement.

---

## C6 — Symbol purity/recurrence vs reasoning causality

**Conflict:** AIM-style work reports symbol purity/convergence and interprets chains; E-CERT2 rejects recurrence, post-hoc partitioning and endpoint behavior as sufficient causal evidence.

**Resolution:** Evaluate discrete symbols using preregistered task meaning, symbol permutation/lesion, mechanistic rescue, OOD transfer, hidden-state mediation and matched continuous/no-symbol controls. Purity alone is descriptive.

**Source-quality correction:** the 2508.18988 manuscript contains unresolved result placeholders and Phase-2 accuracy around 47.3%; broad interpretability claims must remain weak/open.

---

## C7 — Semantic unity vs common-mode failure

**Conflict:** C6 seeks one Clay semantic world; H4 shows one language can become one failure domain.

**Resolution:** semantic unity with typed firebreaks. Facts, observations, activation priors, proposals, forms, capabilities and effect intents remain distinct Clay semantic classes with trusted casts.

---

## C8 — Compile-once/run-many vs adaptive cognition

**Conflict:** AINL's recurring-cost advantage favors deterministic reuse; FRANK requires changing memory, workspace and contextual reasoning.

**Resolution:** compile/reuse only when causal slice/basis permits. Recompile or revalidate when relevant state, selector, policy or capability witness changes. Model reasoning is reserved for genuinely unresolved semantics.

---

## C9 — Natural-language flexibility vs reproducibility

**Conflict:** Vibe Coding values semantic flexibility but documents ambiguity, reproducibility, maintenance and security risks.

**Resolution:** preserve flexible human input but make the L0->L1 compilation result explicit, versioned, reviewable and replayable. Intent text itself is provenance, not executable authority.

---

## C10 — “Native language makes model smarter” vs training confounds

**Conflict:** C6 wants full-model Clay adaptation; existing proxy results mainly show untrained models fail Clay or benefit from deterministic preprocessing. AIM studies impose specialized bottlenecks/losses.

**Resolution:** target experiment must separate training compute/data/curriculum/tokenizer, L1 compilation and L2 native-language effects. A bundled old-model/raw-state vs fine-tuned-model/compiled-Clay comparison cannot identify a mother-tongue effect.

---

## C11 — Same-language memory vs useful cognition

**Conflict:** ClayGraph-native memory and model-native Clay may reduce impedance, but shared language could also propagate stale/poisoned associations more coherently.

**Resolution:** activation remains non-authoritative; run truthful/shuffled/no-field and revocation/selector attacks with exact anchors, semantic firebreaks and effect receipts.

---

## C12 — AI-native language vs emergence/consciousness

**Conflict:** Endogenous symbols and shared workspace may look language-like/organism-like.

**Resolution:** E-CERT2 remains mandatory. Native symbols, convergence, recurrence, GWT access or self-description do not establish functional emergent-organ status without causal certificate, and never by themselves establish phenomenal consciousness.
