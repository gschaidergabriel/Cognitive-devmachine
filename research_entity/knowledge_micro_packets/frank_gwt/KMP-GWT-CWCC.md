### Core
Strong functional GWT evidence should be represented as a **vector Causal Workspace Closure Certificate (CWCC)**, not a single scalar. Candidate dimensions are competition/winner margin, ignition intervention response, logical availability and actual fanout, audience receipt, reconstruction, effect mediation, outcome receipt, truthful-vs-shuffled/removed/delayed re-entry sensitivity, next-state influence, capacity/load, perturbation amplification, optional latent/event concordance, and task/cost/recovery shadows.

### Evidence / boundary
RAE sandbox results already show stage presence misses causal defects; re-entry benefit depends on usable information paths. External J-space research shows that reportability/broadcast-like structure and ignition-like sharpness can be measured separately and each has limitations. The exact CWCC minimum set is not yet validated.

### Implication
This structure resists Goodhart pressure on broadcast count, self-report, ignition or one information-flow metric and supports lesion-level debugging.

### Next test
Run dimension ablations on corrupted episodes, then carry the surviving vector to FRANK twin/live traces.
