### Core
Between LLM calls, canonical outcome/event deltas can incrementally update semantic graph projections, lexical/vector indexes and a sparse non-authoritative activation field. That field can maintain an Assembly-ready frontier before the next model invocation. Memory therefore becomes a persistent influence on what is considered next, while explicit retrieval remains fallback/validation rather than the only memory path.

### Critical boundary
Activation is accessibility, not fact truth, workspace ignition or authority. Any derived association used for an effect must re-anchor to the appropriate canonical state and pass selection/basis/capability checks.

### High-information test
Run matched long-horizon tasks with no-memory, explicit-retrieval-only and Cognitive-State-Continuity arms at equal model/token budget; lesion and rescue SELF/goal/consequence activation and measure recall, false association, continuity, latency, token cost and downstream effect correctness.
