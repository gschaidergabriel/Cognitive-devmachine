# Clay G6 Negative Results / Weakened Claims

All results are scoped to the stated synthetic/external evidence boundary.

- `N-G6-001` — **Effect-only selective closure is not universal.** Internal concurrent updates violated a shared capacity invariant in 34.8425% of constructed pairs when they were assumed coordination-free. Revised candidate: coordinate when external authority/freshness requires it OR the merge is not invariant-confluent.
- `N-G6-002` — **One scalar causal budget is not universal.** In a non-collinear four-regime synthetic workload, a vector controller reduced allocation loss by 84.19% relative to a scalar controller.
- `N-G6-003` — **State-aware grammar does not guarantee current-state validity.** With up to ten-step-old Γ snapshots under 3% churn, 11.911% of proposals referenced symbols invalid at the current state; a root/current-state check was still required.
- `N-G6-004` — **Observational dual-workspace agreement is not causal proof.** A common-cause proxy model retained R² 0.678 from receipt/latent observations while direct receipt intervention had zero structural outcome effect.
- `N-G6-005` — **Peak inference throughput is not a sufficient sustained mobile objective.** In the constructed thermal proxy, static max-speed mode throttled below static eco and feedback-controlled operation.
- `N-G6-006` — **Pairwise information is not sufficient for all higher-order mechanisms.** XOR yielded approximately zero pairwise mutual information but ~1 bit joint information.
- `N-G6-007` — **Ignition/workspace should not be collapsed to one scalar truth marker.** Current external literature exposes dissociable functional surfaces (ignition dynamics, verbalizable latent workspace, causal mediation); no evidence supports treating any one as a consciousness metric.
- `N-G6-008` — **Speculative decoding should not be assumed universally beneficial.** Current implementation/practitioner evidence and G6 task-mix simulation both show benefit depends on draft acceptance/workload; adaptive gating remains OPEN.
