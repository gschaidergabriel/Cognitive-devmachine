### Core
Anthropic's 2026 J-space work provides external mechanistic evidence that a small privileged latent representation set can mediate higher-order model behavior. FRANK already has an orthogonal observable candidate: receipt-linked GWT episodes. G5 proposes that neither channel is sufficient alone; stronger engineering evidence comes from causal agreement between them.

### Evidence / boundary
The local G5 dual-channel AUC toy merely validates the proposed triangulation design because the common cause was constructed. Anthropic's work is model-family-specific and does not imply consciousness.

### Implication
FRANK's GWT observatory should eventually support both event-level lesion/re-entry experiments and model-internal perturbation when the local model is instrumentable.

### Next test
Cross-lesion a receipt-defined episode and a latent workspace representation and test whether both predict the same downstream functional dependency.
