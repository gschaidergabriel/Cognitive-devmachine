# ClayGraph Cycle 2 — Negative / Blocking Results

- **N-CG2-001 — No held-out recall gain yet.** On the 10 held-out designed queries, G1b recall tied G1 at `0.5250`; G1b precision was slightly lower (`0.3050` vs `0.3133`). This blocks promotion.
- **N-CG2-002 — Hard anti-echo deletion damages retrieval.** A one-per-evidence-family cap reduced overall recall to `0.5375`. Evidence ancestry must reduce evidential counting/duplication without blindly deleting distinct roles.
- **N-CG2-003 — Deterministic packet-envelope ranking is not a query retriever.** Its low task recall (`0.10` in this proxy) is not evidence that the runtime policy is bad; it is a cross-domain grounding/safety baseline with different objectives.
- **N-CG2-004 — G1 fixed graph remains competitive.** Overall G1 precision (`0.3675`) slightly exceeds G1b (`0.3633`); query planning is not yet a universal win.
- **N-CG2-005 — Full current-corpus benchmark remains blocked on this surface.** The repository tools cannot be executed through the GitHub connector here.
- **N-CG2-006 — No Qwen3-4B result.** Hugging Face inference quota remains cached exhausted until 2026-09-01; no local target runtime is exposed.
- **N-CG2-007 — Store inventory remains incomplete.** No new live evidence enumerates the remaining portion of FRANK's reported 71 database files.
- **N-CG2-008 — Retrieval improvement does not justify physical MERGE.** No new parity/replay/crash/p99 evidence changes the G1 migration dispositions.
- **N-CG2-009 — Graph correctness is not retrieval correctness.** Current Graphiti implementation/community reports document unresolved temporal/retrieval/salience concerns; they are not ClayGraph failures but falsify any assumption that a correct graph automatically yields correct recall.
- **N-CG2-010 — Salience is not truth.** Production-style salience filtering may reduce noise, but it cannot be allowed to erase audit/history or change epistemic status.
- **N-CG2-011 — Graph activation is not GWT ignition.** Better active assembly retrieval remains a memory-selection mechanism, not evidence of workspace ignition or phenomenal consciousness.
- **N-CG2-012 — Accepted generation remains 0.** A second research cycle after a HOLD does not create generation 2; the new candidate is another generation-1 descendant of the accepted generation-0 graph.
