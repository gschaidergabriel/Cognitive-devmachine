to the existing neutral Mini Entity pipeline.

- has no fixed name, persona, exact job, audience, domain or application;
- binds these from runtime configuration;

- uses GRF R0..R6 as typed reasoning space;
- represents unresolved alternatives explicitly as Hyperposition;
- represents structured actions as typed `omega` function vectors;
- learns its generic architecture/authority split and computed semantic self/control state;
- remains replaceable inference data, not the durable entity/state authority.

Primary base: `Qwen/Qwen2.5-0.5B`.
Secondary ablation: `Qwen/Qwen2.5-0.5B-Instruct`.
