# ATOMIC Deep Run — SWC-001 Sectional Workspace Compiler

## Verdict

**REVISE — supported as a Frank v0.1 validation/compiler research candidate, not promoted as a new runtime organ and not established as a novel mathematical algorithm.**

The run began from the current Frank v0.1-only program, preserved the prior ATOMIC IAC-001 refutation, cross-read the newly re-entered LCOP/native-workspace work, generated a 12-hypothesis population, performed fresh external prior-art/counterevidence research, selected one sparse GRT mechanism region, specified it ClayCode-first, and executed a reproducible synthetic discriminator.

## The candidate

SWC changes the semantic geometry of a candidate WorkspaceEpisode. Instead of assuming that there is one globally coherent broadcast object, each explicit Clay receiver contributes a typed local relation over the semantic variables it actually constrains. ClayGraph supplies the overlap topology. Hyperposition is the set of global assignments still consistent with every local section.

A compiled validation plan then chooses the cheapest exact method justified by topology:

- certified acyclic/forest scopes -> local/join-tree exact path;
- exact bounded-width decomposition available -> decomposed exact path;
- cyclic, uncertain or otherwise uncertified topology -> global residual solver;
- stale, mismatched or incomplete state -> fail closed.

Zero global assignments yields an obstruction and blocks coherent re-entry. Multiple global assignments preserve Hyperposition. A unique/global-action-invariant projection may reuse the surviving IAC sufficient-stop law, but still carries no truth, identity or effect authority.

## Why it survived the first falsifier

The synthetic binary-CSP discriminator generated 10,000 episodes over 20 seeds. A deliberately weak pairwise projection baseline averaged 86.22% accuracy and produced 68.9 false coherent admissions per 500 episodes. SWC matched the exact satisfiability oracle on all generated episodes. It invoked explicit global backtracking in 29.18% of episodes on average and used 34.90% of the counted reference operations of an AC-3 plus always-global exact baseline.

These are narrow synthetic measurements. They are not Frank runtime latency, target-VPS resource results, production correctness evidence or proof that actual Frank receiver scopes fit the same relation model.

## What the web research destroyed

The mathematical skeleton is prior art. Database/CSP theory has long studied local versus global consistency and the special tractability of acyclic scope hypergraphs. Distributed-systems work has formulated local computations and global solutions through sheaf/global-section language. Hypertree decomposition and incremental decomposition are established solver/query techniques. 2026 work has also proposed sheaf frameworks for multi-agent systems. Therefore a generic claim that SWC invented sheaf-based agent coherence is rejected.

The defensible remaining novelty is only a **project-specific composition candidate**: explicit Frank GWT receiver-stage receipts + Hyperposition-preserving alternatives + ClayGraph topology + provenance-bound re-entry + topology-specialized exact validation lowering. Even that must be treated as a possibility, not a world-first claim.

## Strongest counterhypothesis

A normal exact CSP/SAT/SMT validator or query-style decomposition planner can provide the same correctness at lower total complexity. The counterhypothesis is partially supported. The current reference implementation itself uses ordinary arc consistency, topology detection and backtracking. This is a reason to avoid a new runtime organ, not a reason to discard the useful validation question.

## Architecture consequence

No accepted Frank architecture is changed by this run. The candidate should enter the research mesh as a test obligation. If real traces support it, the preferred implementation is conventional exact solver/decomposition machinery lowered behind typed Clay semantics. ClayCode's frozen semantics should not be reopened unless an executable compiler counterexample proves the required witness/plan semantics cannot be represented.

## Highest-value next experiment

Replay frozen real Frank WorkspaceEpisodes and derive receiver semantic scopes from actual GWT/ClayGraph receipts. Stratify by acyclic/cyclic/estimated-width topology. Compare pairwise-only, AC-3 + always-global exact, and SWC topology-adaptive exact validation. Add truthful, shuffled, provenance-broken, stale and no-reentry controls plus topology-fast-path lesion/rescue. Measure false coherent admission, false rejection, task/outcome effects, solver-call rate, p50/p95/p99 latency, CPU/RAM, state/witness amplification, replay/restart integrity and timeout fail-closed behavior.

Promotion requires equal-or-better exactness and a material robust resource or diagnostic benefit on real Frank workloads. If the always-global exact baseline dominates, SWC is refuted as an optimization and only the explicit local-vs-global coherence test law survives.
