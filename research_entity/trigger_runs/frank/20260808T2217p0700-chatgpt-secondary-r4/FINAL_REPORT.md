## 1. Executive result

C7 answered the physical architecture question:

> `semantic organ boundary != process boundary != storage boundary != authority boundary`.

That remains valid and is retained as SCRF's runtime/fault-domain foundation.

C8 answers the next question created by CACC-G12, GWT-R5 and Hypofusion H1:

> **If FRANK has rich persistent Clay state, how much of that state should become cognitively active for one operation, how should that budget adapt, and how do we distinguish system-level workspace selection from what the Qwen reader actually takes up internally?**

C8's compact answer is:

> **rich persistent state != active cognitive slice**

and:

> **system workspace != model-internal workspace != effect authority**.

The architecture therefore adds four control planes to C7 CORF:

1. **Memory Lifecycle Compiler** — different memory classes receive different update/retention/replay semantics;
2. **Salience Governor** — utility can adapt accessibility, but bounded gain/decay/inhibition/diversity prevent self-confirming stale attractors;
3. **Cognitive Resource Governor** — chooses operation/device-specific Assembly, retrieval, graph depth, rail, context/KV and backend budgets;
4. **Nested Workspace Bridge** — measures/intervenes on the model-internal uptake plane separately from FRANK's external `WorkspaceEpisode`.

C8 is not another claim that all cognition should be globally active. It is the opposite: the persistent substrate may be large, but the active cognitive surface should be **small, task-conditioned, receipted and conservatively escalated when uncertain**.

## 5. Memory lifecycle model

C8 explicitly rejects one uniform memory pipeline.

### L0 — Canonical record
Exact event/state/effect/outcome/source-grounded records. Explicit authoritative commits only.

### L1 — Stable semantic/profile state
Slowly evolving self/world/profile summaries or distilled semantics. Evidence-gated consolidation with ancestry back to canonical records.

### L2 — Temporal event/relation state
Changing facts, valid-time/transaction-time relations and episodic state.

### L3 — Associative derived state
ClayGraph, vector, FTS and materialized relational views. Rebuildable/incremental by default.

### L4 — Salience/activation
Fast non-authoritative accessibility state updated between model calls.

### L5 — Active Assembly
Small operation-conditioned model-visible slice compiled for one causal episode.

This separation combines the project's CACC/UnifiedDB/ClayGraph results with convergent 2026 memory work such as query-aware tiering and memory-class-specific compression/retrieval. It also makes failure recovery and scientific attribution cleaner.

## 6. Cognitive Resource Governor

The resource governor consumes a typed `MemoryDemandProfile`:

- exactness need;
- temporal need;
- relational depth/breadth;
- provenance need;
- risk class;
- latency/energy budget;
- platform/device state;
- demand confidence.

It chooses:

- Assembly budget;
- retrieval routes;
- graph traversal depth;
- P1/P2/P3/hybrid rail;
- context budget;
- KV policy;
- backend/platform lowering;
- fallback/escalation policy.

Unknown or high-risk demand escalates; cost optimization may never weaken exactness/provenance/authority requirements.

### EXP-C8-RESOURCE-GOVERNOR-001

12 seeded trials × 100,000 synthetic cognitive requests compared fixed resource tiers to a noisy query-aware adaptive router.

Mean constructed result:

- fixed low: quality **0.6001**, coverage **0.3802**, cost **1.0**;
- fixed mid: quality **0.9126**, coverage **0.8698**, cost **3.2**;
- fixed high: quality **0.9700**, coverage **1.0**, cost **5.8**;
- adaptive: quality **0.9627**, coverage **0.9830**, cost **2.3975**.

Interpretation: the experimental shape is promising — operation-aware allocation can approach the maximum-quality arm at much lower constructed average cost. The numbers are not FRANK accuracy, latency or energy estimates. A target trace could falsify the entire governor if routing error/overhead dominates.

## 7. Anti-attractor Salience Governor

CACC's rule `utility may change salience, not truth` is necessary but not sufficient.

A stale association can remain authentic and repeatedly win accessibility. If the reward signal is partly conditioned on what was exposed, salience can become self-reinforcing even while the canonical ledger stays perfectly correct.

C8's candidate controls:

- hard/bounded gain;
- temporal decay;
- lateral inhibition/competition;
- novelty/diversity reserve;
- negative credit for incorrect selected associations;
- reward-poisoning/regime-shift tripwires;
- role/temporal-shuffled holdouts;
- immutable truth/provenance/authority state.

### EXP-C8-SALIENCE-ATTRACTOR-002

A deliberately adversarial 64-candidate simulation made candidate 0 genuinely frequent early and ordinary after a regime shift.

Naive reinforcement:
- pre-shift accuracy: **0.5549**;
- post-shift accuracy: **0.0155**;
- stale old hub selected wrongly after shift: **0.9845**;
- final old-hub weight: **18.20**.

Guarded policy in the same constructed family:
- pre-shift accuracy: **0.8966**;
- post-shift accuracy: **0.8882**;
- stale old hub wrong-selection rate: **0.00108**;
- final old-hub weight: **0.0273**.

This establishes a counterexample/failure shape, not prevalence. The guarded settings are also not automatically optimal: inhibition/diversity can suppress genuinely useful habits, so live trade-off tests are mandatory.

## 8. Nested system/model workspace

C8 now represents two workspace levels explicitly.

### System workspace
FRANK-level candidate competition, winner identity, audience routing, gate policy and `WorkspaceEpisode` receipts.

### Model-internal uptake
A privileged latent/readout plane in the target reader if one can be found causally. `S.INTERNAL_WORKSPACE_RECEIPT` records method/readout/intervention identity.

The key scientific question is mediation:

> Does changing the FRANK system winner change behavior because the selected content enters a privileged internal model workspace, or merely because normal distributed transformer computation sees a different input?

The decisive test is a target-Qwen intervention: hold candidate/projection information fixed where appropriate, lesion/swap the internal plane, and cross truthful/shuffled re-entry. A real causal bridge predicts selective attenuation/rescue; an ordinary extra-context explanation predicts matched shuffled/token controls should rescue similarly.

No execution authority depends on a workspace probe.

## 10. Full-model Clay adaptation

The fixed goal remains full-model adaptation, not LoRA-only.

The research problem is preserving pretrained capability while transcoding the model into Clay.

External ACL 2026 evidence on source-shielded language adaptation shows that ordinary full fine-tuning can produce large source-task degradation in its tested 7B/13B setups. The protected-parameter method itself is not imposed on FRANK because the owner target requires full-model adaptation, but the forgetting mechanism is directly relevant.

C8 training curriculum:

1. freeze baseline retained-capability, OOD, authority and external-language suites;
2. natural/external P0 ↔ canonical P1 Clay semantic transcode;
3. Clay primitives, TCQS collection types, n-ary roles, epistemic and authority classes;
4. MOSAIC/UnifiedDB/ClayGraph memory-lifecycle tasks;
5. CACC truthful/stale/role-shuffled/temporal-shuffled continuity curriculum;
6. system `WorkspaceEpisode` → reader uptake/reconstruction tasks;
7. tool/effect proposal + explicit authority-negative tasks;
8. P2 compact-native rail with P1 semantic equivalence;
9. P3/hybrid only behind causal communication audit;
10. Android/resource-governor curriculum after semantic/retention gates.

Full-update-compatible mitigation candidates include rehearsal, distillation, importance/loss-adaptive scheduling and tokenizer/vocabulary alignment.

Tokenizer factorial remains:

- base tokenizer + Clay lexeme design;
- continued-BPE extension;
- aligned vocabulary / embedding transfer.

Checkpoint promotion requires more than Clay loss:

- Clay semantic execution;
- retained capability;
- OOD composition;
- authority-class separation;
- tool/effect correctness;
- external-language interoperability;
- forgetting delta;
- latency/RAM/KV/energy.

## 12. Security and authority

C8 keeps one of C7/H4's strongest boundaries:

> **native Clay cognition does not eliminate the need for deterministic effect authority.**

Prompt/task alignment and typed model outputs are defense-in-depth. The authority root remains an isolated effect-time policy/capability broker with current revocation, basis and selection checks.

`UNKNOWN` causal closure is explicit:

- known valid → proceed according to policy;
- known invalid → recompute/reject;
- unknown → broaden validation, instrument, recompute, escalate or deny depending risk.

A model-generated proposal, salient memory, workspace winner, latent internal state or Clay capability-looking object cannot mint external authority.

## 15. Reversible migration from C7

C8 is deliberately shadowable and reversible.

1. **Receipts only** — add C8 memory-demand/resource/salience/internal-uptake schemas without behavior change.
2. **Memory lifecycle classification** — classify existing state into L0–L5 while leaving current authority unchanged.
3. **Resource governor observe-only** — compare its decision to current fixed policy without routing control.
4. **Salience governor shadow** — compute guarded field beside current/frozen activation; no model visibility change.
5. **Nested-workspace instrumentation** — only where target reader hidden-state access is available; no runtime dependency on probe.
6. **Adaptive resource cutover** — after target trace Pareto and failure gates.
7. **Adaptive salience cutover** — only after role/temporal shift, poisoning and useful-habit retention gates.
8. **Physical placement tuning** — use U2/real FRANK traces to choose same-process/colocated/separate paths per operation.

## 17. Final decision

**FRANK C8 — Selective Cognitive Runtime Fabric (SCRF) is the newest OPEN FRANK architecture candidate. It does not canonically replace C7 or promote a scientific generation.**

The central architectural change is not another service split. It is a control principle:

> **FRANK should persist a rich Clay world continuously, but activate only the smallest operation-relevant causal slice required for the current decision, with explicit escalation, anti-attractor memory control, stage-resolved workspace uptake and isolated effect authority.**

The strongest remaining bottleneck is empirical, not architectural:

> **Does this selective persistent state actually improve the exact Clay-adapted target Qwen under matched information/compute, and can the benefit be causally localized from memory field -> system workspace -> model-internal uptake -> effect -> truthful re-entry?**

Until that is answered prospectively and replicated with independent ancestry, C8 remains OPEN/HOLD.
