### Core
When memory, architecture and model use one language, stored data can lexically resemble executable/privileged Clay. Clay therefore requires first-class semantic roles such as QUOTED_TEXT, OBSERVATION, INFERENCE, HYPOTHESIS, POLICY_CONTENT, PROPOSAL, RECEIPT and OWNER_CONTRACT with provenance-bound privilege.

### Boundary
The simple current Groq 8B sanity test was non-discriminating: both typed and untyped cases returned the facts. This does not validate the defense. Strong adaptive memory/graph injection attacks on the trained target remain mandatory.

### Authority
Effect paths consume privilege/types in deterministic validation before model output can become an action proposal. Lexical command shape never mints authority.
