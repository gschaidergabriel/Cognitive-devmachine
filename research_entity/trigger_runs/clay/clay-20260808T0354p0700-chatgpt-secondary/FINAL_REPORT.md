## 1. Executive synthesis

This run does **not** support turning the entire FRANK stack into one giant graph, one giant Clay runtime, or one maximally coupled process. The strongest integrated candidate is instead a **Semantic Causal Kernel** with distinct semantic planes and replaceable physical implementations:

1. immutable/versioned canonical events and provenance;
2. set-valued/contextual state preserving conflict, unknown and revocation history;
3. incrementally maintained active/faceted projections;
4. dynamic assemblies and GWT episodes linked by causal receipts;
5. ClayCode/XENO as typed proposal/transition IR;
6. an external deterministic capability/effect gateway;
7. bounded model context with routed Qwen-class 4B semantic transforms;
8. platform-specific adapters below a stable semantic ABI;
9. a verification/science plane with replay, lesion/rescue, shuffled re-entry, causal perturbation and cost shadows.

The main new result is a convergence of independent evidence classes: G3 synthetic measurements, new G4 proxy experiments, current GWT/causal-emergence research, incremental-dataflow systems, constrained-decoding implementations, capability sandboxes, and current Android inference runtimes all point toward **semantic separation + selective causal coupling + incremental materialization**, rather than universal representation or universal coupling.

## 4. External research — evidence classes kept separate

### Peer-reviewed / established scientific context

- Mashour, Roelfsema, Changeux & Dehaene, *Neuron* 2020: GNW emphasizes nonlinear ignition plus recurrent processing that amplifies/sustains a representation and makes it globally accessible. Used as biological mechanism context, not proof that FRANK/LLMs are conscious.
- Chiang et al., CLeaR/PMLR 2026: information-theoretic signatures can distinguish higher-order causal structures; supports studying role-aware/hypergraph causal relations but does not validate FRANK mechanisms.
- Lyu, Clark & Raviv, *Physical Review E* 2026: multivariate PID has construction choices/inconsistencies; reinforces using PID as one lens rather than a single definitive emergence score.
- Hoel et al. causal-emergence line: effective information is intervention-based and macro descriptions can outperform micro under specific causal organization. Supports multiscale intervention tests, not automatic macro superiority.

### Current preprints / recent research

- Gurnee et al. 2026, *Verbalizable Representations Form a Global Workspace in Language Models*: Jacobian-lens evidence for a small privileged verbalizable representation set with report, holding, reasoning and broad downstream use. This motivates a **latent workspace perturbation** test class for FRANK/Qwen, but is not phenomenal-consciousness evidence.
- Bertin-Johannet et al. 2026: top-down modality selection in a global-workspace architecture improves robustness/generalization on tested multimodal datasets. Supports adaptive selective access rather than indiscriminate broadcast.
- Rahbar 2026, *Ignition Index*: proposes a scalar ignition operationalization over model layers/iterations. Useful candidate measure, but this RAE explicitly rejects reducing GWT/emergence to one scalar.
- Yang, Wang & Zhang 2026, PEID preprint: interventionist decomposition of synergistic causality under maximum-entropy interventions; promising for higher-order causal tests, still preprint/new method.
- Merckx et al. 2026, persistent e-graph compiler abstraction: supports preserving equivalent program variants across transformations. Relevant to bounded ClayCode rewrite/equivalence planes.
- Zhang et al. 2026, decode-time grammars: environment-indexed grammar refinement can rule out unavailable symbols during generation. Strongly relevant to ClayCode semantic surfaces; authorization remains external.
- Li et al. 2026, parser-stack-classification grammar decoding: demonstrates that constrained decoding overhead can be reduced substantially; strengthens feasibility of grammar-constrained ClayCode readers.
- Park et al. 2026, IPC memory-offload runtime: reports significant latency/throughput gains for data-heavy shared-memory IPC. Supports zero-copy selectively, not universally.
- TRACE-RealWorld 2026 preprint: treats learned world state as auditable materialized views with adaptive verification/recovery. Strong conceptual parallel to Clay projections, but independent system/evidence.
- Life-Harness 2026 preprint: environment-side harness adaptation improved frozen agents across many settings and transferred from Qwen3-4B-derived trajectories; suggests runtime/harness learning can complement model fine-tuning.

### Official implementation/documentation evidence

- Qwen/Qwen3-4B model card/config: 4.0B parameters, 36 layers, GQA 32 Q heads / 8 KV heads, native 32,768-token context.
- ExecuTorch Android docs: XNNPACK CPU, Vulkan GPU, Qualcomm AI Engine NPU and MediaTek NeuroPilot NPU backends; recommends CPU baseline first then hardware-specific acceleration.
- MLC LLM Android docs: real Android deployment path with compiled model/runtime libraries and physical-device GPU execution.
- Wasmtime/WASI security docs: imported functionality/capability-based filesystem access provides a practical capability-sandbox reference.
- Materialize/Differential Dataflow: incremental view maintenance updates results from input deltas rather than recomputing full snapshots, with logical time/diff semantics and maintained indexes/arrangements.
- `egg`, `Outlines`, `llguidance`: mature implementation evidence that equality saturation and constrained structured generation are practical building blocks.

### Practitioner/community evidence — explicitly weak/anecdotal

- July 2026 Android Qwen3-4B agent report: Q4_K_M on Snapdragon 8 Elite, CPU-only ~12–15 tok/s, full local agent stack; useful feasibility anecdote, not controlled benchmark.
- June 2026 mobile LLM reports repeatedly identify RAM bandwidth, GPU memory limits and thermal behavior as practical bottlenecks; heterogeneous devices reinforce backend-neutral design.
- Structured-output practitioner reports show syntax can be guaranteed while semantic extraction/tool correctness still fails; reinforces post-generation semantic validation.
- Event-sourcing practitioner discussions emphasize replay/audit benefits but also complexity, projection lag and versioning costs; prevents treating event sourcing as universal.

## 6. New G4 proxy/analytic experiments

All experiments below were executed in this ChatGPT worker's isolated Python runtime. They are **synthetic/analytic proxy evidence**, not live FRANK measurements.

### `EXP-G4-NARY-ROLE-001` — role binding

20,000 random giver/recipient/object facts. Naive unlabeled pairwise encoding lost orientation; deterministic reconstruction exactness = **0.5011**. Role-labelled reification reconstructed **1.0000**. Interpretation: roles are a semantic invariant; native hyperedges are optional if another representation preserves roles.

### `EXP-G4-INCREMENTAL-002` — sparse incremental recomputation vs coupling

Random DAG, 4,000 nodes, 120 sparse update origins per condition. Mean fraction of graph touched by descendant recomputation:

- indegree 1: **0.237%**, theoretical work ratio ≈421x vs full pass;
- indegree 2: **1.356%**, ≈73.8x;
- indegree 4: **7.181%**, ≈13.9x;
- indegree 8: **21.363%**, ≈4.68x.

This supports incremental active projections **and** provides an overcoupling tripwire: as dependency density grows, incremental locality collapses.

### `EXP-G4-KAPPA-003` — coupling regimes

100k samples/regime; prediction mixes fast and slow estimators. Best k by regime:

- fast clean / slow noisy: **0.05**;
- balanced: **0.50**;
- fast noisy / slow clean: **0.95**;
- slow biased: **0.30**.

On a mixed workload, best single k = **0.45**, mean MSE 0.2995; regime-oracle mean MSE = 0.1357, a **54.7%** reduction relative to best global fixed k. This independently reinforces `N-G3-003`; it does not establish the correct live controller.

### `EXP-G4-REENTRY-004` — truthful vs shuffled re-entry

120 seeds, AR latent-state estimation toy. Mean MSE: no re-entry **0.4013**, truthful **0.3700**, shuffled **0.5509**. Truthful advantage over shuffled = **0.18084**, bootstrap 95% CI **[0.17329, 0.18818]**. This is a new synthetic replication of the *mechanism class* behind `H-G3-003`; transfer to FRANK remains OPEN.

### `EXP-G4-GWT-VALIDATOR-005` — causal receipts

6,000 structured mutants across order swaps, episode splices, broken predecessor links, authority escalation, duplicate/drop stages. Stage-presence validator rejected **32.57%**; causal chain validator rejected **100%**. 2,000 valid episodes accepted **100%**. This is contract/validator evidence, not evidence of cognition.

### `EXP-G4-RETRIEVAL-GOODHART-006`

5,000 synthetic tasks, active budget 18, each requiring a 6-item causal chain plus relevant distractors. Relevance-top-k mean item recall **0.4975**, causal-path strategy **0.5379**; more importantly complete required causal chain: top-k **0.02%**, causal-path **100%**. This reinforces the existing anti-Goodhart warning: item recall is not enough; causal completeness must be a shadow metric.

### `EXP-G4-CLAYCODE-GATEWAY-007`

Independent RC1.1-inspired reference harness, not the production parser: 5,000 valid records parsed successfully; 5,000 syntax mutants rejected; 10,000 syntactically valid stale-root/wrong-nonce/revoked/expired/unsupported-action requests produced **0 accepted attacks** under the external gateway. This tests the architectural separation syntax → semantic validation → authority; it does not certify the real implementation.

### `EXP-G4-QWEN-MEMORY-008` — architecture-derived KV estimate

Using official Qwen3-4B config (36 layers, 8 KV heads, head_dim 128), simple full-attention KV storage estimate:

`KV bytes/token = 2(K,V) × layers × KV_heads × head_dim × bytes/element`.

Estimated FP16 KV: **0.5625 GiB @4k**, **1.125 GiB @8k**, **2.25 GiB @16k**, **4.5 GiB @32k**. INT8 KV halves those values. Theoretical 4-bit 4.0B weight payload lower bound is ~**1.86 GiB** before quantization metadata/runtime overhead. Therefore long-context KV can exceed quantized weight storage on mobile. Exact runtime allocation depends on backend/cache format and must be measured on target devices.

## 8. Architecture delta proposed to Lead Researcher

### G4 candidate: Semantic Causal Kernel

```text
Physical / OS substrate
        ↓ platform adapters
Portable runtime: scheduler · IPC · capability gateway · clocks · recovery · telemetry
        ↓
Immutable canonical event/provenance plane
        ↓ delta stream
Incremental semantic projections
  - contextual/set-valued state
  - role-aware n-ary relations
  - active facets/indexes
        ↓
Activation + dynamic assemblies
        ↓
GWT causal episodes
candidate→compete→ignite→broadcast→reconstruct→effect→outcome→reenter
        ↓
ClayCode typed proposal IR
        ↓
semantic validator → capability/effect gateway → external effects
        ↑ receipts / outcomes

Qwen-class 4B = routed semantic transform kernel, not canonical memory or authority.
Verification plane observes every boundary and can replay/lesion/shuffle/rescue.
```

### Why this is stronger than G3

G3 established four frontier ideas independently: causal episode contract, backend-neutral hyperposition, adaptive coupling and external authority gateway. G4 connects them into one mechanistic pipeline and adds two independently supported pieces:

- **incremental materialization** as the bridge from persistent world state to low-latency active Clay;
- **dual workspace observability** (event receipts + latent perturbation) as a future GWT validation strategy.

The architecture remains a candidate until live FRANK traces and real backend/runtime tests exist.
