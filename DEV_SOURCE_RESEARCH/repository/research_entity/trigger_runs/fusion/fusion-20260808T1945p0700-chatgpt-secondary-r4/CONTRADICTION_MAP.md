# CONTRADICTION MAP — AI-Native Programming & AI Speech R4

| Proposition | Fusion verdict | Evidence / reason |
|---|---|---|
| `AI-native language` is one thing. | REJECTED | At least intent language, canonical executable IR, discrete model-native symbols, continuous latent channels and physical/effect runtime are causally distinct. |
| More compact symbolic syntax is automatically better for models. | REFUTED AS GENERAL RULE | CC10 Groq 8B: compact symbolic arm 9/16 vs raw L0 15/16; SENSE finds direct semantic parses can reduce LLM performance. |
| Canonical semantic IR and optimal model-facing view should be identical. | REJECTED | Reader representation changes performance even at equivalent intended semantics; canonical correctness and reader optimization are separate objectives. |
| Natural language is necessary for reasoning or agent-to-agent communication. | CHALLENGED | Coconut and Interlat demonstrate useful continuous latent reasoning/communication. |
| Latent communication is inherently superior because it is higher-bandwidth. | REJECTED | 2026 causal audit shows aggregate gains/losses can decompose into generic message effects and example-specific information with model-dependent signs. |
| A successful latent channel proves meaningful information transfer. | REJECTED | Requires message-content substitution/lesion controls. |
| Models converge to one universal interchangeable latent language. | WEAKENED | Semantic Hub supports shared intermediate semantics, but calibrated 2026 work finds global convergence largely disappears while local neighborhood agreement remains. |
| Stable/pure emergent symbols prove causal reasoning. | REJECTED | Fusion-1855 synthetic purity null; emergent communication can be effective yet opaque or overfit. |
| Emergent convention proves consciousness or strong emergence. | REJECTED | Science Advances demonstrates population-level conventions/bias; it does not establish phenomenal consciousness, and RAE E-CERT2 causal gates remain required. |
| AI-native programming is simply vibe coding/natural-language coding. | REJECTED | AINL, COVENANT, SIGIL, FAVA, ETAS, PDL/LMQL/SGLang/DSPy show a broader trend toward typed/compiled/validated model-centered programs and deterministic boundaries. |
| Model-native language can directly authorize effects. | REJECTED | FAVA, ETAS, PCAA plus RAE capability gateway separate proposal/meaning from authorization/commit. |
| Token vocabulary should define the semantics of Clay. | CHALLENGED | BLT shows competitive scalable language modeling from raw bytes/dynamic patches without fixed vocabulary. |
| L4's `hidden activations/KV/tensors/binary/DB/machine code` can remain one causal layer. | REVISED | Interlat and latent-channel audits establish hidden representations as an independently manipulable functional communication variable; effect/physical execution remains separate. |

## Goodman anti-echo result

The strongest new support is independently ancestried: ACL/ICLR/Science Advances papers and recent external agent-language papers do not derive from FRANK/ClayCode. Agreement with Fusion-1855/CC10 therefore counts as external convergence where mechanisms match. Shared FRANK<->ClayCode statements themselves are not counted twice.
