# ClayCode CC11 — Negative Results / Rejected Shortcuts

1. **One fixed compact Clay surface is not currently justified as the universal model view.** Generic Nemotron-Mini-4B compact P2 failed the required output contract; prior Groq 8B compact P2 scored below raw language. This does not refute target full-FT native Clay, but it refutes compactness-as-evidence.

2. **Canonical richness is not automatically the optimal reader surface.** On the NVIDIA CC10 task, typed L1 gained 6.25 percentage points but used 328 more prompt tokens (+81%) than raw. Reader/task economics remain a separate optimization problem.

3. **Source-bound projection receipts are insufficient.** CC11 fuzzing found that a receipt binding canonical input identity without the exact emitted view accepted all 20,112 constructed projected-value mutations in that attack class. Dual input/output binding is required.

4. **Payload hash is not semantic equivalence.** Hashing hidden states/KV/embeddings establishes payload identity only. It cannot prove meaning, role binding, truth or authority.

5. **Embedding nearest-neighbor similarity is unsafe as relation identity.** Fresh NVIDIA tests made reversed directed relations more similar than same-role paraphrases in both constructed pairs. Dense geometry remains retrieval/proposal evidence only.

6. **Latent communication performance alone is not proof of message-content use.** Training curriculum, extra passes, sender/receiver alignment and generic message effects are competing explanations; substitution/lesion controls remain mandatory.

7. **ClayGraph latent activation is not the model latent rail.** The former is a sparse memory salience field over a semantic epoch; the latter is transient neural communication/cognition. Shared terminology does not merge causal stages.

8. **Cross-rail agreement is not replication.** P1/P2/P3 projections with shared source/model ancestry can echo the same error.

9. **Equality saturation is not a free optimization oracle.** Current e-graph work explicitly studies tractability/analysis unsoundness and strategy/memory control. CC11 therefore rejects unbounded equivalence saturation as the default ClayCode runtime.

10. **Rail planner choice is not authority.** A learned/LLM planner may rank candidate views but cannot enlarge semantic closure, change hard requirements or waive capability/effect checks.

11. **No canonical promotion from this run.** Exact target Qwen full-model adaptation, live FRANK integration, hidden-state/KV interventions and formal proof remain unrun/unavailable in this worker.
