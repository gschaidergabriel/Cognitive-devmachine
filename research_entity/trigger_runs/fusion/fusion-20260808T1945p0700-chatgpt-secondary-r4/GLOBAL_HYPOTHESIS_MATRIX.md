## Fusion-2 architecture candidate

### CLAY-L5 — Five-Plane AI-Native Speech Contract (OPEN)

Fusion-1855's CLAY-L4 correctly separated intent, canonical semantics, model-native symbols and neural/physical implementation. New independent evidence requires one further distinction: continuous hidden states/KV/embeddings can be a **functional cognitive/communication channel**, not merely passive physical implementation.

```text
P0  EXTERNAL INTENT
    human/agent goals, prose, vibe, constraints
            |
            | ICSL: extract -> adequacy -> commit
            v
P1  CANONICAL CLAY SEMANTICS
    exact typed intent/claims/causal basis/authority requirements
            |
      +-----+-------------------------+
      |                               |
      v                               v
P2  DISCRETE NATIVE RAIL        P3  LATENT NATIVE RAIL
    learned Clay symbols             hidden states/embeddings/KV
    compact model views              high-bandwidth cognition/communication
    interpretable handles            model/layer/version specific
      |                               |
      +-------------+-----------------+
                    |
                    | proposal/receipt back to P1 semantics
                    v
P4  EFFECT / PHYSICAL RUNTIME
    deterministic lowering, capability gateway, tools, DB, binary,
    effect/outcome/re-entry receipts
```

Hard rule: **P2 and P3 are cognitive/communication representations, never execution authority or canonical truth.**
