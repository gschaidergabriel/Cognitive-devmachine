# HYPOFUSION R3 — Contradiction Map

## 1. Adaptive recurrence vs simpler compute allocation

Internal proxy: pressure+trend matched fixed-12 success with ~47.1% fewer steps in authored synthetic dynamics. External recurrent-depth work supports adaptive compute, but independent work also reports overthinking and memory/depth interactions.

Resolution: **OPEN NARROWING**. Keep recurrence, but do not canonize pressure+trend. Memory/state capacity, stability and overthinking become competing variables.

Discriminator: matched-compute Ubuntu H1 factorial.

## 2. Compiler provenance vs semantic correctness

Prior negative evidence already showed that a self-consistent source/hash chain can accompany wrong lowering. Verified-compiler practice independently treats behavioral preservation as a separate obligation.

Resolution: provenance remains necessary audit evidence, never semantic-preservation proof. Add independent semantic oracle/translation validation.

## 3. Effect typing vs authority closure

Internal proxy: brokered opaque authority accepted 0 unauthorized attempts in the constructed 100k mixed corpus, while an ambient backend bypassed the broker 10,000/10,000 times and structural capability records were forgeable 20,000/20,000 times.

Resolution: type/effect expressibility != runtime authority. Authority must survive lowering as an unforgeable/out-of-band runtime property; resource lifetime and revocation remain separate.

## 4. Online MVC semantics vs need for online learning

Internal 100k-transition proxy supports representability and rollback/open-set state rules after correcting an over-strong test oracle. External open-set/prototype literature makes the design plausible but does not prove continual adaptation is needed.

Resolution: semantic expressibility **strengthened**; online-learning utility **OPEN**. Frozen open-set prototype baseline is mandatory competitor.

## 5. One deterministic scheduler vs deterministic replay with recorded choices

Internal async proxy: disjoint operations had no schedule divergence, conflicting operations did; replay without recorded choice mismatched 66,583/100,000 race workflows, while recorded choices had zero proxy mismatches.

Resolution: reject the strong claim that one arbitrary global scheduler is the only production semantics. Still keep single-threaded authoritative H1 as a simpler countercandidate.

## 6. Lesion recovery vs causal necessity

Adaptive synthetic system compensated a lesion over time, nearly erasing delayed error while frozen lesion remained impaired. External plasticity work provides an independent analogue for rapid/slow compensation.

Resolution: post-adaptation recovery cannot be read as absence of acute causal dependence. Freeze learning for one causal lane and separately measure adaptive compensation.

## 7. Observational/state equivalence vs intervention equivalence

Late Emergenz experiment produced observationally equivalent H1/H3 trajectories before lesion, yet naive low-level H3 lesion changed causal effect. Translating the semantic intervention through the representation map restored effect equivalence to numerical precision. Causal-abstraction literature independently requires intervention mappings for cross-level equivalence.

Resolution: H1/H2/H3 equivalence must include **intervention commuting**, not only state/output parity.

## 8. ClayGraph reversal robustness vs plasticity cost

RAB strongly reduced false reversal under correlated source echo, but context-aware scalar state already handled ordinary context bifurcation and RAB incurred more lag at high noise/diversity thresholds. Data-incest literature independently shows that re-used dependent information causes overconfidence.

Resolution: provenance diversity is a targeted anti-echo mechanism, not universal graph-state complexity. Compare against explicit source-correlation weighting.

## 9. Component PASS vs release PASS

H-WP-01 is durably COMPLETE as a component and H-WP-04 has 9/9 remote-sandbox deterministic tests. Both explicitly deny H1 release or target-Ubuntu proof. BASE ClayCode gate remains IN_PROGRESS/NOT_PASS with all 14 formal BASE work packages OPEN and no application acceptance PASS receipts.

Resolution: operational progress is real but does not promote H1 or canonical science.

## 10. Strict LALR diagnostic existence vs parser closure

A strict Ubuntu CI workflow exists to localize D-LALR conflicts, but the expected durable `STRICT_LALR_D_CONFLICT_RECEIPT.json` was not present at the screening cutoff.

Resolution: workflow existence is tooling progress, not evidence that the parser blocker is closed. Keep BASE parser/source-chain closure as active blocker until the receipt and production-chain tests exist.
