## 1. Executive synthesis

C5 finds that the next FRANK architecture boundary is not another cognitive organ. It is a **causal-basis and projection-integrity layer connecting already separated organs**.

C4 correctly introduced the `CognitiveFrame` because individually fresh state channels can still form a causally torn workspace basis. Fresh ClayGraph G1d, Clay G9 EPOCH, ClayCode CC9, GWT Run 4 and Hyperposition H3 extend that result in four directions:

1. **The basis is multidimensional but operation-specific.** Exact state, CognitiveFrame, semantic graph epoch, activation epoch, query/selection plan, projection semantics and capability state may all advance independently. A trusted operation declares only the dimensions it actually depends on and their compatibility rules. One universal global vector lock would reject harmless unrelated churn.
2. **Record provenance is not selection provenance.** Authentic facts can still be routed into cognition through a corrupted/noisy selector, graph, Assembly or query plan. Effect-bound cognition therefore needs a Selection Integrity boundary before GWT/effects.
3. **Semantic workspace state is not the reader projection.** A deterministic `Reader ABI Compiler` should resolve sound deterministic semantics before the model and emit a disposable target-reader projection with semantic/schema/wire/query/order/selection receipts.
4. **Graph prior, candidate formation, workspace selection, projection/uptake and re-entry are different causal stages.** A bundled “GWT on/off” experiment is not evidence for workspace causality when the neighboring stages change with it.

The C5 workspace path is therefore:

```text
exact/event state
 -> CognitiveFrame
 -> semantic graph epoch
 -> compatible sparse activation epoch
 -> bounded ActiveAssembly + exact anchors + selection receipt
 -> operation-specific Certified Basis / CognitiveEpochCapsule
 -> candidate set
 -> GWT competition/selection/ignition
 -> semantic WorkspaceEpisode
 -> deterministic Reader ABI projection
 -> ProjectionReceipt / uptake receipt
 -> model
 -> proposal
 -> K0 compositional closure + capability gateway
 -> effect/outcome receipt
 -> causally compatible re-entry
```

Hard separation remains:

`truth != activation != GWT ignition != reader projection != execution authority`.

## 4. External research

Current external literature was used as architecture-class evidence, not as proof that FRANK already works this way.

- **Graph-based Agent Memory: Taxonomy, Techniques, and Applications** (arXiv:2602.05665) separates graph-memory extraction, storage, retrieval and evolution, supporting the decision not to collapse all memory stages into one graph operation.
- **SYNAPSE** (arXiv:2601.02744 / ACL Findings 2026) combines graph spreading activation, lateral inhibition and temporal decay, independently supporting the plausibility of a sparse associative activation mechanism while not implying truth or GWT ignition.
- **Structured Output Collapses Answer Diversity Across 44 Language Models** (arXiv:2607.18476) supports treating structured reader projection/format as a causal model input rather than neutral serialization.
- Linux **RCU** provides a concrete implementation analogue for immutable published versions plus delayed reclamation: readers can retain an older consistent object while writers publish a new one.
- SQLite `ATTACH DATABASE` documents a useful negative implementation boundary: crash-atomic behavior across multiple attached databases is conditional and can fail under WAL/main-db conditions, reinforcing the rule that physical DB colocation or attachment does not automatically produce one semantic atomic state.

These sources are evidence-class distinct from internal synthetic tests, hosted 8B proxies and live runtime measurements.
