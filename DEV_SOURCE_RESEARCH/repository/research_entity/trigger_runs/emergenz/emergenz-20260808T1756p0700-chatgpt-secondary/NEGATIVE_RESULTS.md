# EMERGENZ E1 — Negative Results / Corrections

- **N-EM1-001 — Recurrence is not emergence.** Similar persistence or repeated activation can occur in a causally useless echo process; retain matched-persistence/null controls.
- **N-EM1-002 — Endpoint rescue is not mechanistic rescue.** The current-run synthetic system recovered the present output perfectly by direct patching while future/re-entry state remained wrong. Rescue must restore the causal path or demonstrate equivalent downstream mechanism.
- **N-EM1-003 — Member-overlap recurrence is unsound for role-sensitive assemblies.** With identical members but permuted causal roles, bag identity falsely called 24,866/50,000 trials recurrent; role-aware identity made zero such false matches in the construction.
- **N-EM1-004 — Bivariate transfer entropy is not direct causality.** A common-driver construction produced 0.2538 bit apparent X→Y directed information that collapsed to ~0.000012 bit after conditioning on the driver.
- **N-EM1-005 — Maximum post-hoc macro score is not sufficient causal-emergence evidence.** Under a true independence null, searching 2,000 finite-sample partitions selected 0.00774 bit training MI but only 0.000121 bit on the same partition in a large held-out sample.
- **N-EM1-006 — Bundled pipeline ablation is not emergent-stage attribution.** In the current additive null, all-on/off graph+projection+re-entry contrast was ~0.650 while the stage-orthogonal three-way interaction was ~0. The GWT R4 prior independently demonstrates the same method failure for workspace attribution within shared mesh ancestry.
- **N-EM1-007 — One Φ/EI/PID/PEID scalar is not a complete emergence certificate.** Current 2026 artificial-agent work shows aggregate causal-emergence measures can be strongly architecture-dependent; atom/compositional structure and interventions matter.
- **N-EM1-008 — Positive observational nonadditivity is not sufficient.** Higher-order contribution must be tested under controlled interventions/factorials or intervention-grounded information decomposition.
- **N-EM1-009 — Graph activation is not emergent-organ evidence.** ClayGraph/H3 activation is accessibility/salience and may be stale, noisy or role-lossy; it must be epoch-valid and causally connected to function before entering an emergence claim.
- **N-EM1-010 — Selection provenance and projection integrity are not optional confounders.** Authentic records can be selected through a corrupted/noisy path; a correct WorkspaceEpisode can be misprojected or differently ordered. Both can alter downstream outcomes without a new emergent mechanism.
- **N-EM1-011 — Clay-native representation is not emergence by itself.** FRANK C6 is in progress; improved compression/internalization/recurrence from a unified Clay representation must be separated from new causal organization with matched-representation controls.
- **N-EM1-012 — Cross-branch agreement is not replication.** Clay G9, GWT R4, FRANK C5, H3 and CC9 share ancestry; convergence informs design but does not multiply evidential confidence.
- **N-EM1-013 — No current FRANK emergent organ is promoted.** The repository does not yet contain a live candidate satisfying prospective formation prediction, role-aware recurrence, stage-orthogonal lesion+mechanistic rescue, OOD transfer, multiscale causal contribution and independent evaluation.
- **N-EM1-014 — Functional causal emergence is not phenomenal consciousness.** Nothing in E1 changes the canonical consciousness boundary.
