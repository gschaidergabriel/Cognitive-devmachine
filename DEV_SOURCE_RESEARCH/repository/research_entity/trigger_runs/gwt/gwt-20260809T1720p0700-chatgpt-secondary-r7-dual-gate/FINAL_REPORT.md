## Exact experiment — candidate-surface boundary

`EXP-GWT-R7-FILTER-BOUNDARY-001` is an exact model-free enumeration.

Let relevant set be `R`, model/internal candidate surface `Wi`, external/system surface `We`, and FILTER mean `We subset_of Wi`. Recall is `|W intersect R| / |R|`. Since `(We intersect R) subset_of (Wi intersect R)`, external recall cannot exceed internal recall.

Executable enumeration over universe size 6 checked **41,895** non-empty FILTER cases:

- recall-improvement violations: **0**;
- recall equal: **14,231**;
- recall lower: **27,664**;
- precision improved: **15,482**.

A control allowing AUGMENT instead of subset-only filtering checked **250,047** cases; recall improved in **83,307**.

Therefore a pure-filter external GWT can improve selectivity but cannot rescue relevant content that never entered its declared input surface. A nested model-workspace -> system-workspace bridge must type its relation as `FILTER | AUGMENT | RECONSTRUCT | UNKNOWN`.

This exact invariant does not show that Qwen has a model-internal workspace or that augmentation helps Frank.
