2. **Activation timestamp is not semantic validity.** The H3 proxy retained revoked relation support when activation outlived the semantic epoch that generated it.
3. **Pairwise flattening is an activation hazard.** It can synthesize false associative recipients from different n-ary events as relation overlap grows.
4. **Native hypergraph storage is still not mandatory.** Relation-instance identity + explicit roles preserved the tested semantics exactly.
5. **Always-incremental is rejected as a universal policy.** ClayGraph C4 and H3 rematerialization results show workload-dependent rebuild crossover.
6. **Fixed change-fraction thresholds are insufficient.** Expected reads-before-next-update materially alter amortized cost.
7. **Maximum coupling/unbounded diffusion is unsupported.** External higher-order diffusion theory and the H3 proxy support controlled propagation, not global spread.
8. **Sparse activation speed/specificity is not cognitive benefit.** Matched truthful/shuffled/no-field model experiments remain open.
9. **Groq 8B remains a proxy.** It does not close the target Qwen-class 4B reader experiment.
10. **ClayGraph G1d remains HOLD.** H3 feedback does not promote accepted generation/state.
11. **Semantic Scholar failed with HTTP 429 and Tavily with HTTP 403 in this run.** Their evidence surfaces were covered by OpenAlex/arXiv/Exa/native-web/primary-source fallbacks; no silent provider success is claimed.
12. **No emergence or consciousness inference.** Persistent activation, self-reference or causal integration are functional mechanisms only until the Emergence Certificate is satisfied.
