# ATOMIC — ACEF-V0.1 final research report

## Result

This run produced one radical measured Frank v0.1 research candidate: **Atomic Causal Epoch Fabric (ACEF)**.

ACEF is not promoted. It is a `NOVEL_COMBINATION_CANDIDATE` whose purpose is to test whether Frank benefits from one lease-fenced semantic visibility/commit geometry across cognitive state, GWT/Hyperposition, external-effect outcomes, causal credit and re-entry.

## Why this candidate survived prior-art destruction

Direct agent transactions are already represented by Cordon; transactional belief admission by MemTX; event-sourced agent execution by ESAA; speculative durable execution by libDSE; recovery dry-runs by PILOT; dependency-guided recovery by FRACTAL; monotonicity/coordination by CALM; incremental retractions by Differential Dataflow; belief dependency/revision by TMS; alternative assumption environments by ATMS; and capability safety by recent language-level agent work.

Therefore ACEF does not claim novelty for any of those components individually. Its research novelty is the Frank-specific composition and architecture-compression proposal.

## Core semantic change

Cognitive organs emit immutable typed `SemanticDelta` values. Safe deterministic monotone evidence may be admitted early. Non-monotone and effect-coupled state remains branch-local until a `CommitCertificate` proves current execution lease, schema and identity lineage plus required outcome/causal-use conditions. External effects retain the current Frank authorization/reservation/attempt/unknown/verification lifecycle and are never fictionally rolled back. GWT operates as selection/broadcast over a transaction branch; Hyperposition is the unresolved branch set; UnifiedDB is canonical persistence; ClayGraph is a differential/rebuildable projection.

## Executable discriminator

A local bounded reference simulator enumerated 336 provider/fault/recovery scenarios per architecture over provider outcomes, idempotency, crash positions, reconciliation outcomes and cancellation.

The deliberately weak LOOSE reference produced 176/336 scenarios with at least one encoded invariant violation. TASK_TX and ACEF produced 0/336 violations under the encoded invariants. ACEF retained raw monotone evidence in 144/144 cancelled scenarios; TASK_TX retained it in 44/144. The model assigns ACEF 2.988 mean synchronous commit barriers versus 4.815 for TASK_TX, but that number is a model assumption, not a latency measurement.

The simulation is a discriminator only. It is not current Frank target-runtime evidence, does not execute compiled ClayCode, and does not perform a real external provider effect.

## Strongest counterhypothesis

ACEF may be over-unification. Current Frank contracts plus a Cordon-like task transaction or MemTX-like belief transaction could match correctness/recovery with materially less compiler/runtime/storage complexity. This counterhypothesis remains strong and unresolved.

## Kill criteria

Reject ACEF if matched real tests show no cross-surface correctness/recovery gain; if a simpler transaction baseline dominates it; if monotonicity classes cannot be deterministic at the type/runtime boundary; if branch/causal metadata violates target resource budgets; if the candidate requires an opaque second semantic architecture; or if it weakens the existing Frank external-effect lifecycle.
