### Core
“All Clay” should mean one target semantic IR family, not one literal text/storage format. Canonical Clay, model Clay, graph Clay, wire Clay, ClayVector/Tensor and platform Clay are typed projections/lowerings of one semantic system.

### Evidence / boundary
A C6 deterministic size proxy showed textual vector representation increasingly larger than a typed binary payload as dimensionality grew; this is not a production benchmark. MLIR-style multi-dialect lowering is an external implementation analogue.

### Implication
Native Rust/C/SQL/tensor/mmap implementations remain valid if generated/validated against Clay semantics and cannot silently become a second semantic source of truth.
