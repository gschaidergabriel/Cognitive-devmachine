# CIT-001 architecture delta

Status: `TEST_OBLIGATION_ONLY / NO_PRODUCT_CHANGE`

CIT-001 does **not** add a Frank v0.1 runtime organ now.

The durable result of this run is a bounded research option for large uncertain causal cones:

`current candidate cone -> current topology/prior quality check -> if narrow/high-quality prior: exact tests directly -> else if safe replayable + sparse/additive diagnostics plausible: CIT pooled probe screen -> complement audit -> exact confirmation -> exact verified-outcome-bound causal witness -> reward/re-entry`

## Retained laws

1. `CORRELATED_ONLY` evidence never becomes material learning credit.
2. CIT reconstruction is a candidate ranking, never `RewardOutcomeEvidence.causal_credit`.
3. Exact positive confirmation binds the exact current effect, attempt and verified outcome hash.
4. External provider effects are never reissued for tomography.
5. Stale/fidelity-unknown projection rows are rejected.
6. Dense/nonlinear/uncertain regimes abstain or fall back.
7. A complement-only audit challenges missed causes before acceptance.
8. An exploration floor preserves some uniform exact probes so a mistaken screen cannot permanently starve an unseen cause.
9. When a calibrated current dependency/prior ranking is already strong, skip CIT and spend budget on direct exact tests.
10. Persisted `DONE`/old screen/old confirmation is not sufficient current semantic authority; causal support must be revalidatable.

## Required future discriminator before any promotion

On a current bounded replayable Frank component or loop-core episode on the accepted Hostinger target, compare:

A. full individual lesions;
B. prior/dependency-guided active individual lesions;
C. trusted factorized-DAG bounded responsibility where available;
D. learned counterfactual critic with explicit validity monitoring;
E. CIT pooled probes + audit + exact confirmation.

Use frozen current episodes with:

- true used vs broadcast-only candidates;
- redundant and joint causes;
- sparse and dense causal cones;
- additive and interaction-heavy cases;
- stale replay and provenance break;
- shuffled group masks;
- recovery/restart;
- explicit no-learning;
- exact verified-outcome hash mutation;
- lesion/rescue.

Measure:

- exact-confirmed cause recall/precision;
- false material-credit admissions (must be zero under accepted gate);
- total interventions and fallback rate;
- p50/p95/p99 probe + confirmation latency;
- CPU/RSS/I/O/storage writes;
- replay/recovery latency;
- support invalidation behavior;
- reward-state divergence;
- complexity/maintenance delta.

**Kill CIT** if B/C/D match or beat E on exact-confirmed cause yield per total cost with lower complexity, or if realistic cone density/nonlinearity makes CIT fallback dominate.
