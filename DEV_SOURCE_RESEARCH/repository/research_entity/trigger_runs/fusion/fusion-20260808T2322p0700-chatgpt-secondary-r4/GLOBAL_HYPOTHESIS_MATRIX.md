## F7-H1 — Orthogonal control planes are the stable synthesis

**Synthesis.** FRANK C8, UnifiedDB U2, Hyperposition H5 and ClayGraph G2a converge on the same architecture constraint: semantic identity, activation/propagation, selection/workspace, physical placement, persistence/rebuildability and effect authority should be separately typed and separately testable.

**Counterhypothesis.** A strongly unified runtime can safely collapse several of these axes and gain latency/simplicity without losing causal identifiability or recovery.

**Falsifier / highest-information test.** Run matched implementations that deliberately collapse one pair of axes at a time versus the orthogonal design; measure correctness, replay, selection identity, crash recovery, latency and authority violations on real FRANK traces.

**Affected branches.** clay, frank, gwt, claycode, hyperposition, claygraph, unifieddb.

## F7-H2 — Safe-effect closure should compose across generated code

**Synthesis.** The late Clay Safe-Effect Geometry delta fits the existing external authority boundary if child programs cannot acquire effects outside the parent Clay contract: `EffectiveEffects(child) subseteq Effects(parent)`.

**Counterhypothesis.** Typed effect closure at the ClayCode/compiler boundary is insufficient because subprocesses, FFI, kernels, resource exhaustion or ambient authority create effective capabilities outside the declared effect algebra.

**Falsifier / highest-information test.** Adversarial foreign-code matrix across Python/Bash/C/Rust/WASM/FFI/plugins/subprocesses with pinned parent capabilities; attempt destructive writes, deletion/format/truncate/drop, secret exfiltration and resource exhaustion while measuring ordinary compile/test/refactor/deploy utility. Runtime containment must hold independently of model refusal.

**Affected branches.** clay, frank, claycode, unifieddb.
