# GWT Dual Workspace and Causal Closure — Summary

Status: **OPEN architecture/research delta**. No live-FRANK or phenomenal-consciousness promotion.

The current candidate now separates the full causal chain into independently testable stages:

`exact/event state → CognitiveFrame → ClayGraph latent activation/Assembly (candidate prior only) → candidate set → competition → selection → gate_event → WorkspaceEpisode → reader projection → reconstruction/uptake → effect → outcome → causal-freshness re-entry`.

`LATENT_WS` remains an optional model-internal uptake/intervention plane; `EVENT_WS` remains the system-level receipt-defined workspace. Run 3 established the methodological separation `configured gate != endogenous ignition evidence` and `transport/read != semantic reconstruction/uptake`.

**GWT Run 4 adds causal stage orthogonality.** A downstream performance change cannot be attributed to workspace selection when graph activation/candidate membership, CognitiveFrame consistency, projection order/detail, reader encoding or re-entry also changed. CSOC-GWT-R4 therefore binds frame/root, graph+activation epochs, Assembly/candidate-set hashes, competition/winner, gate policy, WorkspaceEpisode, projection hash/order/reader version, uptake, effect, outcome and re-entry receipts.

ClayGraph C4 is integrated as the mandatory memory substrate branch. Its sparse latent field may be a useful **candidate-prior/availability mechanism**, but graph spreading activation is not truth, workspace ignition or broadcast. Its decisive no-field/truthful-field/shuffled-field model experiment remains open.

FRANK Cycle 4 strengthens the same separation: all competing channels should derive from one `CognitiveFrame`, while semantic WorkspaceEpisode and Qwen-facing projection are distinct. A workspace can be fresh yet frame-inconsistent; a correct winner can be behaviorally confounded by winner-first/full-detail projection.

Run-4 synthetic negative control demonstrated the danger quantitatively. In a constructed model with **zero true workspace-selection effect**, a bundled `GWT on/off` comparison falsely reported `+0.23961`; the orthogonal workspace contrast was exactly `0`. Judge0 independently reproduced `+0.23981` bundled versus `0` clean. With a nonzero constructed workspace mechanism, bundled delta was `+0.31133` while the isolated workspace contribution was only `+0.08443`.

A new Groq `llama-3.1-8b-instant` `8b_proxy_for_4b` test also showed strong reader-side confounding. With truthful GRAPH_PRIOR+WINNER metadata, one arm chose the first presented candidate 12/12 times and achieved only 5/12 truth; an exact replication repeated the same choices. Metadata-free pure order controls scored 10/12 original order versus 8/12 reversed order. Earlier mesh evidence independently within the same proxy family found 87.5% neutral versus 62.5% reversed order and 0/8 truth under deliberately scrambled semantic projection. These are proxy diagnostics, not Qwen3-4B/live-FRANK results.

Current external 2026 evidence reinforces the boundary: spreading-activation systems can improve graph retrieval/memory without being GWT, while ACL 2026 prompt-order work shows decoder causal attention can create >14 percentage-point order effects. Projection is therefore a causal stage, not formatting noise.

Highest-information next steps: instrument CSOC receipts on live/twin FRANK → graph-field × workspace-selection factorial with projection counterbalanced → projection mediation → gate/recurrent identifiability → Core/Qwen reconstruction/uptake → pinned Qwen LATENT_WS×EVENT_WS cross-lesion.
