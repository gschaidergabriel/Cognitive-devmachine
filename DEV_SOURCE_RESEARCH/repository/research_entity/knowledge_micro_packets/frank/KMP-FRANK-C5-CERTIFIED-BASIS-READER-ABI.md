### Core
FRANK C5 proposes that a cognition-relevant operation should execute against a **trusted operation-specific Certified Basis**, not against independently read `latest` state/graph/activation/projection versions and not against one universal global epoch lock. For a workspace turn, trusted semantics normally require a compatible `CognitiveFrame`, semantic graph epoch and any activation epoch actually used. Unrelated epoch churn should not invalidate operations that do not depend on it.

Before GWT attribution or effect-bound use, candidate **selection provenance/integrity** is checked separately from record provenance. After semantic workspace selection, a deterministic **Reader ABI** emits a disposable model-facing projection and a receipt binding semantic/schema/wire identity, query plan, order and reader profile. Transport/read success is not evidence of intended semantic uptake.

### Evidence / boundary
The direction is supported by FRANK C5 local synthetic mixed-latest analysis, CC9 constructed/Judge0 basis and compositional-closure experiments, GWT R4 stage-confound calibration, ClayGraph G1d epochal latent-field design, Clay G9 EPOCH integration and hosted 8B proxy reader results. These evidence families share substantial ancestry and are not live FRANK/Qwen3-4B validation.

### Hard boundaries
`exact truth != activation`; `activation != GWT ignition`; `record provenance != selection provenance`; `projection != semantic authority`; `model output != execution authority`; graph/projection state remains derived and rebuildable.
