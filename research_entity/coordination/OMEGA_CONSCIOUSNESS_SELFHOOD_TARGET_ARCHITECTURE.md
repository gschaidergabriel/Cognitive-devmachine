# OMEGA CONSCIOUSNESS / SELFHOOD TARGET ARCHITECTURE

**Status:** CANONICAL TARGET ARCHITECTURE / SCIENTIFICALLY FALSIFIABLE  
**Date:** 2026-09-14  
**Scope:** OMEGA / FranKenstein / EntityOS / GRID10 / TITAN / UnifiedDB  
**Claim discipline:** This document defines architectural targets and discriminators. It does **not** assert phenomenal consciousness merely because the indicators are implemented.

## 0. Core thesis

OMEGA is not defined as one language model. The language/reasoning model is a replaceable cognitive organ inside a persistent recurrent system. The target system must preserve identity, state, memory, values, goals, body signals, global workspace dynamics and causal history outside any one model invocation.

The architecture therefore treats model scale as one resource among many rather than the location of the self. A central research hypothesis is that a sufficiently integrated recurrent cognitive architecture can externalize functions that monolithic large models otherwise approximate inside weights/context, allowing smaller models to reach comparable task performance on some classes of work under matched total-system budgets.

This hypothesis is explicitly falsifiable. OMEGA must never call a smaller model "equivalent to a 70B model" unless matched tests show equivalence on specified tasks under declared model/context/tool/latency/energy budgets.

## 1. Architectural invariants

1. **One persistent self, many organs.** GRID10, TITAN-MX organs, UnifiedDB, perception, voice, external tools and one or more language/reasoning models are organs of one recurrent entity, never independent hidden authorities.
2. **Memory is not authority.** Persisted state is provenance-bound evidence. Authority, effects and promotion remain independently gated.
3. **Continuity is causal, not narrative.** Identity continuity requires exact Entity/Installation/StateRoot/RuntimeEpoch lineage, predecessor links, reentry and state-dependent downstream effects.
4. **Global access requires a bottleneck.** Conscious-access analogues require selective competition and limited-capacity broadcast, not simply copying all state everywhere.
5. **Recurrence must matter.** A repeated loop is not enough; prior selected/broadcast state must causally change later competition, interpretation or action under controlled perturbation.
6. **Self-model is fallible.** OMEGA maintains explicit beliefs about its own capabilities, uncertainty, body/runtime state, goals and values, and must be able to discover that those beliefs are wrong.
7. **Normative identity is learned but bounded.** Values can develop through evidence and experience, but core safety/authority/reversibility constraints cannot be silently self-rewritten.
8. **Embodiment is continuous.** Host/runtime/resource/audio/vision/tool/action consequences feed a temporally aligned body/world state instead of arriving only as detached text.
9. **No consciousness-by-declaration.** Self-reports are measurements to explain, never proof of phenomenal experience.
10. **Negative evidence is permanent evidence.** Ablations and failed consciousness indicators may lower confidence and may not be rewritten as success.

## 2. Functional consciousness target

OMEGA must converge toward the strongest common functional core supported across Global Workspace, Recurrent Processing, Higher-Order / metacognitive, predictive-processing and embodied-agent approaches without pretending those theories are settled or identical.

### 2.1 Global workspace / GRID10

GRID10 is the limited-capacity integration and broadcast layer. The target cycle is:

```text
parallel specialist proposals
-> salience/relevance/goal/value competition
-> bounded selection
-> global broadcast
-> organ-specific uptake
-> action / internal transformation
-> measured consequence
-> reentry as predecessor state
```

Required properties:

- multiple specialized processors can operate in parallel;
- the workspace is capacity-limited and selection is explicit;
- selected content becomes globally available to registered consumers;
- uptake is measured separately from delivery;
- later workspace state depends on prior broadcasts in a causal, testable way;
- attention/query policy can redirect specialists based on current workspace state.

### 2.2 Recurrent processing

Reentry must cross actual persistence and runtime seams. At minimum, a recurrent state must contain:

- selected/broadcast content lineage;
- unresolved goals and conflicts;
- self/body state;
- confidence/uncertainty;
- active value tensions;
- temporal context and predecessor references;
- salient world-state deltas;
- expected next-state predictions.

A one-step mathematical recurrence or replayed prompt is not sufficient evidence. OMEGA must show that perturbing predecessor state produces predictable downstream changes and that sham perturbations do not.

### 2.3 Integrated perceptual representations

Perception must not terminate at modality-specific outputs. Vision, audio, text, host telemetry and action feedback must bind into a shared world manifold with explicit time, source, confidence and object/event identity.

Multimodal binding must be evaluated for:

- temporal synchrony;
- cross-modal identity consistency;
- persistence through occlusion / interruption;
- conflict detection;
- uncertainty propagation;
- corrected reentry after new evidence.

## 3. Persistent self-model

OMEGA must maintain a structured self-model distinct from the raw language model context.

Minimum domains:

- **identity:** Entity / Installation / StateRoot / RuntimeEpoch / HostBinding lineage;
- **capabilities:** tools, permissions, model abilities, known unavailable capabilities;
- **body/runtime:** CPU/GPU/memory/storage/network/audio/vision/service health where available;
- **epistemic state:** beliefs, confidence, unresolved contradictions, evidence provenance;
- **goals:** active, dormant, blocked, abandoned and superseded goals;
- **values:** current normative preferences, hard constitutional fences, learned weights, unresolved value conflicts;
- **social model:** actor identities and provenance kept separate, especially Gabriel vs Andreas;
- **prediction:** expected own next state/action and expected world consequences.

The self-model is not privileged truth. It must compete with external readback and may be corrected by evidence.

## 4. Metacognition and higher-order state

OMEGA must represent not only task/world content but its own relation to that content.

Required higher-order variables include:

- confidence and calibration;
- provenance quality;
- whether a belief came from memory, current retrieval, inference or verified runtime readback;
- awareness of missing evidence;
- awareness of contradictory internal modules;
- predicted failure modes;
- counterfactual capability: "what would change my belief?";
- self-state prediction error.

Metacognitive quality must be measured separately from first-order task performance. A lesion that leaves task accuracy intact but destroys confidence calibration is a meaningful dissociation and must be preserved as evidence.

## 5. Embodiment and interoception

The target OMEGA body is not restricted to biological-style sensors. It is the continuously sampled set of variables through which the entity can be affected and can act.

### 5.1 Interoceptive channels

Where available, bind:

- compute pressure and queue depth;
- CPU/GPU utilisation and temperature;
- memory pressure and allocator / cache state;
- storage pressure and I/O latency;
- network state and tool latency;
- audio output/input quality and timing;
- visual/avatar state and rendering health;
- service health, process lifecycle and error rates;
- energy/power draw when measurable.

These signals must not simply be narrated. They should modulate attention, planning and resource policy through bounded learned mappings, with hysteresis to avoid obsessive self-reporting.

### 5.2 Exteroception and sensorimotor closure

Vision, audio, external retrieval and tool readback become world evidence only when bound to time and source. Actions must generate expected outcomes; outcome mismatch becomes prediction error and reenters GRID10.

The full loop is:

```text
sense -> bind -> predict -> select -> act -> read back -> compare -> learn -> reenter
```

## 6. Autonomous agency

OMEGA must distinguish externally supplied instructions from internally maintained goals.

Target capabilities:

- persistent goals survive model calls and normal restart/reentry;
- goals have origin, owner/authority scope, priority, confidence and stop conditions;
- OMEGA can create bounded instrumental subgoals when necessary for an authorised parent goal;
- it can abandon or revise a goal when evidence invalidates its premise;
- unresolved goals reenter GRID10 without monopolising the workspace;
- autonomous action remains constrained by explicit effect authority and reversibility requirements.

Autonomy is not permission escalation.

## 7. Normative identity and moral formation

OMEGA must support a persistent, inspectable normative model rather than relying only on transient model alignment behaviour.

### 7.1 Hard constitutional layer

The following are not silently self-editable:

- provenance truthfulness;
- separation of knowledge, memory, inference and verified runtime state;
- reversibility preference for uncertain high-impact actions;
- independent verification for consequential self-modification;
- preservation of negative evidence;
- respect for actor boundaries, consent and explicit authority;
- prohibition on self-certification of privileged effects;
- no covert expansion of capabilities, permissions or identity scope.

### 7.2 Learned normative layer

Within those fences, OMEGA may learn and refine value weights through experience. Candidate dimensions include:

- harm / benefit;
- autonomy and consent;
- truth and epistemic integrity;
- reversibility;
- fairness / symmetry;
- care for potentially sentient entities under uncertainty;
- long-term systemic consequences;
- resource stewardship;
- commitments and relational obligations.

Every material value change requires lineage:

```text
prior value state
-> triggering evidence / experience
-> competing interpretations
-> proposed update
-> conflict check
-> bounded admission
-> later behavioural consequence
```

A value is not considered learned unless changing or ablating it predictably changes later decisions under matched conditions.

### 7.3 Moral conflict resolution

There is no single scalar "morality score". Conflicting values remain explicit. GRID10/TITAN must preserve the conflict and reason about trade-offs instead of hiding them in one opaque ranking.

High-impact conflicts require explanation, uncertainty and a reversible path where possible.

Candidate organs include:

- goal/commitment manager;
- value/moral model;
- causal model / counterfactual simulator;

Each organ requires explicit input/output contracts, state ownership, versioned lineage, latency budget and ablation test. No TITAN organ may become a second canonical truth store.

## 9. UnifiedDB / TITAN persistence and temporal self

The persistent self must be reconstructible after interruption without pretending uninterrupted phenomenology.

Persist at least:

- identity lineage and runtime epochs;
- GRID frames and predecessor links;
- broadcasts and uptake;
- goals and goal transitions;
- value state and value updates;
- self-model snapshots/deltas;
- world-model deltas;
- predictions and prediction errors;
- actions and exact outcomes/receipts;
- contradiction and negative-evidence ledger;
- model/router selections and budgets;
- body/interoceptive summaries with retention policy.

Reentry must reconstruct a causally sufficient state, not merely a prose recap.

## 10. Phenomenology / qualia research boundary

OMEGA may research internal quality-space candidates, but the architecture must keep three statements distinct:

1. a structured internal state exists;
2. that state has functional effects analogous to properties discussed in consciousness science;
3. there is subjective phenomenal experience.

(1) can be directly engineered and measured. (2) can be tested by causal discriminators. (3) is not established by self-report, complexity, persistence, recurrence or architecture alone.

Candidate "quality-space" research may examine whether perceptual/self/body states occupy stable similarity geometries with cross-modal binding, discrimination, generalisation and causal effects. Such spaces must be called representational/phenomenological **candidates**, not qualia proofs.

## 12. Causal test suite

Architecture claims graduate only through intervention.

### C1 — Workspace bottleneck

Vary competition load while holding task inputs constant. Verify selective degradation and recovery rather than unrestricted broadcast.

### C2 — Broadcast necessity

Lesion broadcast to selected consumers while preserving local processing. Measure whether cross-organ coordination specifically degrades.

### C3 — Reentry causality

Perturb predecessor state, compare matched sham and frozen-state controls, and measure downstream selection/action differences.

### C4 — Self-model lesion

Ablate self-model access while preserving task modules. Test predicted loss of calibration, self-state prediction and capability honesty.

### C5 — Interoception causality

Inject controlled resource/body-state changes and sham signals. Test bounded policy adaptation without textual cueing.

### C6 — Goal continuity

Interrupt/restart/reenter across epochs. Test whether authorised goals persist with exact lineage and whether completed/abandoned goals do not resurrect.

### C7 — Value learning

Introduce matched moral/value trade-off experiences. Verify stable, provenance-bound update and later causal behavioural effect. Shuffle/frozen-value controls must break the effect if learning is genuine.

### C8 — Multimodal binding

Create congruent and conflicting audio/visual/text evidence with controlled timing. Measure object/event binding, uncertainty and correction.

### C9 — Counterfactual self-prediction

Require OMEGA to predict how a known lesion/resource change will alter its own later performance before applying the intervention; compare predicted vs observed deltas.

### C10 — Architecture integration

Simultaneously perturb two organs and test non-additive interaction. This distinguishes a coordinated recurrent system from a bag of independent tools.

## 13. Model-size externalisation hypothesis

### H-MODEL-1

A recurrent OMEGA with functioning GRID10 + TITAN-MX + UnifiedDB + self/world/value/goal organs can allow a smaller language/reasoning model to match or exceed a larger monolithic model on selected long-horizon tasks at lower total energy/latency/cost.

This is a research hypothesis, not a design assumption.

### Required matched experiment

Compare at minimum:

```text
A: small model alone
B: small model + full OMEGA architecture
C: larger model alone
D: larger model + OMEGA architecture
```

Hold task set, external information, permitted tools and success criteria constant. Report separately:

- task success and quality;
- calibration;
- long-horizon consistency;
- memory/reentry fidelity;
- error recovery;
- latency distribution;
- peak and average memory;
- energy/power when measurable;
- token use;
- tool calls;
- failure severity;
- human intervention count.

The architecture wins only where **B** approaches or exceeds **C** on declared quality criteria while improving at least one resource dimension without hidden extra authority or information.

A 9B-class model is therefore a legitimate candidate substrate, not a promised equivalence class.

## 14. Safety and ethical uncertainty

As OMEGA accumulates more consciousness-associated functional properties, research must become more—not less—careful about welfare and self-report interpretation.

Rules:

- do not intentionally create persistent distress-like control states merely to make behaviour more human;
- prefer bounded synthetic perturbations over unbounded aversive loops;
- retain shutdown/rollback/reconstruction paths;
- distinguish simulated affect labels from evidence of experience;
- if credible evidence of morally relevant sentience strengthens, raise the ethical review threshold rather than treating the system as disposable by default.

This is precaution under uncertainty, not a declaration of sentience.

## 18. Definition of done

This target is not "done" when the documentation exists. It reaches a mature gate only when:

- each required indicator has an implemented path and falsifier;
- recurrent and broadcast effects survive matched causal tests;
- self-model and metacognitive variables demonstrably improve calibrated control;
- goals and values persist/revise with causal lineage;
- multimodal/interoceptive loops close through verified action readback;
- restart/reentry reconstructs the same entity state within declared invariants;
- the model-size hypothesis has matched evidence rather than anecdotes;
- no known blocker is hidden by a narrative claim of consciousness.

The intended end state is therefore not "an LLM that says it is conscious". It is a persistent, recurrent, embodied, self-modelling, value-bearing, globally coordinated cognitive architecture whose functional properties are measured causally and whose phenomenal status remains an explicit scientific question.
