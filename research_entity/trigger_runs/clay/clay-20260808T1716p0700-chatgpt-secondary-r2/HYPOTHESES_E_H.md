# Clay G9 first-generation hypotheses E–H (64/64)

## E — GWT / CognitiveFrame / freshness
- **H-G9-E01** Workspace competition over one immutable CognitiveFrame/graph epoch reduces mixed-basis winner artifacts versus asynchronous source reads. **Falsifier:** live/twin mixed-basis rate and downstream outcomes are unchanged.
- **H-G9-E02** A GWT episode should carry `graph_epoch` and `projection_id` separately from state/root freshness. **Falsifier:** fields never detect reconstruction/selection mismatches.
- **H-G9-E03** Graph-prior activation and workspace selection are causally distinct and separable in a 2×2 intervention. **Falsifier:** they cannot be independently manipulated or outcomes are completely collinear.
- **H-G9-E04** Winner metadata/order must be counterbalanced because reader sensitivity can mimic workspace effects. **Falsifier:** large target trials show negligible order/label effects.
- **H-G9-E05** Freshness scheduling should include selector/projection epoch drift as well as source revisions. **Falsifier:** selector/projection changes never alter decisions at fixed source state.
- **H-G9-E06** Transport, semantic projection, receiver uptake and effect are independently lesionable stages. **Falsifier:** instrumentation proves stages operationally inseparable.
- **H-G9-E07** Configured ignition thresholds and graph activation must remain excluded from endogenous ignition evidence. **Falsifier:** controlled threshold shifts reveal threshold-invariant pre-gate nonlinear/recurrent signatures.
- **H-G9-E08** Re-entry should require episode/frame/projection compatibility with current causal state. **Falsifier:** incompatible re-entry performs equally without more stale decisions.

## F — Hyperposition / relation semantics
- **H-G9-F01** Canonical n-ary identity or role-labelled reification preserves semantics lost by unlabeled pairwise flattening under randomized serialization. **Falsifier:** pairwise form exactly reconstructs roles without side information.
- **H-G9-F02** Small-reader projections should prefer explicit relation-instance role labels over compact function-like n-ary syntax until target evidence reverses this. **Falsifier:** pinned target reader consistently favors compact n-ary on accuracy/cost.
- **H-G9-F03** Semantic S, coordination C, physical P and selector Q topologies should remain separable operational views. **Falsifier:** one topology replaces them without semantic/correctness/cost loss.
- **H-G9-F04** Selector topology Q can change accessibility without changing semantic truth or physical storage. **Falsifier:** selector changes necessarily mutate truth/storage.
- **H-G9-F05** Scope-coverage confidence should gate coordination independently of semantic-relation confidence. **Falsifier:** relation confidence predicts all unsafe scope misses.
- **H-G9-F06** Epoch-pinned Assemblies preserve contextual alternatives without destructive merge and replay from exact basis + relation ids. **Falsifier:** same basis replays different alternatives/order.
- **H-G9-F07** RETRACT/REPLACE/COMPENSATE should incrementally update selector/coordination projections while retaining immutable historical relation identity. **Falsifier:** incremental semantics diverge from rebuild.
- **H-G9-F08** Physical graph-database unification is unnecessary if the semantic ABI preserves relation identity, epochs and query-plan semantics. **Falsifier:** a supported semantic operation requires one physical graph backend.

## G — Emergence / causal memory
- **H-G9-G01** Long-lived sparse activation is not emergence evidence unless lesion changes preregistered function beyond recurrence-matched controls. **Falsifier:** persistence alone predicts unique causal contribution.
- **H-G9-G02** Truthful latent memory needs content-specific rescue, not compute-matched activity rescue. **Falsifier:** shuffled/content-free rescue restores the same function.
- **H-G9-G03** Emergent memory-organ claims require OOD recurrence of causal contribution across tasks/episodes. **Falsifier:** contribution disappears OOD.
- **H-G9-G04** Higher-order synergy/PEID should be measured on intervention-defined components after shared-ancestry/routing controls. **Falsifier:** synergy vanishes under intervention or is common-routing artefact.
- **H-G9-G05** Graph restructuring that improves retrieval is adaptation, not emergence, absent reproducible nonadditive causal function. **Falsifier:** no nonadditive contribution.
- **H-G9-G06** Self-evolving reader-writer loops require anti-Goodhart tests because feedback can amplify selection bias/poisoning. **Falsifier:** adversarial feedback cannot shift selection while preserving reward.
- **H-G9-G07** A transient epoch-pinned Assembly may be a better candidate causal unit than a persistent node/module. **Falsifier:** Assemblies lack stable lesion/rescue signatures across recurrence.
- **H-G9-G08** GWT/activation/emergence evidence does not by itself imply phenomenal consciousness; functional mechanism remains the claim boundary. **Test boundary:** no operational consciousness falsifier is asserted by this run.

## H — Edge/runtime/resource governor
- **H-G9-H01** A unified governor should jointly allocate compaction, active-set pruning, context zoom, graph escalation, KV and model path. **Falsifier:** independent controllers dominate after interaction/switching overhead.
- **H-G9-H02** Expected decision utility per latency/energy/memory is a better objective than raw recall or token minimization. **Falsifier:** utility-aware policy is not Pareto-better on downstream success-cost.
- **H-G9-H03** Android/edge thresholds must adapt to thermal/backend/KV state rather than copy server thresholds. **Falsifier:** server-tuned policy stays Pareto-optimal in sustained mobile traces.
- **H-G9-H04** Speculative decoding should activate only above a device/model-specific predicted acceptance crossover. **Falsifier:** always-on speculation is never worse on target workloads.
- **H-G9-H05** Exact-address recall can reduce context/HBM pressure while preserving recoverability compared with keeping all tool history inline. **Falsifier:** addressable compaction loses required evidence or costs more end-to-end.
- **H-G9-H06** Semantic consolidation should be event/shift-triggered instead of every turn/write. **Falsifier:** always-consolidate is equally cheap and more accurate.
- **H-G9-H07** Local-first SQLite/FTS plus optional graph/vector overlays can satisfy many FRANK memory paths without mandatory graph server. **Falsifier:** target relational workloads require unavailable external-server semantics/performance.
- **H-G9-H08** Crash/recovery must cover selector epochs, latent-field reconstruction, pending compaction and effect intents as one recovery envelope. **Falsifier:** independently recovering planes is always equivalent under fault injection.

## Counterhypotheses / hard alternatives
- **CH-G9-01:** Well-tuned SQLite/FTS may outperform all graph escalation on actual FRANK workloads.
- **CH-G9-02:** Latent activation may add correlated noise; explicit retrieval may capture all useful memory influence more cheaply.
- **CH-G9-03:** Query-plan compilation may overfit benchmark structure and fail on open semantic questions.
- **CH-G9-04:** Selection-integrity hardening may erase graph-association latency gains on effect-bound work.
- **CH-G9-05:** Immutable epochs may create reclamation/memory pressure making mutable transactional storage superior.
- **CH-G9-06:** Exact-address zoom may add round-trips that lose to larger context windows.
- **CH-G9-07:** Reader-specific projections may fragment the ABI and increase maintenance cost.
- **CH-G9-08:** A native graph/hypergraph backend may eventually dominate overlays at target scale.
- **CH-G9-09:** Recurrence-matched controls may still miss hidden common-cause dynamics.
- **CH-G9-10:** Integrated governors may chatter/Goodhart; independent hard limits may be safer.
