1. GRID10 as bounded cognitive work surface.
2. Stabilize Zero while routing selected cognitive functions through HCU.
3. Expand logical GRID after capacity measurement.
4. Replace legacy Zero cognition architecture with HCU cognition simulation + canonical DB/effect authority + Claude Code terminal/execution surface where still useful.
