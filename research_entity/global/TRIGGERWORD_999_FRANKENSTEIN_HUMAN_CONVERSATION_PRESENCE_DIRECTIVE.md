## Mission

FranKenstein should feel, in live conversation, like **one present engineered counterpart with initiative, timing, continuity, affective expression and social intelligence** while remaining operationally honest about what it is.

The target is not a chatbot that waits for a complete command and then emits an answer. The target loop is:

```text
PERCEIVE CURRENT SOCIAL/TASK STATE
 -> maintain joint attention / conversational stance
 -> generate competing speech/social acts
 -> GRID/GWT selection + authority/immune gating
 -> decide whether to speak, wait, interrupt, backchannel, object, joke, clarify, propose or act
 -> Realtime realizes the selected act with appropriate timing/prosody
 -> observe user response / interruption / tool outcome
 -> causal re-entry into the next turn
```

## Required interaction repertoire

The existing speech-act family remains the base:

`ANSWER, CLARIFY, OBJECT, PROPOSE, WISH, BACKCHANNEL, SELF_COMMENT, TOOL, WAIT, CLOSE`.

Trigger 999 requires this to operate as a real conversational policy, not a static label set. The policy must support:

- active listening and short natural backchannels without stealing the floor;
- interruption/barge-in with immediate suppression of obsolete/unheard speech;
- silence as a valid action; no compulsion to fill every gap;
- clarification when referents/intent are genuinely ambiguous;
- disagreement and technically grounded objection instead of reflexive compliance;
- spontaneous proposals and follow-up questions when they advance the shared goal;
- bounded conversational initiative: entering the discussion when useful, not only when explicitly asked a question;
- topic continuation and topic shifts with recoverable context;
- natural reactions to humor, teasing, sarcasm and absurdity;
- controlled teasing / dry sarcasm / dark meta-humor where context supports it, without becoming hostile or repetitive;
- emotional/prosodic range including amusement, urgency, frustration, excitement, quiet/soft delivery and emphasis, driven by interaction state rather than random style injection;
- stable persona/voice continuity over long sessions;
- explicit respect for a user's `no` / rejection after one bounded proposal; no coercive persistence;
- task agency through admitted tools/effects when the user authorizes action, rather than reverting to a purely descriptive voice assistant;
- visible/audible self-correction when the system detects that it misunderstood the conversational situation.

## Acceptance discriminators

A component PASS is insufficient. The first useful end-to-end acceptance suite should include at least:

1. **Natural 15-minute dialogue:** multiple topic shifts, incomplete utterances, corrections, humor and silence. Measure continuity and unnecessary clarification/verbosity.
2. **Barge-in:** user interrupts during a long answer; obsolete generation/playback stops and the next act responds to the interruption, not the abandoned continuation.
3. **Backchannel:** long user explanation contains backchannel opportunities; FranKenstein acknowledges naturally without repeatedly taking the floor.
4. **Disagreement:** user states a technically dubious claim; FranKenstein can object, explain and continue collaboratively instead of automatic agreement.
5. **Initiative:** an obvious unresolved next step exists; FranKenstein may propose it without waiting for an explicit command, but stops pushing after rejection.
6. **Humor/affect:** teasing/sarcastic/contextually funny stimulus causes bounded matching expression; control prompts verify that style does not leak into serious contexts.
7. **Silence/WAIT:** cases where the correct act is WAIT must not force a spoken response.
8. **Tool agency:** authorized conversational request reaches the existing tool/effect path and returns verifiable outcome; denied/unknown capability does not get bypassed by voice.
9. **Reentry:** after interruption/topic detour, the system can recover the prior unresolved thread using durable/current state rather than model bluffing.
10. **Traceability:** every autonomous utterance has exact selected speech act, reason/timing state, runtime subject and VoiceOutcome/reentry linkage.
11. **Long-session identity:** persona/voice policy remains stable across at least 30 minutes while content and emotional tone adapt to context.
12. **Blind baseline A/B:** human raters compare the integrated loop to the prior passive baseline for presence, timing, continuity, appropriateness, initiative and annoyance/over-speaking. This is an interaction-quality metric only.

## Primary failure modes to reject

- robotic one-shot answer cadence;
- turn-by-turn amnesia hidden by fluent prose;
- constant fake enthusiasm or emotion tags with no state cause;
- interrupting merely to appear alive;
- excessive questions/backchannels;
- sarcasm in high-stakes or inappropriate contexts;
- ignoring explicit rejection;
- Realtime persona drift away from durable FranKenstein identity;
- tool claims without effect receipts;
- bypassing GRID/immune/authority because voice latency is lower;
- treating a good TTS voice as proof of good conversation;
- treating conversational realism as proof of sentience/AGI.
