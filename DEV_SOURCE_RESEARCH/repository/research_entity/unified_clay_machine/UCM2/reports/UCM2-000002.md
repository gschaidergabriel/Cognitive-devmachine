## Question

Can one isolated key module already hold and self-read several previously separate Clay surfaces — generic state, world model, Hyperposition, wiki, graph relation and worker experience — while preserving a single monotonically advancing epoch?

## Hypotheses

H1. A single semantic root plus generic typed objects can represent heterogeneous Clay surfaces without creating a database per subsystem.

H2. A frontier worker can treat the machine itself as the experimental interface: write state, query self-read, record an experience and verify the persisted result.

H3. Experience records can remain first-class machine state instead of existing only in external prose/logs.

## Counter-hypotheses

C1. A single-root object fabric will immediately become too weak to distinguish state/world/wiki/Hyperposition semantics.

C2. Graph relations may accidentally become a separate authority surface rather than derived/link state.

C3. Experience recording may fail to preserve ordering/provenance relative to state mutations.
