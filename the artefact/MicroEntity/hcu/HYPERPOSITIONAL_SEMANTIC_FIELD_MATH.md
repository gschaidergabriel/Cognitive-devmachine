## 2. Typed world-state hyperposition

For issue/region `q` at epoch `t`, define a typed alternative set

```text
H_q(t) = { a_i = (x_i, e_i, c_i, tau_i, p_i, f_i) }_{i=1..n}
```

where:
- `x_i` is the semantic state/claim/hypothesis representation;
- `e_i` is epistemic class (observed, measured, hypothesis, counterhypothesis, forecast, unknown);
- `c_i` is calibrated support metadata, not truth authority;
- `tau_i` is valid/observed time;
- `p_i` is provenance/causal identity;
- `f_i` is falsifier/counterevidence state.

Multiple alternatives may remain simultaneously active. Selection does not delete losing alternatives unless a canonical supersession/retraction rule does so.

## 3. Hyperdimensional semantic carrier

A module may project typed states into a high-dimensional carrier `z_i in R^d` from the exact local ~0.8B representation or an admitted learned projection.

The carrier is an **associative computational coordinate system**, not canonical truth.

A generic field state may be written

```text
Z_q = sum_i alpha_i * z_i + sum_r beta_r * psi_r(z_{r1}, ..., z_{rk})
```

with:
- `alpha_i`: context/accessibility activation;
- `psi_r`: typed higher-order relation operator;
- `beta_r`: measured relation gain.

Canonical identity stays in the typed records and receipt lattice; `Z_q` is rebuildable from admitted sources when feasible.

## 4. Dynamic coupling model

For HCU module `m`, candidate state evolution is modeled as

```text
x_m(t+1) = Phi_m(
    B_m u_m(t)
    + sum_j g_mj K_mj(x_m(t), x_j(t-d_mj))
    + sum_{j,k} h_mjk K_mjk(x_m, x_j, x_k)
    + r_m(t)
)
```

where:
- `u_m` is the selected local semantic projection;
- `g_mj` is pairwise coupling gain;
- `h_mjk` is higher-order/hyperedge gain;
- `d_mj` is explicit delay;
- `r_m` is re-entry/broadcast input from Global J-Space/GWT;
- `Phi_m` is the exact bound module transform.

This is a control/readout model. Gains/hyperedges are admitted only when interventions show stable predictive/useful effects.

## 6. Measurable emergence / irreducibility

For a proposed higher-order relation `R`, compare the full model against the strongest matched pairwise/state-machine reduction `R_pair*`.

Candidate irreducibility readout:

```text
Delta_R = L_pair* - L_full
```

where `L` may combine held-out prediction loss, intervention-response mismatch, replay divergence, workspace-selection mismatch and normalized runtime cost.

`Delta_R > 0` alone is not sufficient. Promotion also requires lesion/rescue evidence and scope-bound repeatability.

Synergy/PEID/PID readouts remain preferred when feasible, following the existing Hyperposition readout contract.

## 7. Resonance as a controlled readout

"Resonance" is not a mystical variable. In HCU it means a repeatable amplification or stabilization caused by coupled modules/relations under a fixed basis.

A candidate normalized resonance readout for an intervention window is

```text
R_ij = EffectCoupled(i,j) - EffectAblated(i,j)
```

or, for higher order relation `r`:

```text
R_r = outcome(full_r) - outcome(best_reduced_r)
```

with outcome defined before the experiment (prediction quality, selection stability, task utility, calibration error, etc.).

A resonance is retained only if it survives topology shuffle, gain perturbation, delay perturbation and rescue controls.

## 9. Forecast branches

For forecast branch `b`:

```text
S_b = C_base * exp(-lambda_s * depth_b) * exp(-lambda_t * horizon_b)
      * E_b * B_b
```

where `E_b` summarizes evidence quality and `B_b` branch stability. This mirrors the current HCU source ranking concept.

`S_b` is a scheduling score unless calibrated against outcomes; it is not automatically a probability.

## 10. Zero information bottleneck

Let `W_t` be the active world field and `D_t` the current Zero decision demand. The HCU seeks a projection

```text
C_t = P(W_t | D_t)
```

that minimizes cognitive payload subject to preserving decision-relevant information and explicit uncertainty.

Operationally this means ClayCode capsules with references/handles rather than raw world-state dumps.

The projection receipt binds both the source semantic state and the exact emitted view, following the MRSC projection-witness rule.

## 11. Global J-Space composition

For local module projections `J_m`, use versioned maps `P_m` into a shared basis:

```text
J_global = Aggregate({ P_m(J_m) })
```

The aggregate preserves module identity, role, epoch and uncertainty. It is not a commutative truth vote.

For Claude Code the current admitted architecture uses a compiled projection `Q(J_global)` into Claude's exposed context/control surface and measures the returned candidate at the system level. No equation here implies direct access to Claude private activations.

## 12. Canonical rebind and falsification

Any associative/field route used for consequential cognition rebinds to canonical MiniUnifiedDB identities before state/effect admission.

Learned/approximate routes remain revocable under a shadow exact-reference sentinel. Distribution drift can invalidate a route even when model/index hashes do not change.

## 13. Required experimental discriminators

Before calling this substrate "controlled emergent compute", execute at minimum:

- pairwise vs n-ary matched-budget comparison;
- edge and hyperedge lesions;
- gain and delay sweeps;
- topology shuffles;
- frozen-model / changed-topology control;
- frozen-topology / changed-context control;
- re-entry break and rescue;
- local-module vs multi-module matched-token comparison;
- deterministic replay under exact basis/runtime;
- Zero decision-quality vs projection-size curve;
- external-provider-removed boot/retrieval/cognition test.

Until these discriminate the mechanism, the design remains a candidate architecture, not a verified claim of controllable emergence.
