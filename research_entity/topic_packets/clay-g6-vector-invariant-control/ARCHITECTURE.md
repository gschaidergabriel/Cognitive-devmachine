# G6 Architecture Candidate — Vector-Governed Invariant-Confluent Semantic Causal Kernel

## Semantic planes

1. **Canonical Event / Provenance Plane** — append/versioned identity, history, evidence roots and effect receipts.
2. **Contextual State Plane** — set-valued hyperposition preserving alternatives, conflict, unknown and revocation.
3. **Incremental Projection Plane** — shared/faceted arrangements over deltas; online `R_delta` estimate and uncertainty.
4. **Activation / Assembly Plane** — bounded active working sets selected by expected causal utility, not truth or salience alone.
5. **GWT Plane** — candidate, compete, ignite, broadcast, reconstruct, effect, outcome, re-entry with causal receipts.
6. **Latent Workspace Probe Plane** — optional instrumentable-model probes used only as independent mechanistic evidence, never canonical state.
7. **ClayCode Proposal Plane** — grammar and Γ-state-aware typed proposals bound to explicit root/epoch.
8. **Closure / Authority Plane** — decides whether a proposal may remain local or requires coordination/real-world capability checks.
9. **Platform Runtime Plane** — Linux/Android adapters, model backends, scheduler, IPC, recovery, thermal/memory governor.
10. **Verification Plane** — replay, lesions, rescue, causal interventions, PID/PEID, fuzzing, invariants and Goodhart shadows.

## Causal Budget Vector

`B_t = [context_KV, active_workspace, recompute, coupling_reentry, speculation, coordination]`

Observations include `R_delta` + uncertainty/trend, causal-path completeness, novelty/uncertainty, workspace divergence, invariant/conflict risk, thermal state, KV pressure, speculative acceptance, error/recovery signals and task utility.

A hierarchical implementation is preferred if it matches a central vector controller while reducing control overhead. A scalar summary may be exposed for telemetry but is not the only control degree of freedom.

## Local/speculative admission rule

A proposal may remain local/speculative only if all applicable conditions hold:

- it is reversible or quarantined before authority;
- no real-world capability has been exercised;
- its Γ/root/epoch is fresh enough for state semantics;
- concurrent merge is proven/known invariant-confluent for the relevant invariant class, or the proposal is isolated from shared invariants;
- replay and provenance receipts are retained.

Otherwise it enters coordination and/or authority closure. Effectfulness is therefore one dimension, not the whole classifier.

## ClayCode pipeline

`grammar -> Γ(root/epoch) -> typed semantic proposal -> current-root/invariant validation -> capability/policy/nonce/rollback checks -> effect -> receipt`.

The model cannot add capability terminals or authorize itself. Grammar constraints are correctness aids and may themselves be adversarial inputs; safety policy remains independent.

## Workspace evidence

Represent workspace evidence as a vector rather than one scalar:
- receipt/order completeness;
- ignition dynamics;
- latent verbalizable/global-use representations;
- downstream mediation;
- lesion/rescue effect;
- truthful/shuffled/delayed re-entry effect;
- OOD recurrence/stability.

Agreement strengthens a functional mechanism claim only when interventions support it. Divergence is retained as diagnostic evidence. None implies phenomenal consciousness.

## Edge governor

Expose CPU/GPU/NPU backend, frequency/power mode, thermal state, context/KV allocation and speculative-decoding acceptance to feedback control. Objective is sustained task utility under latency, energy, memory, thermal and recovery constraints, not peak tok/s.
