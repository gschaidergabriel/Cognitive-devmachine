# Hypofusion R6 — Contradiction Map

## C6-01 — Preserved semantics vs executable semantics
**Evidence A:** WP03 bridge v2 preserves and distinguishes residual semantics with real Ubuntu/tamper evidence on a narrow production bridge scope.  
**Evidence B:** 100 residual nodes / 10 classes remain unlowered; WP03 is OPEN.  
**Unresolved contradiction:** lossless identity can coexist with unusable or silently stranded meaning.  
**Discriminator:** explicit WP04 legality + WP05 consumption/fail-closed disposition for every class versus generic opaque-consumer baseline.  
**Architecture consequence now:** no WP03 package/BASE promotion; opaque semantics remain non-authoritative.

## C6-02 — More routing views vs independent completeness evidence
**Evidence A:** multi-view reconciliation can repair missed recipients in synthetic routing.  
**Evidence B:** V3 correlated dual-plane run showed no qualitative recall advantage, and its numeric outputs are currently non-reproducible.  
**Unresolved contradiction:** a second view may be redundant if it shares the same upstream failure ancestry.  
**Discriminator:** reproducible exact-blob run plus real-repo correlated-view vs independently-derived-audit vs dense-fallback fault matrix.  
**Architecture consequence now:** no promotion from V3 synthetic evidence; ancestry is part of completeness confidence.

## C6-03 — Omnisource re-entry vs overcoupling/backpressure
**Owner-fixed law:** all newly available registered data is an ingestion candidate and material semantic deltas must re-enter research.  
**Counterhypothesis:** per-observation fusion/re-entry can amplify duplicates, stale invalidations, false interrupts and resource cost.  
**Discriminator:** periodic-batch vs materiality-gated incremental source-cursor replay at equal coverage and correctness.  
**Architecture consequence now:** source coverage is fixed direction; routing/materiality/backprop implementation remains falsifiable and rollbackable.

## C6-04 — Dedicated contradiction retrieval vs diversified relevance retrieval
**External mechanism evidence:** specialized contradiction retrieval exists because similarity search is not naturally optimized for refutation retrieval.  
**Counterhypothesis:** diversified hybrid retrieval plus model reasoning is sufficient and cheaper.  
**Discriminator:** frozen known-support/refutation corpus measuring contradiction recall, false conflict, abstention/calibration, decision impact and cost.  
**Architecture consequence now:** candidate test obligation only; no retrieval architecture promotion.

## C6-05 — Rich reward state vs simpler scalar causal outcome value
Feature-specific/distributional/multitimescale reward evidence strengthens the richer candidate family externally, but Frank's historical causal reward subspace remains incompletely measured.  
**Discriminator:** H1 caller/channel/outcome/E-PQ/re-entry instrumentation followed by historical vs scalar vs typed vs typed+multihorizon factorial.  
**Architecture consequence now:** H-HF5-02 remains OPEN_BASELINE_GATED.

## C6-06 — Observer/durability performance vs causal audit guarantees
SQLite WAL semantics and prior local fsync results establish plausible performance/backaction tradeoffs, not a winner.  
**Discriminator:** no-observer/same-file/isolated observer plus strict-per-record/group-commit crash and power-loss-surrogate factorial.  
**Architecture consequence now:** no same-file/isolation or fsync/group-commit preference is promoted.
