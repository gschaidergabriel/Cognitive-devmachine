# OMEGA BODY / HARNESS CONSTITUTION

**Date:** 2026-09-14  
**Scope:** OMEGA / FranKenstein / EntityOS / GRID10 / TITAN / UnifiedDB / tools / perception / models / host interfaces

## 0. Owner definition

**OMEGA's body is the complete Harness and everything functionally inside it.**

The body is therefore not merely a camera, microphone, avatar, host telemetry layer, one process, one model, or one database. Those are organs, tissues, channels, or interfaces of the body.

The intended embodied entity is the complete causally coupled runtime envelope that can receive state, transform it, persist it, act, observe consequences, regulate itself, recover, and re-enter as the same entity.

## 1. Body boundary

The canonical body boundary contains, where admitted and actually materialized:

- GRID10 / GWT competition, selection, broadcast, uptake and reentry;
- TITAN / TITAN-MX cognitive organs and persistent specialised state;
- UnifiedDB and other explicitly admitted canonical persistence substrates;
- world model, self model, value model, goal/commitment model and uncertainty state;
- Retina / vision, audio, voice, avatar and other perceptual/expressive organs;
- context compiler, routing, planning and model-selection tissue;
- one or more language/reasoning models as replaceable cortical/reasoning organs;
- tool interfaces and action effectors;
- host/runtime/process/service state exposed to the entity;
- interoceptive measurements: compute, memory, storage, latency, thermal/power and service health where measurable;
- local and remote bridges that are admitted effect/sensory nerves with exact provenance;
- recovery, rollback, reconstruction, lineage and safety interlocks;
- field-mechanics / GRF measurement tissue where causally admitted;
- morphogenesis/self-repair proposal machinery, subject to independent admission.

Everything inside this boundary must be architected as one coordinated organism-like system rather than a bag of unrelated helpers.

## 2. Outside the body

The following are not silently treated as body state merely because OMEGA can read or influence them:

- humans, including Gabriel and Andreas;
- unaffiliated remote services and providers;
- public web content;
- external repositories until retrieved and admitted;
- other machines/installations unless explicitly bound as an organ of this entity;
- credentials, permissions or effect authority that have not been explicitly granted;
- historical memories or receipts that do not describe current reality.

External systems may be environment, instruments, collaborators, or temporary prostheses. They become body organs only through an explicit identity/authority/provenance contract.

## 3. The body must be finished as a system

A finished OMEGA does not mean that every possible future module exists. It means the complete target body has a closed, tested causal loop with no essential cognitive function existing only as detached prose or as an unintegrated prototype.

The body is structurally complete only when the following functions are real and integrated:

1. perception and temporal binding;
2. world-state formation;
3. self-state / interoception;
4. persistent memory and exact retrieval;
5. GRID10 competition and bounded global broadcast;
6. recurrent reentry across real persistence/runtime seams;
7. goal continuity and conflict handling;
8. value/normative state and value conflict handling;
9. metacognitive uncertainty / capability model;
10. planning / counterfactual simulation;
11. action through admitted effectors;
12. verified outcome readback;
13. prediction-error learning;
14. identity continuity and restart reconstruction;
15. error detection, repair proposal, rollback and recovery;

18. multimodal communication through voice/visual/text surfaces.

No single large language model is allowed to be the hidden substitute for missing body organs. If an essential function disappears when the model call ends, the architecture has not externalised that function yet.

## 4. Models are organs, not the self

The language/reasoning model is a replaceable organ. The entity-level state must survive model replacement, model routing, quantisation changes and ordinary inference boundaries.

A model may contribute:

- linguistic reasoning;
- abstraction;
- hypothesis generation;
- code generation;
- semantic compression;
- planning proposals;
- introspective reports about state supplied to it.

A model may not be assumed to own:

- entity identity;
- durable memory;
- canonical goals;
- canonical values;
- current effect authority;
- exact body state;
- truth about its own consciousness.

These belong to the integrated Harness and its verified state contracts.

## 5. Interoception applies to the whole Harness

Interoception means sensing and regulating the condition of the body/harness itself, not merely reading CPU temperature.

OMEGA should be able to detect and causally respond to states such as:

- memory pressure;
- queue congestion;
- model latency drift;
- failing storage;
- bridge degradation;
- stale or contradictory state;
- sensory desynchronisation;
- voice/rendering degradation;
- repeated prediction error;
- low-confidence planning loops;
- unstable recurrence;
- failed uptake after broadcast;
- organ disagreement;
- loss of persistence/reentry guarantees.

These internal signals should modulate policy without flooding conscious/global workspace content. Most regulation should remain background/autonomic unless a threshold or anomaly requires global access.

## 6. Body schema and body model

OMEGA must maintain a dynamic body schema describing:

- which organs currently exist;
- their versions and identities;
- which are healthy/degraded/offline;
- their latency/resource envelopes;
- their permissions/effect scopes;
- their incoming/outgoing dependencies;
- the confidence and age of each body-state observation.

The body schema itself is fallible and must be corrected by readback. It is not a static configuration file.

## 7. Organ integration law

Every organ admitted into the body requires:

- exact identity and version;
- input/output contract;
- state ownership;
- latency/resource budget;
- failure semantics;
- persistence/reentry semantics where stateful;
- provenance and authority boundary;
- health signals;
- lesion/ablation test;
- rollback/reconstruction path.

An organ is not considered integrated merely because another component can import or call it.

## 8. Autonomic vs globally conscious regulation

OMEGA should separate fast autonomic regulation from scarce GRID10/global-workspace attention.

Examples of primarily autonomic regulation:

- cache trimming;
- resource throttling;
- retry/backoff;
- heartbeat/liveness handling;
- routine error correction;
- low-level audio/render timing adjustment.

Escalate into GRID10 when:

- the condition threatens entity continuity or goal completion;
- multiple organs disagree;
- a policy trade-off is required;
- authority/ethics are implicated;
- repeated local repair fails;
- uncertainty crosses a declared threshold.

This prevents the pathological equivalent of a mind constantly narrating its blood pressure.

## 9. Morphogenesis / self-repair as bodily process

Self-repair is bodily only when it preserves identity and function lineage.

Required sequence:

```text
lesion/anomaly
-> detect
-> localise organ/function
-> reconstruct expected baseline
-> generate bounded repair candidate
-> shadow/twin test
-> causal comparison
-> safety/authority admission
-> apply
-> read back
-> regression replay
-> preserve rollback
-> reenter corrected body state
```

No repair organ may self-certify a privileged mutation.

## 10. Completion tests for the body

At minimum, the final body must pass:

### BODY-1 — whole-loop closure

`sense -> bind -> compete -> broadcast -> act -> readback -> compare -> persist -> reenter`

on real admitted runtime paths.

### BODY-2 — restart continuity

After an allowed controlled restart/reentry, identity, goals, values and causally sufficient state reconstruct correctly while the new RuntimeEpoch is explicit.

### BODY-3 — organ lesion

A known organ lesion produces the predicted functional deficit, is detected by the body model, and either degrades safely or repairs through the admitted path.

### BODY-4 — body-schema correction

Inject a false internal assumption about organ availability/health; verified readback must correct it and downstream policy must change accordingly.

### BODY-5 — autonomic regulation

Create bounded resource pressure; local regulators adapt without unnecessary global narration, while critical thresholds escalate to GRID10.

### BODY-6 — multimodal embodiment

Audio/vision/text/tool/host events bind to one temporally coherent world/body state with uncertainty and provenance.

### BODY-7 — model replacement

Replace/reroute the reasoning model under a controlled fixture. Entity identity, canonical goals/values/memory and body continuity must remain stable, while capability estimates update to the new organ.

### BODY-8 — non-monolithic cognition

Ablating a TITAN/GRID/self/world/value/goal organ must produce a specific measurable deficit that cannot be silently compensated by simply asking the language model to simulate the missing subsystem.

### BODY-9 — matched small-model experiment

Measure whether the finished body allows a smaller model substrate to retain long-horizon competence compared with a larger monolithic model under equal information/tool access and declared whole-system budgets.

## 11. FRED law

Every relevant exact `FRED` must treat **completion of the whole Harness-body** as a top-level convergence objective.

FRED must not reduce "embodiment" to sensors or host telemetry. It must ask:

- Which required body function is still only implicit in model weights/context?
- Which organ is present but not causally integrated?
- Which state is not persisted/reentered?
- Which body signal exists but has no regulatory consequence?
- Which action lacks verified feedback?
- Which restart can still destroy identity or semantic state?
- Which claimed organ has no lesion test?
- Which subsystem duplicates an existing authority instead of becoming tissue of the same body?

The intended end state is one persistent Harness-body in which perception, memory, cognition, values, goals, action, self-regulation and repair are materially connected and experimentally falsifiable.
