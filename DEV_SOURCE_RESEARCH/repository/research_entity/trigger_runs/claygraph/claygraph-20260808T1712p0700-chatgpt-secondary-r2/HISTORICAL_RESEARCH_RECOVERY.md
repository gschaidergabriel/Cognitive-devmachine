# ClayGraph Cycle 4 — Historical Research Recovery

The project owner supplied/referenced older research material during the run. It is treated as historical evidence, not as automatically current truth.

## Surviving mechanisms recovered

### Associative memory as pre-retrieval state
The older `neue-denk-struktur-in-frank-sytetic-clay-memory-and-database-transcendence.txt` articulates a stronger goal than ordinary RAG: a current thought/event should alter which memories are active before the model explicitly decides to search. It distinguishes a small active Assembly from a much larger latent relational memory and proposes that the persistent substrate continues evolving between LLM calls.

This mechanism remains compatible with current ClayGraph evidence if activation is treated as salience rather than truth and if model-visible context stays bounded.

### Incremental relation plane before activation
`XENO_TO_CLAYCODE_MIGRATION_AND_ARCHITECTURE_RAE88_G2.pdf` already proposed the build order `canonical identity + bitemporal event schema -> adapters -> read-only world -> incremental relation/materialized views -> activation field + budget/inhibition -> Assembly compiler`. It also explicitly allowed physically plural storage behind one logical world and required replayable migration/rollback.

This anticipates G1c's resident index but adds the missing update/activation lifecycle.

### Four lifecycle separation
`CLAYCODE_MANUAL_RAE88_G2.pdf` separates persistent world/history, ephemeral activation, temporary Assembly membership and authorized effects. `ACTIVATE/INHIBIT` change salience only; production should add decay, saturation, budget and coarse-to-fine expansion. Fast processes may update activation continuously while slow model transforms are invoked selectively.

This becomes the semantic safety basis for G1d.

## What remains retired or unproven

- no resurrection of withdrawn G10/XENO compression or motif-performance claims;
- no claim that graph/hypergraph structure proves higher-order causation;
- no claim that spreading activation is globally superior to FTS or graph-lexical retrieval;
- no phenomenal-consciousness inference;
- no physical database-monolith requirement.

## New synthesis

Cycle 3 solved the question-time architecture by proposing resident indexes and adaptive graph escalation. Historical recovery shows that a complete Clay memory architecture also needs a **between-query latent field**. The new candidate therefore separates:

1. authoritative exact/event truth;
2. immutable resident semantic graph epoch;
3. incremental delta overlay;
4. ephemeral continuously updated latent activation field;
5. temporary epoch-pinned Assembly;
6. optional graph escalation and exact validation.

The key test is whether this field can stay cheap, bounded and causally useful without becoming stale truth or noise amplification.
