# ClayGraph Cycle 4 — Negative / Limiting Results

1. **No new post-Cycle-3 repository evidence existed at trigger start.** Cycle 4 cannot claim independent mesh replication from chronology alone.
2. **Historical recurrence is not replication.** Older Clay/XENO documents anticipating activation fields/incremental views increase design continuity, not empirical confidence.
3. **Always-incremental maintenance is rejected as a universal rule.** In the 30k-node proxy, a 20% changed-node batch made overlay construction slower than a full rebuild; large overlays also impose query/memory tax.
4. **Change fraction alone is not enough.** At 10% changes, overlay publication was cheaper but accumulated query tax amortized the rebuild after ~974 subsequent queries in the proxy.
5. **Continuous activation must not mean global continuous sweep.** Eager whole-field decay was much more expensive than lazy touched-node decay; G1d therefore rejects O(N) salience refresh as default.
6. **Sparse-field proxy is not cognitive benefit.** The 0.028 ms local update result establishes only synthetic implementation feasibility, not better memory, autonomy or reasoning.
7. **Epoch proxy is not a concurrency proof.** Zero mismatches in 1,000 simulated old/new epoch reads does not establish real thread/process atomicity, reclamation safety or crash consistency.
8. **Spreading activation remains non-universal.** The hosted 8B evidence from Cycle 3 still says the current activation overlay did not consistently outperform graph-lexical retrieval and must remain outside the default hot path.
9. **No target Qwen-class 4B validation.** Historical 4B expectations and current 8B proxy results cannot substitute for target-model testing.
10. **No live FRANK migration advancement.** The 71-store inventory/parity/p99/crash/privacy gates remain incomplete; `MERGE` is still unsupported.
11. **No consciousness inference.** Persistent self-reference, associative activation and between-call state are functional architecture properties only.
12. **No resurrection of retired XENO claims.** Withdrawn G10 motif/compression/performance claims remain negative/history-only despite the historical source recovery.
