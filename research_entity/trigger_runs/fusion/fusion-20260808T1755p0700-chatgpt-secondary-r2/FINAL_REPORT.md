## Executive synthesis

The current mesh has converged strongly around four mechanisms—operation-specific causal basis, epoched/derived memory, stage-orthogonal workspace causality and external effect authority—but most of that convergence shares ancestry. Fusion therefore did not count repeated branch agreement as replication. Instead it searched for a failure mode that cuts across the converged architecture.

The key new result is that **a certified causal basis is necessary but not sufficient for consequential cognition**.

A transition can use mutually compatible epochs and still be unsafe if:
1. a memory item's authority/origin was laundered before retrieval;
2. an untrusted but structurally valid selector redirected which authentic records entered cognition;
3. a projection changed the reader's semantics/order;
4. an effect capability was invalid at release time.

Fusion therefore proposes the OPEN candidate:

# CTC-FUS1 — Authority-Aware Cognitive Transaction Capsule

```text
authoritative memory/event write
  -> non-malleable origin / authority class
  -> exact state + operation-specific required basis witnesses
  -> selector/query-plan attestation when selection is reallocatable
  -> graph prior / ActiveAssembly (non-authoritative accessibility)
  -> candidate set
  -> GWT competition / selection / gate evidence
  -> semantic WorkspaceEpisode
  -> deterministic reader projection + projection receipt
  -> receiver reconstruction / uptake
  -> model proposal
  -> compositional closure + capability/effect gateway
  -> effect receipt -> outcome
  -> ancestry-bound revocation / freshness-gated re-entry
```

The broad fallback remains important: **when dependency, selector or authority closure is unknown, widen validation/selection or reject.** The candidate is not a license to optimize every path narrowly.

## 4. Independent external research

### Selection integrity
Current 2026 research `Selection Integrity for LLM Graph Memory` (arXiv:2606.12290) provides an independently developed counterexample to record-only provenance. Its central mechanism is directly relevant: writable graph structure can change which authenticated facts enter top-k while the retrieved records themselves remain authenticated. The paper reports an effect-bearing live-action setting where structural writes redirected irreversible actions and an authenticated-subgraph selector blocked the attack. Fusion uses this as external support for a **selector-integrity boundary**, not as evidence that FRANK currently has the vulnerability.

An important refinement from that work is that exposure depends on **reallocatability** of the selector's structural term, not simply on whether a graph is used. Fusion therefore rejects a universal rule that every graph query must always pay the same attestation cost.

### Write-time origin / memory laundering
Current 2026 preprint work surfaced by Exa argues that content- or lineage-based memory authority can be laundered through agent summarization, trusted-tool echoes or manufactured corroboration, and proposes non-malleable write-time origin binding. A current memory-security survey likewise frames security across the full Write -> Store -> Retrieve -> Execute -> Share/Propagate -> Forget/Rollback lifecycle.

Fusion's transfer is narrower than those papers' security claims: **selector integrity must not be treated as a replacement for origin authority.** Both are separate witnesses.

### Proof-carrying action envelopes
2026 `Proof-Carrying Agent Actions` independently converges on portable runtime-verifiable action certificates with pre-action admissibility, approval/assumption and outcome checkpoints. This is architecture-class support for carrying verifiable evidence through a consequential transition; it is not direct proof of CTC-FUS1.

### Projection is not neutral serialization
Current work on structured output shows model-dependent changes in answer distributions under forced structured formats, while other causal studies find no universal format effect across all scenarios. Fusion therefore retains the conservative rule: projection/order/schema are causal inputs that must be measured and receipted, but no universal direction or benefit should be assumed.
