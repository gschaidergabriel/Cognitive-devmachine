Its operational contract does not permit a shallow one-search/one-answer run. ## Perceptual Assembly Reflex remains a candidate

The user-proposed connection between q23 and UnifiedDB/EAP remains deliberately falsifiable rather than fixed.

**PAR-1 — Perceptual Assembly Reflex:**

`current visual evidence`
` -> Qwen native vision / MVC`
` -> high-confidence provenance-bound visual entity/state seed`
` -> current UnifiedDB ref resolution`
` -> Emergent Assembly Preprocessor`
` -> bounded ActiveAssembly`
` -> combine current visual representation + relevant relational memory`
` -> optional Qwen semantic decode / GWT / action reasoning`

Unknown/ambiguous perception does not get forced into memory anchors. A higher-risk bidirectional extension may use EAP context only to choose where/how to sense next; retrieved memory never overwrites or pre-validates observation.

Existing EAP evidence makes this plausible because EAP is already a disposable epoch/hash-bound possibility preprocessor returning context-only ActiveAssemblies, with some synthetic subpaths in microsecond/sub-millisecond ranges. It is not literally latency-free and complete sensor->seed->EAP->prompt->decision latency remains the relevant measurement.

The strongest failure mode remains confirmation bias: one wrong high-confidence visual seed can activate coherent but false relational context. Wrong seed, stale state, shuffled graph, contradictory memory, changed identity, unknown near-neighbor and direct/no-EAP controls are mandatory.

## New mandatory separation: Frank has experience vs Frank has no experience

The Qwen/Frank/PAR experiment may no longer collapse memory benefit into a binary familiar/unfamiliar comparison.

Any claim that **Frank benefits from prior experience** must use:

`research_entity/retina/Q23_FRANK_EXPERIENCE_DOSE_RESPONSE_CONTRACT_20260810.md`.

One Frank experience data point is one **independent provenance-bound Frank episode** containing observed visual/context evidence and verified outcome. Repeated near-identical frames from one episode do not increase N. Qwen pretrained knowledge remains constant across conditions and is explicitly **not counted as Frank experience**.

Default experience ladder:

`N = {0, 1, 2, 4, 8, 16, 32, 64}`

Extend geometrically if useful and independent data exist.

At each N, compare at least:

- `QWEN_ONLY`;
- `DIRECT_MEMORY_N`;
- `PAR_EAP_N`;
- `PAR_ACTIVE_N`;
- irrelevant matched-volume `SHAM_N`.

Run separate regimes where fixtures permit:

- exact recurrence;
- same entity/state variants;
- relational transfer;
- novel entity;
- conflicting/stale experience.

Required threshold outputs:

- `N_onset`: first reproducible net benefit without safety/error regression;
- `N_robust`: first N where benefit survives independent seeds/orderings/relevant fixture classes;
- `N_90`: smallest N reaching ~90% of stable plateau benefit when a plateau is identifiable;
- `N_harm`: first N where more/stale/conflicting experience reverses net benefit.

If no onset appears, report `N_onset > max_tested_N` rather than inventing a threshold.

This creates several live counterhypotheses: no dose effect because Qwen already solves the task; useful threshold too high for realistic Frank experience; early small-N overfit; generic memory-volume/cache confound; direct memory dominates EAP; or non-monotonic harm when stale/conflicting experience accumulates.

## Important research split

Q23 now separately asks:

1. **Physical vision reuse:** can Qwen/mmproj media features be encoded once and reused without duplicate deep vision?
2. **Representation geometry:** raw Qwen vs tiny projected Qwen vs dedicated lightweight embedding for familiarity/open-set behavior.
3. **End-to-end cognition:** does the abliterated/text-semantic decoder preserve correct visual reasoning/actions even if low-level features are stable?
4. **Perceptual memory seeding:** can visual evidence safely produce current UnifiedDB anchors before full semantic decode?
5. **Associative retrieval utility:** does EAP beat both Qwen-only and simpler direct memory end-to-end?
6. **Memory-guided perception:** does EAP improve active sensing without confirmation loops?
7. **Experience onset:** at what independent Frank episode count does any benefit actually begin, stabilize, saturate or become harmful?

These questions must not be collapsed into one benchmark score.
