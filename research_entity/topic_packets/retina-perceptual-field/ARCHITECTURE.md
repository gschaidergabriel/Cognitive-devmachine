# Architecture

Logical planes:

1. **E / Evidence** — immutable source/time/transform-bound observations and calibrated bottom-up precision.
2. **P / Perceptual hypotheses** — reversible set-valued interpretations with support/contradiction and separate prior/context contributions.
3. **W / World integration** — persistent entities/relations with explicit visibility/temporal states and evidence lineage.
4. **G / Global projection** — bounded visual Assembly into GWT only when global value justifies it.
5. **A / Active sensing** — choose additional visual computation/action by expected information/task/safety value versus cost/risk.
6. **R / Receipt materialization** — reconstruct complete VisualPercept/audit snapshots on demand.

Candidate multi-rate loop:

`ingress -> local delta/track maintenance -> semantic hypothesis update when needed -> world reconciliation -> local resolution or GWT -> action/sensing -> visual re-entry`.

Hard invariants:
- prior is not evidence;
- non-observation is not absence;
- semantic label is not persistent entity identity;
- model/visual output has no effect authority;
- stale/replayed evidence cannot mutate current truth;
- every derived visual claim retains dependency provenance;
- H1/H2/H3 preserve the same semantic trace even when physical topology changes.
